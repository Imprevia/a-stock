# 市场环境看板设计规范

> 状态：`active`  
> 版本：`1.0` · 最后更新：`2026-09-01`  
> 适用范围：`apps/market-environment-dashboard/` 及后续同类盘后研究页面  
> 实现基线：现有 01 至 09 页面、`src/styles.css` 与 `src/App.vue`

## 1. 目标

本规范用于统一市场环境看板后续页面的设计、实现和评审。页面首先是盘后研究工具，其次才是视觉作品：必须便于连续扫描、横向比较、追溯数据质量和识别风险，不使用营销页式构图或纯装饰视觉。

新增页面应复用现有页面骨架、语义色、组件模式和响应式行为。需要偏离本规范时，先在产品规格或 active plan 中说明原因，再修改实现。

## 2. 设计原则

1. **证据优先**：先展示交易日、覆盖率、质量状态、来源和 warning，再展示推断或结论。
2. **层级克制**：通过字号、字重、留白和边框建立层级，不依赖大面积渐变、阴影或装饰图形。
3. **数据诚实**：缺失值保持 `--` / `null` / `insufficient`，不得用 0、空数组或乐观文案掩盖缺口。
4. **研究工作台**：界面保持安静、紧凑、可扫描；同类指标对齐，数字使用稳定尺寸，表格允许横向滚动。
5. **跨页面一致**：01 至 09 页面共享导航、文档头、证据条、面板、状态和响应式规则。
6. **可读性底线**：所有可见文字、图表标签和 tooltip 不得小于 `14px`。

## 3. 页面骨架

### 3.1 桌面结构

```text
┌──────────── 270px sidebar ────────────┬──────────── main shell ────────────┐
│ 品牌区                                │ 56px sticky topbar                 │
│ 一级导航                              ├────────────────────────────────────┤
│ 01—09 二级导航                        │ 文档头：编号 / 标题 / 规则范围       │
│                                       │ 证据条：交易日 / 覆盖率 / 状态 / 元数据│
│ 规则事实源                            │ 页面专属内容                         │
└───────────────────────────────────────┴────────────────────────────────────┘
```

- Sidebar 固定宽度 `270px`，背景 `#19221f`，页面主体使用同宽左外边距。
- Topbar 最小高度 `56px`，固定在内容顶部，负责导航入口、交易日和刷新动作。
- 内容区最大宽度 `1320px`，桌面左右留白合计 `48px`，上下内边距为 `28px / 54px`。
- 页面主体按“文档头 → 证据条 → 核心指标 → 分析面板 → 质量提醒”组织。

### 3.2 文档头

- 左侧编号块：桌面 `54×54px`，移动端 `48×48px`，窄屏 `42×42px`。
- 中间区域依次展示章节 kicker、页面 H1 和一句话目标。
- 桌面右侧展示规则范围和校准状态；`900px` 以下隐藏规则范围，避免挤压标题。
- H1 必须是页面主题的字面名称，不写营销式口号。

### 3.3 证据条

- 固定展示实际交易日、章节覆盖率、数据状态和更新时间/样本元数据。
- 桌面使用横向排列，最小高度 `68px`；`620px` 以下改为两列，元数据独占整行。
- 证据条位于所有业务结论之前，不得移动到页面末尾。

## 4. 设计 Token

### 4.1 字体

```css
font-family: Inter, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
```

| 层级 | 字号 | 用途 |
|------|------|------|
| 可见文字下限 | `14px` | 正文、辅助信息、标签、表格、图例、坐标轴、tooltip |
| 面板标题 | `15px` | Panel H2 |
| 卡片主价格 | `18px` | 指数卡收盘价 |
| 文档编号 | `19px` | 页面编号块 |
| 信号值 | `20px` | 短线生态信号值 |
| 文档标题 | `23px` 桌面 / `18px` 移动 | 页面 H1 |
| 指标主值 | `23px` 桌面 / `19px` 移动 | Metric Card 数值 |
| 综合结论 | `33px` | 09 页唯一结论 |
| 环境分类 | `38px` 桌面 / `30px` 移动 | 08 页当前环境 |

- 正文行高使用 `1.55` 至 `1.8`；H1 使用 `1.25`；导航使用 `1.4`。
- 普通文字使用默认字重；标签和标题主要使用 `700`，关键数字可使用 `750`。
- 字间距固定为 `0`，不使用负字间距。
- 数字、日期、代码优先使用等宽数字特性 `font-variant-numeric: tabular-nums`。

### 4.3 图表颜色

| 数据系列 | 色值 |
|----------|------|
| K 线上涨 | `#c65050` |
| K 线下跌 | `#26815f` |
| MA5 | `#c45b55` |
| MA10 | `#7263a7` |
| MA20 | `#d18a35` |
| MA60 | `#87929d` |
| 成交额 | `#b9d2d4` |

同一指标跨页面必须使用相同颜色。不得仅为“更鲜艳”而替换系列色。

### 4.4 间距、边框与圆角

- 页面和面板主要间距使用 `8 / 10 / 14 / 18 / 20 / 24 / 28 / 32px`。
- 重复卡片网格间距使用 `8` 至 `10px`；页面级网格间距使用 `14px`。
- 标准面板内边距 `20px`，`620px` 以下为 `16px`。
- 标准面板圆角 `6px`；编号块最大 `7px`；状态标签 `4px`；不得新增大圆角胶囊卡片。
- 标准边框为 `1px solid #dce2df`，通过边框和背景分组，不使用多层重阴影。
- 不允许卡片嵌套卡片；内部信息用分隔线、列表或无边框区域组织。

## 5. 导航与操作

### 5.1 Sidebar

- 一级导航描述章节，二级导航对应 01 至 09 文档视图。
- 二级导航行最小高度 `50px`，编号块 `28×28px`，允许中文标题自然换行。
- 选中态同时改变背景、文字和编号块，不只改变文字颜色。
- `900px` 以下 Sidebar 变为 `278px` 抽屉，并显示遮罩与关闭按钮。

### 5.2 Topbar

- 左侧只保留面包屑或移动端菜单按钮；右侧放交易日和刷新动作。
- 图标按钮采用 Lucide 图标，标准尺寸 `34×34px`、圆角 `5px`。
- 图标按钮必须提供 `aria-label`；不熟悉的图标同时提供 `title`。
- 禁用刷新时使用等待光标和透明度变化，加载图标允许旋转。

### 5.3 键盘与动效

- 按钮和输入框的焦点轮廓为 `2px solid #2d8a8c`，外偏移 `2px`。
- Hover 只使用轻微边框、背景或 `translateY(-1px)` 反馈。
- 尊重 `prefers-reduced-motion`，将动画和过渡缩短到近乎关闭。

## 6. 基础组件

| 组件 | 使用场景 | 约束 |
|------|----------|------|
| Panel | 单个分析工具或数据区域 | 白底、1px 边框、6px 圆角、20px 内边距 |
| Metric Card | 2 至 5 个并列核心指标 | 标签 14px，主值 23px，移动端 19px |
| Index Card | 可切换指数对象 | 名称、代码、主值、涨跌幅、趋势齐全；量价区域先显示 5 日成交额比值，再显示可选状态，未分类时不补文案 |
| Combination Analysis | 第 01 页第四部分 | 当前指数组合状态 + 触发证据、四项市场输出、六类规则对照；命中行可强调，未命中不伪造状态 |
| Quality Badge | 数据集质量 | 必须显示状态文字，并映射语义色 |
| Evidence Strip | 页面级证据元数据 | 位于文档头之后、业务内容之前 |
| Data Table | 多对象横向比较 | 数字右对齐，首列左对齐，移动端横向滚动 |
| Signal List | 少量并列信号 | 4 列桌面、2 列中小屏、1 列窄屏 |
| Empty Evidence | 未接入或证据不足 | 图标 + 标题 + 可追溯原因，不渲染伪数据 |
| Warning Band | Provider 降级与覆盖缺口 | 页面内容之后展示完整 warning，不隐藏细节 |
| Classification Block | 环境类别或唯一结论 | 深绿底，只用于高层结论，不用于普通指标 |
| Verification Panel | 次日确认与失效条件 | 两列桌面、一列移动，信息必须成对出现 |

### 6.1 面板标题

统一结构为：

```text
Kicker（数据域或作用）
H2（本面板直接回答的问题）              Quality Badge / Selected Hint
```

- Kicker 使用 14px、700 字重和次要文字色。
- H2 使用 15px，不使用页面级大标题。
- 右侧只放质量标签、选中对象或明确动作，不放解释性长文。

### 6.2 指标卡

- 适合回答“当前是多少”，不承载长解释。
- 标签在上、主值在下；涨跌使用 A 股红涨绿跌约定。
- 4 项指标使用四列，5 项指标使用五列；在 `1180px`、`620px` 和 `400px` 断点逐步降列。

### 6.3 表格

- 通用宽表最小宽度 `900px`，行业表最小宽度 `700px`。
- 表格外必须有 `.table-scroll`，允许组件内部横向滚动，但页面本身不得横向溢出。
- 表头、单元格和状态标签均不得小于 `14px`。
- 第一列可使用“名称 + 代码”两行结构；数值列使用稳定格式和占位符 `--`。

## 7. 图表规范

- 图表只用于显示真实数据关系，不作为装饰背景。
- 60 日价格图使用真实 OHLC candlestick，采用红涨绿跌，并叠加 MA5/10/20/60；不得以收盘价合成开高低。
- K 线图标准高度 `300px`，`620px` 以下为 `260px`。
- 成交额图标准高度 `120px`，纵轴建议 3 个分段，并启用 `hideOverlap`。
- 图例、坐标轴和 tooltip 文字统一 `14px`。
- 价格图左侧网格留白 `62px`、底部 `42px`，避免轴标签裁切。
- Tooltip 使用 `axis` 触发并限制在图表容器内，必须能读取开盘、最高、最低、收盘和均线。
- 移动端允许图表相对面板左右扩展 `8px`，但不得造成页面级横向滚动。
- 图表下方必须说明指标口径和数据来源。

## 8. 九类页面组合模板

| 页面 | 主要回答 | 推荐组合 |
|------|----------|----------|
| 01 指数结构 | 指数在哪里、趋势和量能如何 | 指数卡 → 价格/成交额图 + 指标栈 → 横向比较表 |
| 02 市场广度 | 指数涨跌是否代表多数股票 | 四项指标卡 → 广度条 + 规则说明 |
| 03 涨跌停生态 | 热度、风险、封板和接力如何 | 五项指标卡 → 四项信号列表 + 数据质量说明 |
| 04 分层亏钱效应 | 风险位于高、中、低哪一层 | 四项指标卡 → 分层分析或 Empty Evidence |
| 05 主线持续性 | 行业方向是否集中和持续 | 行业表 → 质量标签 / Empty Evidence |
| 06 容量方向 | 大成交额资金攻击哪里 | 摘要 → 个股宽表 / Empty Evidence |
| 07 事件台账 | 事件是否可靠且被盘面确认 | 事件列表 + 调整边界说明 |
| 08 环境归类 | 当前属于趋势、轮动、退潮或混合 | 深色分类块 + 证据一致性列表 |
| 09 综合判断 | 唯一结论、风险和次日验证是什么 | 深色结论块 + 证据/风险面板 + 验证面板 |

新页面应先选择最接近的组合模板，再决定是否新增组件。不得为每个页面发明独立视觉语言。

## 9. 数据状态与内容规范

### 9.1 状态顺序

页面必须覆盖以下状态：

1. 初次加载：居中 loader + “正在读取市场证据…”或等价明确文案。
2. 成功：展示证据条和数据内容。
3. 部分成功：保留成功数据，并显示 quality badge 和 warning。
4. 数据不足：使用 Empty Evidence 或 `--`，说明缺少的样本与原因。
5. 请求失败：Error Panel + 错误原因 + “重新加载”动作。

### 9.2 文案

- 页面标题回答“分析什么”，面板标题回答“这里能判断什么”。
- 说明文案使用短句，先结论边界，后解释原因。
- 不写“表现优秀”“智能洞察”等营销措辞。
- 未校准阈值必须标记“经验阈值 · 待回测”。
- `missing`、`insufficient`、`unverified` 等状态必须转换为用户可读中文，同时保留真实语义。
- Provider warning 不得被前端改写成成功文案。

### 9.3 数值格式

- 百分比保留两位小数，正数显示 `+`；位置和覆盖率可使用整数百分比。
- 大额金额按亿或万格式化；比值使用 `x` 后缀。
- 缺失数值统一为 `--`，禁止显示 `NaN`、`undefined` 或虚构的 `0`。
- 日期使用明确的交易日，不以页面加载日期代替实际交易日。

## 10. 响应式规则

| 断点 | 行为 |
|------|------|
| `≤1180px` | 五列卡片降为三列，四列信号降为两列 |
| `≤900px` | Sidebar 改抽屉；主体取消左边距；双列分析区改一列；隐藏规则范围 |
| `≤620px` | 内容左右留白 12px；证据条两列；指标卡两列；面板内边距 16px；图表降低高度 |
| `≤400px` | 指数卡、指标卡、信号列表统一单列；文档编号缩为 42px |

- 最小页面宽度为 `320px`。
- 移动端页面不得出现页面级横向溢出；宽表必须限制在自己的滚动容器内。
- 文字放大后优先增加高度、换行或降列，不得重新缩小到 `14px` 以下。
- 固定格式控件必须有稳定尺寸，加载、hover、长文本或状态变化不得引发布局跳动。

## 11. 禁止事项

- 不创建营销式 Hero、渐变背景、装饰性光斑或大面积插画。
- 不使用大于 `7px` 的卡片圆角，不使用胶囊式文本容器代替正常标签或按钮。
- 不在卡片内部再嵌套卡片。
- 不使用单一色相覆盖整个界面；红、绿、琥珀色只承担数据或状态语义。
- 不把所有内容都做成卡片；页面骨架、导航和内容区保持无框架布局。
- 不缩小字体解决拥挤；应调整网格、宽度、换行、内边距或高度。
- 不在前端补算业务指标，不把缺失数据转成 0。
- 不让图表标签、表格文字或按钮文案相互遮挡。
