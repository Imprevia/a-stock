# 统一市场数据采集适配器

## Stage

Stage 8/8 — 集成验证与完成证据。

## Status

completed-without-real-provider-or-production-write（OpenSpec apply 53/53；等待归档）

## Scope

- 将五个稳定数据集 `core`、`breadth`、`limits`、`sectors`、`activeDirection` 的采集统一为 `DatasetCollector.collect(DatasetDate) -> CollectionOutcome`。
- 以 dataset acquisition plan 表达 provider 优先级、fallback、shadow、enrichment 和日期能力；source adapter 负责供应商请求、验证、归一化与证据。
- 由 coordinator 统一负责 run/task、lease/fencing、失败留存、committer 调用与最多一次 aggregate rebuild，不再反射调用 collector 方法。
- 引入完整的 collector、acquisition plan、source adapter、committer、local projector、transport engine 注册表，并在外部 I/O 前 fail closed。
- 将共享 HTTP 层拆为进程内唯一 policy gateway 与单次请求 engine；gateway 统一控制 pacing、预算、重试、`Retry-After`、single-flight、缓存、熔断和脱敏诊断。
- 保留 `requests` 为默认 engine；新增独立、固定版本、默认关闭且空 allowlist 的 Scrapling 静态 HTTP profile，不安装浏览器或启用挑战处理、代理轮换、stealth 升级。
- 保持 API、快照 schema/checksum、数据集顺序、provider 优先级、feature flag 默认值、精确日期、同日留存、provider-free GET/status 和 PostgreSQL 原子/fencing 语义兼容。
- 保持扶摇行业回退与 Eastmoney dataapi fill-only enrichment 的现有默认关闭状态、字段权威、latest-only/结算门禁、映射 revision、覆盖率和 warning 语义。

## Safety Boundaries

- 本计划不授权访问真实 provider、执行真实 Scrapling/Fuyao/Eastmoney probe、写生产 PostgreSQL/PVC、部署 Kubernetes/Helm release、修改 Secret、激活 CronJob 或切换生产数据源。
- `scheduledCollection.enabled=false` 与 `scheduledCollection.suspend=true` 必须保持默认值；增强镜像/profile 也不得改变该契约。
- HTTP 401/403、登录墙、CAPTCHA/interstitial challenge 与 provider 权限拒绝必须快速失败，不得自动切换 engine、浏览器、代理或挑战解决能力。
- 所有验证使用离线 fixture、fake transport、临时测试存储或显式隔离测试环境；未执行的真实网络/生产检查必须作为剩余缺口记录，不能伪造为成功。
- 缺失和失败继续以 `null`、`missing`、`degraded` 或 `insufficient` 表达，不得用 0、其他日期或无证据响应补齐。

## Acceptance

- OpenSpec `unify-market-data-acquisition-adapters` 的 53 项 apply 任务全部按实际完成状态勾选，strict validation 通过。
- 五个稳定数据集均通过完整注册的 acquisition plan/source adapter/collector/committer/projector 路径运行，业务用例不感知供应商或 transport engine 类型。

- 普通 GET、collection status 和 local detail projection 的 provider/transport 调用数为 0；稳定 root import 和 CLI/API golden 保持兼容。

- 401/403/challenge 不重试升级，敏感 header/cookie/query/proxy/body 不进入日志、任务元数据、快照或 fixture。
- provider 顺序、feature flag 默认值、source/warning/observations、snapshot schema/checksum、same-date retention、aggregate CAS 与 API 字段不变。
- focused 与全量 pytest、交易规则 validate/coverage/docs sync-check、部署离线渲染、OpenSpec strict、docs-contract full 和 `git diff --check` 通过，或对非本变更环境阻塞给出可复核证据。
