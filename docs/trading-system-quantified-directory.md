## 阅读顺序

1. 先读 `00-搭建交易系统.md`，确认样本、窗口、评分、置信度、否决和状态晋级规则。
2. 进入章节后先读 `0-主题.md`，再按编号阅读具体规则。
3. 使用规则时同时记录规则 ID、版本、得分、覆盖率、置信度、否决项、确认和失效条件。
4. 所有 `needs-backtest` 阈值必须经过第10章的样本外和成本验证后，才能升级为 `validated`。

## 维护规则

- 原版和量化版必须保持一对一相对路径；新增、删除或重命名文档时同时更新两个目录索引。
- 原版只维护观点来源，量化版只维护量化规则；不要用量化版反向覆盖原始材料。
- 新规则使用稳定的 `QTS-章节-文档-序号` ID，已有 ID 不因文字调整而重排。
- 规则的执行字段、版本和 evaluator 以 `trading-rules/` 为准；Markdown 必须解释同一规则 ID，不能定义未登记的执行状态。
- 数值阈值必须标明固定定义、用户参数、经验初值或已验证状态。
- 无法可靠观察的主体身份、动机和叙事不得进入评分。
- 目录或规则状态变化后同步更新本索引、`AGENTS.md`、`docs/repository-guide.md` 和 `docs/status.md`。
