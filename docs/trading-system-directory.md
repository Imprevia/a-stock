## 阅读顺序

1. 从 `00-搭建交易系统.md` 了解整体章节。
2. 进入章节目录，先读 `0-主题.md` 总览。
3. 按正文编号从小到大阅读；综合解读通常位于该章节末尾。

## 维护规则

- 新增内容必须放入对应章节目录，不能在 `搭建交易系统/` 根目录新增章节正文。
- 章节总览固定使用 `0-主题.md`；正文使用两位数字加句点，如 `01.主题.md`。
- 调整目录或文件名后，必须同步更新本索引和 `AGENTS.md` 中的结构说明。
- 本索引只描述路径，不复制正文内容；正文变更无需在此重复记录。
