# 交易执行与心理管理

### 执行力的本质

执行力差往往不是“不够自律”，而是规则不清、没有验证或风险设置过大。改善顺序应为：

1. 把模糊规则改成可观察条件；
2. 用历史样本确认规则具有统计依据；
3. 把单笔损失降到心理可承受范围；
4. 使用检查清单和条件单减少临场决策；
5. 复盘执行偏差，而不是只复盘盈亏。

### 常见心理触发器

- **翻本冲动**：连续亏损后突然放大仓位。
- **扛单幻想**：止损触发后期待马上反弹。
- **踏空焦虑**：看到他人盈利或个股拉升后临时追入。
- **利润回吐恐惧**：未达到退出条件就过早卖出。
- **确认偏误**：只寻找支持持仓的信息，忽略反证。
- **结果偏误**：违规交易赚钱后认为规则无用，合规交易亏损后否定系统。

### 针对心理问题建立机械约束

- 连续亏损达到阈值后强制暂停。
- 下单前必须填写交易计划编号。
- 止损触发后不允许在同一逻辑下立即买回。
- 违规交易后降低下一阶段风险预算，而不是用惩罚性交易翻本。
- 将部分资金移出交易账户可以限制仓位，但应作为事先约定的风控措施，不是情绪化自我处罚。
- 每日复盘先评价是否按规则执行，再评价盈亏结果。

### 盘感的四个阶段

原资料将盘感培养分为：

1. **量变积累**：长期观察指数、板块、K线、龙头、跟风、炸板和跳水。
2. **总结规律**：寻找同类结构在不同市场环境中的重复表现。
3. **贴合市场**：理解恐慌、狂热和预期差，但保留反证意识。
4. **形成直觉**：快速识别熟悉结构，再由明确规则完成最终决策。

需要强调：直觉只能用于生成假设，不能取消风控和记录。

### 研究高手交割单的方法

选择与自己风格一致、时间接近当前市场环境、数据相对完整的公开案例。每笔重点研究：

- 当时的市场环境和板块地位；
- 买入前可能看到的信息；
- 买点、仓位和失效条件；
- 持有期间如何处理分歧；
- 卖出依据；
- 盈利单与亏损单是否采用同一规则；
- 是否存在只展示成功案例的幸存者偏差。

研究的目标是提出可验证假设，而不是模仿某一笔成交。
