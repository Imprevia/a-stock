# 2.常见心理触发器

心理触发器是使交易者偏离原计划的情境—情绪—行为链。它不是性格标签，而应被记录成可识别、可干预的风险信号。

## 一、重点记录什么

| 触发器 | 应观察的数据/行为 | 能得到的信息 |
|-|-|-|
| 翻本冲动 | 连亏后是否放大仓位、增加交易次数？ | 亏损后是否出现报复性交易 |
| 扛单幻想 | 止损触发后是否拖延、取消止损或补仓？ | 是否用希望替代失效条件 |
| 踏空焦虑 | 是否因盘中拉升、他人盈利而临时追入？ | 是否违反预设入场条件 |
| 利润回吐恐惧 | 未到退出条件是否提前卖出？ | 是否牺牲盈亏比换取短期安心 |
| 确认偏误 | 交易后是否只搜利好、忽略反证？ | 持仓判断是否失去客观性 |
| 结果偏误 | 是否因一笔赚亏就否定/神化规则？ | 是否将随机结果误作方法优劣 |

## 二、这些数据能说明什么

- 连亏后仓位和频率同时上升，通常不是“机会更多”，而是风险预算被情绪突破。
- 止损被取消、移动或反复补仓，说明交易者已从验证假设转为捍卫仓位。
- 追涨交易若缺少原定计划编号、失效位和风险预算，应单列为计划外样本，不能与正常模式混合统计。
- 提前止盈也可能是违规：若长期只保留小盈利、承担完整止损，系统实际盈亏比会被削弱。
- 单笔结果无法证明规则对错；应以足够样本、R 结果、执行率和市场环境分组来判断。

## 三、把情绪变成可复盘数据

```text
触发情境：
当时情绪：焦虑 / 恐惧 / 急于回本 / 不甘踏空……
原计划：
实际动作：
偏离点：
造成的风险或结果：
下次机械约束：
```

## 四、边界

情绪并非必须消除；它常提示仓位过大、规则不清或信息不确定。重点不是压抑情绪，而是不能让情绪越过事先设置的风险边界。

**结论：**识别心理触发器的价值，是在错误动作发生前看见重复模式，并为它设置明确的阻断机制。

本文用于交易研究与复盘，不构成投资建议。
