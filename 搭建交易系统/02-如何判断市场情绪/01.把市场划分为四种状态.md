# 1.把市场划分为四种状态

“市场情绪”与“市场环境”不是一回事：

- **市场环境**回答：当前适不适合交易，属于趋势、轮动、退潮还是混合环境。
- **市场情绪**回答：短线资金目前处于恐慌、修复、扩张还是亢奋阶段，风险偏好正在向哪个方向变化。

判断市场情绪，重点不是看指数涨跌，也不是机械统计涨停家数，而是看：

> **成功者有没有溢价、失败者是否继续亏钱、赚钱效应是否扩散、主线能否承接，以及这些变化能否持续。**

市场情绪可以划分为四种状态：**冰点或退潮、冰点修复、上升或主升、高潮分歧或退潮前兆**。

---

## 一、先看五组核心数据

### 1. 成交额与市场广度

主要看：

- 全市场成交额及其相对5日、20日均值的变化；
- 上涨家数、下跌家数；
- 涨跌幅中位数；
- 上涨是否由多个板块共同推动；
- 指数上涨是否只是少数权重股贡献。

#### 能得到什么信息

| 数据表现 | 反映的信息 |
|-|-|
| 放量上涨、上涨家数增加、中位数为正 | 风险偏好提高，赚钱效应扩散 |
| 指数上涨，但下跌家数更多、中位数为负 | 权重护盘，真实个股情绪偏弱 |
| 缩量上涨、上涨集中于少数股票 | 资金参与不足，修复质量一般 |
| 指数下跌，但上涨家数增加、中位数转正 | 指数调整，个股情绪可能正在修复 |
| 放量下跌、下跌家数扩大、中位数持续为负 | 亏钱效应扩散，情绪接近退潮 |
| 成交活跃但指数滞涨、个股冲高回落 | 分歧加大，可能处于高潮末端 |

市场广度反映的是“**多数股票是否受益**”。指数可以被少数大市值股票影响，但上涨家数和涨跌幅中位数更接近普通交易者的真实体验。

### 2. 昨日涨停股的次日反馈

主要看昨日涨停股票在次日的：

- 开盘溢价；
- 收盘平均涨跌幅；
- 收盘涨跌幅中位数；
- 高开后能否继续上涨；
- 低开后能否修复；
- 冲高回落比例；
- 跌停或大幅低开的数量。

#### 能得到什么信息

| 次日反馈 | 反映的信息 |
|-|-|
| 平均值和中位数都为正 | 昨日追涨者普遍赚钱，接力意愿增强 |
| 平均值为正，但中位数为负 | 少数核心股拉高平均值，多数追涨者仍亏钱 |
| 高开后普遍继续上涨 | 资金愿意为强势股支付更高价格 |
| 高开低走明显增多 | 一致预期过强，兑现压力增加 |
| 低开后能够修复 | 市场承接较强，情绪具有韧性 |
| 低开后继续下跌 | 接力资金谨慎，亏钱效应扩大 |
| 连续两天涨停溢价改善 | 情绪修复具有持续性 |
| 单日溢价突然转正、次日重新转负 | 更可能是弱势反抽，不是新周期 |

这里应特别重视 **中位数**。如果只有少数龙头赚钱，大部分昨日涨停股没有溢价，不能把市场定义为全面转强。

### 3. 炸板股的次日修复情况

炸板股是“当天交易失败的样本”。观察失败者如何被市场处理，往往比观察最强龙头更能判断风险。

主要看：

- 炸板股次日是否继续低开；
- 低开后能否止跌；
- 是否出现反包；
- 亏损是否明显收窄；
- 是否连续两天扩大亏损；
- 炸板是否集中在中高位或同一板块。

#### 能得到什么信息

| 炸板反馈 | 反映的信息 |
|-|-|
| 炸板股次日止跌、减亏或反包 | 市场开始容忍失败，风险偏好修复 |
| 炸板股普遍低开低走 | 失败成本高，追涨资金会迅速收缩 |
| 炸板率上升，但次日能够修复 | 分歧增加，但暂未形成退潮 |
| 炸板率上升且次日继续亏损 | 高潮转分歧，退潮信号增强 |
| 中高位股集中炸板 | 接力链条可能正在断裂 |
| 低位首板炸板较多，但核心稳定 | 可能是扩散质量下降，尚未全面退潮 |

核心逻辑是：

> **情绪真正转强，不只体现在最强股票继续上涨，还体现在失败交易不再造成持续性重伤。**

### 4. 连板梯队与高中低位亏钱效应

主要看：

- 首板、二板、三板及更高连板的数量；
- 昨日首板晋级率；
- 中位股是否断层；
- 最高连板是否抬升；
- 高位核心是否补跌；
- 跌停是否集中在中高位股；
- 低位股票是否形成有效补涨。

#### 能得到什么信息

| 梯队结构 | 反映的信息 |
|-|-|
| 首板、二板、中高位梯队完整 | 资金愿意从低位向高位逐级接力 |
| 最高板抬升、晋级率改善 | 风险偏好提高，情绪进入扩张 |
| 高位强、中位稳、低位扩散 | 情绪健康，主线具有扩散能力 |
| 高位核心仍强，但中位股大量亏损 | 表面强势，实质已经开始分歧 |
| 中位股断层 | 接力链条受损，后排风险加大 |
| 高位核心补跌 | 退潮进入更明显阶段 |
| 高位弱、中位弱、低位突然活跃 | 旧周期退潮，新周期仍处于试错 |
| 高中低位同时走弱 | 整体风险偏好下降，接近冰点 |

中位股通常是重要的风险温度计：

- 龙头可能因为辨识度高而继续抱团；
- 低位股可能因为价格低而不断试错；
- **中位股最能反映接力资金是否愿意承担风险。**

因此，高位核心上涨并不代表情绪一定健康。如果中位股已经连续大亏，往往说明风险正在从后排向核心传导。

### 5. 主线结构与资金承接

主要看：

- 板块是否连续获得成交额；
- 是否有龙头、中军、补涨和首板梯队；
- 龙头分歧后能否承接；
- 中军是否稳定；
- 板块回调后能否回流；
- 昨日追涨资金次日是否赚钱；
- 板块强势是否连续两天以上。

#### 能得到什么信息

| 主线表现 | 反映的信息 |
|-|-|
| 龙头、中军、补涨共同活跃 | 板块结构完整，资金参与层次丰富 |
| 分歧后成交未明显流失，随后重新回流 | 主线承接强，可能进入主升 |
| 只有龙头上涨，其他个股持续走弱 | 局部抱团，不是全面主升 |
| 板块一天大涨，次日没有承接 | 一日脉冲或轮动，不是情绪周期启动 |
| 新方向连续放量，旧方向同步退潮 | 可能出现真正的主线切换 |
| 新旧方向都没有持续反馈 | 市场处于混沌状态，不宜强行确认主线 |

## 二、四种情绪状态怎么看

### 1. 冰点或退潮

#### 典型数据特征

- 成交低迷，或者放量下跌；
- 下跌家数明显多于上涨家数；
- 涨跌幅中位数持续为负；
- 跌停数量增加；
- 昨日涨停股次日溢价较差；
- 炸板股继续低开低走；
- 连板晋级率下降；
- 中位股断层；
- 高位核心开始补跌；
- 主线成交额流失，分歧后无法回流。

#### 能得到什么信息

说明市场正在主动降低风险：

- 追涨者难以获得正反馈；
- 失败交易的亏损持续扩大；
- 接力资金不愿意继续抬高价格；
- 资金从中位股撤退，并可能向核心股传导；
- 市场赚钱效应正在收缩。

即使此时指数上涨，也可能只是权重护盘。若上涨家数少、中位数为负、高位股仍在补跌，就不能定义为情绪回暖。

#### 操作含义

- 降低仓位和交易频率；
- 避免中高位接力；
- 不因为某只龙头反弹就判断退潮结束；
- 等待亏钱效应停止扩散；
- 观察炸板股和昨日涨停股是否开始修复。

#### 向下一状态转换的信号

冰点转向修复，至少应看到：

1. 跌停不再扩大；
2. 高位核心停止补跌；
3. 昨日涨停溢价改善；
4. 炸板股不再继续大亏；
5. 上涨家数和中位数回升。

### 2. 冰点修复

#### 典型数据特征

- 强势股率先止跌；
- 跌停数量减少；
- 昨日涨停股溢价开始改善；
- 炸板股止跌、减亏或出现反包；
- 上涨家数增加；
- 涨跌幅中位数由深负值向零轴靠近，甚至转正；
- 首板数量增加；
- 但成交额、连板梯队和主线结构尚未完全确认。

#### 能得到什么信息

说明市场的亏钱效应正在收敛，资金开始重新试错。

但这时只能得到两个初步结论：

- **最差阶段可能正在过去；**
- **资金开始恢复风险偏好。**

还不能直接得出“新周期开始”或“主升启动”的结论，因为修复可能只是：

- 超跌反弹；
- 单日情绪回暖；
- 权重与核心股带动的局部修复；
- 退潮过程中的弱反抽。

#### 操作含义

- 可以小仓位试错；
- 优先选择最先止跌、最先获得成交支持的方向；
- 不宜在单日普涨后大幅提高仓位；
- 重点观察次日是否继续改善；
- 关注修复是否从龙头扩散到中军、首板和普通个股。

#### 修复是否有效，重点看三件事

1. **持续性**：次日是否重新回到弱势；
2. **扩散性**：是否只有少数核心股修复；
3. **承载力**：是否有成交额和板块结构支持。

如果第二天炸板股重新大亏、涨停溢价转负、上涨家数收缩，就说明修复失败，市场可能重新回到退潮。

### 3. 上升或主升

#### 典型数据特征

- 成交额连续活跃；
- 上涨家数持续增加；
- 涨跌幅中位数连续为正；
- 昨日涨停股次日溢价持续为正；
- 低开强势股能够修复；
- 炸板股次日亏损可控；
- 连板梯队完整；
- 晋级率改善，最高板抬高；
- 高位核心稳定；
- 中位股没有大面积亏钱；
- 主线有龙头、中军、补涨和板块宽度；
- 主线分歧后能够获得资金回流。

#### 能得到什么信息

说明市场形成了较稳定的正反馈：

> 股票上涨 → 追涨资金赚钱 → 更多资金愿意接力 → 板块扩散 → 成交继续增加。

这时资金不仅愿意买最强龙头，也愿意参与中军、补涨和低位启动，赚钱效应从核心向更广范围扩散。

#### 操作含义

- 可以适当提高仓位；
- 重点围绕主线和核心方向；
- 分歧回流通常比无差别追涨更有性价比；
- 可以适当延长持股周期；
- 但仍需监控中位股、炸板率和高位核心是否开始恶化。

#### 如何确认是真主升

至少观察两天以上，并且分歧后满足：

- 龙头没有结构性破位；
- 中军没有持续放量下跌；
- 板块成交额没有明显流失；
- 中位股没有集中跌停；
- 回流时，市场广度和涨停反馈同步改善。

如果只有核心股反弹，其他同板块股票继续下跌，更可能是局部抱团，而不是主升确认。

### 4. 高潮分歧或退潮前兆

这是最容易被误判的阶段，因为此时指数、涨停数量和热门板块可能看起来最强。

#### 典型数据特征

- 指数仍然上涨；
- 涨停数量仍处于高位；
- 热门板块继续扩散；
- 但炸板率开始上升；
- 昨日涨停股平均值可能仍为正，但中位数下降；
- 中位股开始出现大幅亏损；
- 高位核心放量滞涨或冲高回落；
- 板块扩散到低质量补涨；
- 后排成交放大但价格无法推进；
- 同一题材内部强弱分化扩大。

#### 能得到什么信息

说明情绪仍热，但交易质量开始下降：

- 最强核心仍能吸引资金；
- 后排和中位股已经开始承受兑现压力；
- 赚钱效应从“普遍扩散”转向“集中在少数核心”；
- 新增资金的接力效率下降；
- 市场可能从主升进入高位分歧。

这个阶段不等于已经退潮，但说明 **风险收益比开始恶化**。

#### 操作含义

- 不宜因为市场最热而继续无差别加仓；
- 减少参与低质量补涨；
- 重点观察中位股和炸板股；
- 对放量滞涨的核心股提高警惕；
- 主线分歧后若无法回流，应主动降低仓位；
- 防止把最后一轮扩散误判成新一轮启动。

#### 是健康分歧还是退潮前兆

| 后续反馈 | 判断 |
|-|-|
| 核心稳定、中军承接、炸板修复、中位股止跌 | 健康分歧，主升可能延续 |
| 核心放量破位、中军下跌、中位股跌停、炸板继续亏损 | 退潮前兆得到确认 |
| 只有龙头修复，板块多数个股继续下跌 | 核心抱团，不是全面修复 |
| 次日市场宽度和涨停溢价同步改善 | 分歧后重新转强 |
| 次日涨停溢价和中位数进一步下降 | 情绪继续向退潮演化 |

## 三、四种状态不是静态标签，而是循环变化

常见情绪路径是：

> **冰点或退潮 → 冰点修复 → 上升或主升 → 高潮分歧 → 再次退潮**

但市场不会每天严格按顺序运行，也可能出现：

- 冰点修复后失败，重新退潮；
- 主升分歧后重新回流，继续主升；
- 高位核心抱团，但中低位已经退潮；
- 新旧方向同时缺乏持续性，进入混沌；
- 指数强势，但短线情绪处于退潮。

因此，每天更重要的是判断 **变化方向**，而不是只给当天贴标签。

例如：

- 从极弱到稍弱：可能是修复开始；
- 从强势到略强：可能是主升降温；
- 从普遍强势到只有核心强：可能是高潮分歧；
- 从核心强到核心补跌：退潮可能加速。

## 四、每日评分怎么理解

可以选择七个评分项，每项按 `-1、0、+1` 记录：

1. 成交额与市场广度；
2. 昨日涨停溢价；
3. 炸板修复；
4. 连板梯队；
5. 跌停和高位亏钱效应；
6. 主线持续性；
7. 次日反馈。

### 大致分类

| 总分 | 情绪判断 |
|-|-|
| `+4`以上 | 情绪偏强，但需检查是否已经进入高位高潮 |
| `+1`到`+3` | 修复或结构性活跃 |
| `-1`到`0` | 混沌、分歧 |
| `-2`以下 | 退潮或冰点 |

但分数不能替代结构判断。

例如，同样是 `+4`：

- 如果成交、广度、涨停溢价和主线持续性共同改善，可能是健康主升；
- 如果主要靠涨停数量和龙头表现得分，但炸板率、中位股已经恶化，可能是高潮分歧。

最重要的是分数的变化方向：

- `-5 → -2 → +1`：情绪正在明显修复；
- `+6 → +4 → +1`：表面仍为正，但情绪正在快速降温；
- 连续维持`+2`：结构性活跃，但不一定形成主升；
- `-1 → +3 → -2`：修复持续性差，可能是假修复。

## 五、最实用的盘后判断顺序

### 第一步：看失败者是否继续亏钱

先检查：

- 炸板股次日反馈；
- 中位断板股反馈；
- 跌停数量；
- 高位核心是否补跌。

失败者继续扩大亏损，情绪很难真正转强。

### 第二步：看成功者是否普遍有溢价

检查：

- 昨日涨停股平均值；
- 昨日涨停股中位数；
- 高开后是否继续上涨；
- 低开后能否修复。

平均值强、中位数弱，通常只是少数核心抱团。

### 第三步：看赚钱效应是否扩散

检查：

- 上涨家数；
- 涨跌幅中位数；
- 首板数量；
- 主线板块宽度；
- 是否从龙头扩散到中军和补涨。

只有核心上涨，不属于健康扩散。

### 第四步：看结构是否完整

检查：

- 首板、二板、中高位是否形成梯队；
- 中位股是否断层；
- 主线是否具备龙头、中军、补涨；
- 分歧后是否能够回流。

结构完整并能经受分歧，才更接近主升。

### 第五步：看次日是否确认

单日数据只能提供初步信号。必须看次日：

- 修复有没有延续；
- 追涨资金有没有赚钱；
- 炸板股有没有继续受伤；
- 主线有没有承接；
- 市场是否迅速回到弱势。

## 六、盘后结论模板

> 今日成交额较近期水平\_\_\_\_，上涨家数与涨跌幅中位数显示市场广度\_\_\_\_。昨日涨停股次日平均反馈\_\_\_\_、中位数\_\_\_\_，说明赚钱效应\_\_\_\_。炸板股次日表现\_\_\_\_，失败交易的亏钱效应\_\_\_\_。连板梯队表现为\_\_\_\_，中位股\_\_\_\_，高位核心\_\_\_\_。主线成交与分歧承接\_\_\_\_。  
> 综合判断，当前情绪更接近 **冰点或退潮／冰点修复／上升或主升／高潮分歧或退潮前兆**，变化方向为\_\_\_\_，判断置信度为\_\_\_\_。下一交易日重点确认\_\_\_\_。

最核心的判断标准是：

> **情绪转强，不只是最强股票继续上涨，还要看到失败者停止扩大亏损、普通强势股获得溢价、赚钱效应向更多股票扩散。**

反过来：

> **情绪转弱，也不一定先表现为指数下跌，往往先表现为炸板率上升、中位股亏损、涨停溢价下降和高位核心放量滞涨。**
