# 2.识别情绪节点

“识别情绪节点”不是判断市场今天强还是弱，而是判断：

> **市场情绪正在从哪个阶段向哪个阶段切换，这种变化是真转折，还是只有一天的反弹或波动。**

文档中的两个关键节点分别是：

1. **冰点转强**：判断退潮是否结束、市场是否开始修复；
2. **回调确认主升**：判断上涨后的分歧是健康换手，还是新一轮退潮。

这两个节点不能只看指数或涨停数量，必须同时观察 **亏钱效应、涨停反馈、失败样本、市场广度、主线资金和次日确认**。

---

## 一、为什么要识别“情绪节点”

情绪状态是一个区间，情绪节点则是状态转换的关键时刻。

例如：

- “冰点”是一个状态；
- “冰点转强”是从退潮向修复转换的节点；
- “主升”是一个状态；
- “回调确认主升”是判断分歧后能否继续主升的节点；
- “高潮”是一个状态；
- 炸板增加、中位股大亏、高位核心滞涨，则可能是高潮向退潮转换的节点。

识别节点的意义是：

- 冰点中避免过早抄底；
- 修复初期判断是否可以小仓位试错；
- 主升分歧时判断应该持有、低吸还是退出；
- 高潮阶段及时发现风险收益比恶化；
- 不被指数单日大涨或某只龙头反包误导。

---

## 二、冰点转强怎么看

冰点转强的核心不是“今天涨得多”，而是：

> **原有亏钱效应停止扩散，成功者开始获得正反馈，失败者不再继续重伤，并且有新资金选择出明确方向。**

至少要观察六组信号。

### 1. 亏钱效应是否停止扩散

主要看：

- 跌停家数是否减少；
- 大跌股票数量是否减少；
- 高位核心是否停止补跌；
- 中位断板股是否不再连续核按钮；
- 前期强势股是否开始止跌；
- 亏钱效应是否仍在从后排向核心传导。

#### 能得到什么信息

| 数据变化 | 说明 |
|-|-|
| 跌停减少、大跌股减少 | 恐慌抛售开始收敛 |
| 高位核心止跌 | 退潮可能接近尾声 |
| 中位股不再连续大幅低开 | 接力资金的风险压力下降 |
| 后排止跌，但核心仍在补跌 | 退潮可能尚未结束 |
| 跌停减少，但冲高回落仍很多 | 恐慌缓和，但买盘信心仍不足 |
| 跌停和大跌股继续扩大 | 不能定义为冰点转强 |

这里首先要确认的不是“谁开始上涨”，而是“谁不再继续下跌”。

因为退潮结束通常先表现为：

> **亏钱速度下降 → 失败者止跌 → 强势股修复 → 赚钱效应重新扩散。**

如果亏钱效应仍在扩大，即使指数大涨，也可能只是权重护盘或盘中反抽。

### 2. 昨日涨停股的次日反馈是否改善

主要看：

- 昨日涨停股次日平均涨跌幅；
- 昨日涨停股次日涨跌幅中位数；
- 高开后能否继续走强；
- 低开后能否修复；
- 大幅低开和跌停的数量；
- 改善能否持续两天以上。

#### 能得到什么信息

| 次日反馈 | 说明 |
|-|-|
| 平均值与中位数同步转正 | 多数追涨者开始赚钱，接力意愿恢复 |
| 平均值转正、中位数仍为负 | 只有少数核心股修复，整体情绪仍弱 |
| 低开股能够拉回 | 市场承接增强，抛压可以被消化 |
| 高开后继续上涨 | 资金愿意为强势股支付溢价 |
| 高开低走仍然普遍 | 兑现压力较大，修复质量不足 |
| 单日改善、次日重新转负 | 更接近弱势反抽，而不是节点确认 |

**平均值不能单独使用。**

如果两只龙头大涨，而多数昨日涨停股下跌，平均值可能仍然很好，但中位数会揭示真实情况。冰点转强应尽量看到平均值与中位数共同改善。

### 3. 炸板股是否出现修复

炸板股代表前一日交易失败的资金。

主要看：

- 炸板股次日平均涨跌幅和中位数；
- 是否继续低开低走；
- 是否能够止跌、减亏；
- 是否出现反包；
- 中高位炸板股是否仍然大幅杀跌；
- 炸板后的亏损是否连续扩大。

#### 能得到什么信息

| 炸板反馈 | 说明 |
|-|-|
| 炸板股止跌或明显减亏 | 市场开始容忍失败，风险偏好修复 |
| 部分有辨识度的炸板股反包 | 活跃资金开始重新进攻 |
| 炸板股仍普遍低开低走 | 失败成本仍高，情绪尚未真正转强 |
| 只有一只炸板股反包 | 个股行为，不能代表整体修复 |
| 中高位炸板股止跌，低位重新活跃 | 接力链条可能开始恢复 |
| 炸板率降低，但炸板股次日仍大亏 | 当日封板质量改善有限，风险尚未解除 |

冰点转强不要求所有失败股票都反包，但至少要看到：

> **失败交易的后续亏损不再持续扩大。**

这是资金愿不愿意重新试错的重要前提。

### 4. 市场广度是否扩大

主要看：

- 上涨家数是否增加；
- 下跌家数是否减少；
- 涨跌幅中位数是否回升；
- 上涨是否从少数权重扩散到普通个股；
- 是否有多个板块共同修复；
- 修复是否贯穿早盘、午后和收盘。

#### 能得到什么信息

| 广度表现 | 说明 |
|-|-|
| 上涨家数明显增加、中位数转正 | 修复从局部扩散到多数股票 |
| 指数上涨，但中位数仍为负 | 权重行情，短线情绪未必修复 |
| 上涨家数增加，但主要是超跌小票 | 风险偏好有所恢复，但主线尚未确认 |
| 多个板块同步修复 | 市场整体风险偏好提高 |
| 早盘普涨、午后大量回落 | 修复承接不足，资金仍偏谨慎 |
| 连续两天广度改善 | 冰点转强的可信度提高 |

广度回答的是：

> **这次转强是少数核心股的自救，还是全市场风险偏好的真实改善。**

只有龙头上涨、其他股票继续走弱，通常属于局部抱团，而不是冰点转强。

### 5. 核心方向是否获得成交额支持

主要看：

- 是否出现明确的领涨板块；
- 板块成交额是否放大；
- 是否不只有一只龙头上涨；
- 是否出现中军、首板、补涨共同响应；
- 核心股票上涨后能否维持强势收盘；
- 资金是否连续两天流向同一方向。

#### 能得到什么信息

| 资金表现 | 说明 |
|-|-|
| 板块放量，龙头、中军、补涨共同上涨 | 新方向可能正在形成 |
| 只有龙头反包，板块没有宽度 | 个股抱团，不足以确认转强 |
| 多个板块普涨，但没有持续成交 | 情绪反弹，主线尚未出现 |
| 核心方向连续两天获得资金 | 修复可能向上升周期演化 |
| 板块大涨但收盘回落、成交放大 | 分歧较大，可能存在兑现 |
| 当日领涨方向次日无承接 | 一日脉冲，不是新周期启动 |

成交额支持的作用，是判断上涨有没有真实资金承载。

冰点后的普涨可能来自空头回补和超跌反弹，只有当某个方向连续获得成交，并形成龙头、中军和板块宽度，才说明资金开始主动建立新仓位。

### 6. 次日是否确认

冰点转强不能只根据当天判断，必须观察次日：

- 指数和市场广度是否迅速重新转弱；
- 昨日涨停股是否继续有溢价；
- 炸板股是否重新大亏；
- 核心方向是否有承接；
- 前一日低位启动股是否出现晋级；
- 中位股是否重新出现集中亏钱。

#### 能得到什么信息

| 次日表现 | 判断 |
|-|-|
| 广度继续改善、涨停溢价保持、主线承接良好 | 冰点转强得到确认 |
| 指数震荡，但个股反馈继续改善 | 修复仍然有效 |
| 指数上涨，但涨停溢价转负、炸板扩大 | 指数强不代表情绪强 |
| 核心方向分化后能够回流 | 资金认可度较高 |
| 修复次日全面低开低走 | 修复失败，可能重新进入退潮 |
| 只有龙头继续上涨，后排全部兑现 | 局部抱团，不是全面转强 |

最重要的原则是：

> **节点可以在第一天识别，但必须由第二天确认。**

第一天解决“是否出现变化”，第二天解决“变化是否真实”。

---

## 三、冰点转强可以分成三个层次

### 第一层：止跌

表现为：

- 跌停减少；
- 高位核心停止补跌；
- 炸板股不再扩大亏损；
- 市场中位数不再继续下降。

能得到的信息：

> 恐慌可能开始收敛，但尚未出现明确进攻方向。

此阶段只适合观察或极小仓位试错。

### 第二层：修复

表现为：

- 昨日涨停溢价改善；
- 上涨家数扩大；
- 炸板股出现减亏或反包；
- 首板数量回升；
- 强势方向开始出现。

能得到的信息：

> 风险偏好开始恢复，但仍可能只是超跌反弹。

### 第三层：转强确认

表现为：

- 修复延续到次日；
- 核心方向连续获得成交；
- 龙头、中军、补涨形成结构；
- 分歧后仍有承接；
- 赚钱效应继续扩散。

能得到的信息：

> 市场可能由冰点修复进入上升阶段，可以逐步提高进攻性。

---

## 四、回调确认主升怎么看

主升并不是每天都上涨。真正健康的主升一定会经历分歧和回调。

“回调确认主升”要回答的问题是：

> **这次回调是在清洗浮筹、完成换手，还是资金已经撤退、主线开始退潮？**

重点看五组数据。

### 1. 龙头是否发生结构性破位

主要看：

- 是否跌破关键均线或前期突破位置；
- 是否放量长阴；
- 是否从高位快速跌停；
- 次日能否修复；
- 分时承接是否持续存在；
- 同板块核心是否同步走弱。

#### 能得到什么信息

| 龙头表现 | 说明 |
|-|-|
| 缩量回调、未破关键位置 | 正常分歧或洗盘的可能性较高 |
| 盘中回落但尾盘有承接 | 核心资金仍在维护 |
| 放量下跌并跌破关键位置 | 主线结构可能受损 |
| 龙头跌停、次日无法修复 | 退潮风险显著提高 |
| 龙头反弹但板块不跟随 | 个股抱团，不代表主升恢复 |
| 龙头分歧后创新高，板块同步回流 | 主升延续的强确认 |

“结构性破位”不能只看一天是否收阴，而要看：

- 关键位置是否失守；
- 成交是否表明资金撤退；
- 次日是否能收回；
- 板块是否同步恶化。

### 2. 中军是否持续放量下跌

中军通常是板块中成交额大、容量大、机构或趋势资金参与较多的股票。

主要看：

- 成交额是否异常放大；
- 收盘是否接近日内低点；
- 是否连续两天放量下跌；
- 是否跌破重要平台；
- 反弹时是否缩量无力；
- 板块其他容量股是否同步走弱。

#### 能得到什么信息

| 中军表现 | 说明 |
|-|-|
| 缩量回调、守住平台 | 趋势资金尚未明显撤退 |
| 放量分歧但收盘有承接 | 资金在换手，未必是退潮 |
| 连续放量下跌 | 容量资金可能持续流出 |
| 跌破平台后无法收回 | 主线承载能力下降 |
| 龙头强、中军持续下跌 | 可能只剩短线抱团 |
| 中军企稳并重新放量上涨 | 主线回流可信度提高 |

龙头体现短线情绪，中军体现资金承载力。

如果龙头仍然强，但中军持续放量下跌，说明板块可能只剩少数资金维持核心，主升结构并不健康。

### 3. 板块成交额是否明显流失

主要看：

- 板块成交额相对前几日的变化；
- 分歧日成交是否仍保持在较高水平；
- 回流日成交能否重新增加；
- 板块成交占全市场的比例；
- 资金是否转向其他方向；
- 板块内部上涨是否仍有宽度。

#### 能得到什么信息

| 成交变化 | 说明 |
|-|-|
| 回调时缩量、核心位置稳定 | 抛压有限，可能是正常整理 |
| 分歧时放量，但承接良好 | 多空充分换手，主线仍可能延续 |
| 连续缩量且板块宽度收窄 | 关注度下降，主线可能弱化 |
| 连续放量下跌 | 资金主动撤离风险较高 |
| 成交转向新板块，旧板块无法回流 | 可能出现主线切换 |
| 回流时成交、广度和核心股同步改善 | 主升确认度较高 |

不能把“缩量”机械理解为弱，也不能把“放量”机械理解为强：

- 回调缩量、价格稳定，通常是抛压有限；
- 回调放量、价格跌破，通常是资金撤退；
- 回流放量、价格推进，才是资金重新进攻。

### 4. 中位股是否集中跌停

中位股通常包括：

- 二至三板股票；
- 板块后排核心；
- 前期强势但辨识度不及龙头的股票；
- 已经脱离低位、但尚未成为最高标的的股票。

主要看：

- 中位股断板数量；
- 断板后的平均亏损；
- 是否出现集中跌停；
- 次日是否继续低开；
- 是否能够修复；
- 亏钱效应是否向龙头和中军传导。

#### 能得到什么信息

| 中位股反馈 | 说明 |
|-|-|
| 分歧但跌幅可控，次日能够修复 | 接力结构仍然健康 |
| 个别中位股掉队 | 正常淘汰，不一定影响主升 |
| 中位股成批断板、跌停 | 接力链条断裂，退潮风险升高 |
| 中位股大亏，但龙头继续上涨 | 核心抱团，主升质量下降 |
| 中位股止跌、低位补涨恢复 | 分歧后结构可能修复 |
| 亏钱效应从中位向高位扩散 | 退潮正在加速 |

中位股是识别情绪节点的重要先行指标。

很多时候，指数和龙头仍然强，但中位股已经率先退潮。此时市场表面热度仍高，内部风险却已经积累。

### 5. 回流时涨停反馈和市场广度是否同步改善

分歧之后出现龙头反弹，不等于主升确认。需要看回流是否具有扩散性。

主要看：

- 昨日涨停股次日溢价是否提高；
- 上涨家数是否增加；
- 涨跌幅中位数是否改善；
- 板块涨停和首板数量是否恢复；
- 中军是否同步走强；
- 补涨股是否获得正反馈；
- 炸板股是否减少或得到修复。

#### 能得到什么信息

| 回流结构 | 判断 |
|-|-|
| 龙头、中军、补涨共同走强 | 主线结构恢复 |
| 市场广度和涨停反馈同步改善 | 风险偏好重新扩张 |
| 只有龙头反弹，其他个股继续下跌 | 局部抱团，不是主升确认 |
| 板块上涨，但涨停溢价仍差 | 当日回流质量一般 |
| 回流后次日继续有承接 | 主升延续的可信度提高 |
| 回流当天冲高回落、次日低开 | 回流失败，退潮风险增加 |

主升确认需要同时看到：

> **核心修复＋中军承接＋板块宽度恢复＋市场赚钱效应改善。**

## 五、如何区分健康分歧和退潮开始

| 观察维度 | 健康分歧 | 退潮开始 |
|-|-|-|
| 龙头 | 未破关键结构，分歧后有承接 | 放量破位，无法快速修复 |
| 中军 | 缩量调整或放量换手后稳定 | 持续放量下跌 |
| 板块成交 | 未明显流失，回流时重新增加 | 持续流出并转向其他方向 |
| 中位股 | 个别淘汰，整体亏损可控 | 成批断板、跌停、次日继续大亏 |
| 低位股 | 有效补涨，结构保持完整 | 首板无溢价，补涨冲高回落 |
| 涨停反馈 | 平均值与中位数保持稳定 | 中位数转负，高开低走增加 |
| 炸板反馈 | 次日能够止跌或修复 | 次日继续低开低走 |
| 市场广度 | 分歧后重新改善 | 上涨集中在少数核心 |
| 次日表现 | 主线重新回流 | 弱势继续扩散 |

最关键的区别是：

> **健康分歧淘汰的是个别后排，退潮伤害的是一整个层级，并逐步从后排向核心传导。**

---

## 六、还要识别两个风险节点

除了冰点转强和回调确认主升，还应关注高潮转弱与修复失败。

### 1. 高潮转弱

可能出现：

- 涨停数量仍多，但炸板率上升；
- 昨日涨停平均值为正，中位数却开始下降；
- 中位股率先出现大亏；
- 高位核心放量滞涨；
- 板块扩散到低质量补涨；
- 成交额增加，但价格推进效率下降；
- 后排股票冲高回落增多。

#### 能得到什么信息

说明市场看起来仍热，但新增资金的接力效率开始下降。赚钱效应正在由普遍扩散转为集中在少数核心。

这不是立即确认退潮，但代表：

- 风险收益比开始恶化；
- 不宜继续无差别追涨；
- 应重点观察次日中位股、炸板股和核心承接。

### 2. 修复失败

可能出现：

- 冰点后单日普涨；
- 次日昨日涨停溢价重新转负；
- 炸板股继续大亏；
- 上涨家数迅速收缩；
- 新方向没有持续成交；
- 龙头冲高回落；
- 中位股重新出现集中亏钱。

#### 能得到什么信息

说明前一日更可能是：

- 超跌反弹；
- 空头回补；
- 单日情绪脉冲；
- 退潮过程中的弱修复。

此时不能继续按“新周期启动”的预期交易，应重新降低仓位。

---

## 七、最实用的节点确认方法

每天按照以下顺序检查。

### 第一步：看亏钱效应

检查：

- 跌停是否扩大；
- 炸板股是否继续大亏；
- 中位股是否集中断板；
- 高位核心是否补跌。

回答：**退潮还在继续，还是已经开始收敛？**

### 第二步：看成功者的反馈

检查：

- 昨日涨停平均溢价；
- 昨日涨停中位数；
- 高开后能否继续上涨；
- 低开后能否修复。

回答：**接力资金是否重新赚钱？**

### 第三步：看修复是否扩散

检查：

- 上涨家数；
- 涨跌幅中位数；
- 首板数量；
- 板块宽度；
- 龙头、中军、补涨是否联动。

回答：**是少数核心自救，还是市场整体风险偏好改善？**

### 第四步：看资金是否选择出主线

检查：

- 是否连续获得成交额；
- 分歧后能否回流；
- 核心股是否有承接；
- 是否连续两天保持相对强度。

回答：**这次修复有没有可以承载资金的方向？**

### 第五步：等待次日确认

检查：

- 修复是否持续；
- 弱势是否迅速回归；
- 追涨资金是否继续赚钱；
- 失败样本是否重新恶化；
- 主线是否还有承接。

回答：**节点是真切换，还是单日波动？**

## 八、盘后记录模板

> 今日情绪原状态为\_\_\_\_，可能出现从\_\_\_\_向\_\_\_\_转换的节点。  
> 亏钱效应方面，跌停数量\_\_\_\_，炸板股次日反馈\_\_\_\_，中位股表现\_\_\_\_，高位核心\_\_\_\_，说明风险正在\_\_\_\_。  
> 正反馈方面，昨日涨停股平均溢价\_\_\_\_、中位数\_\_\_\_，低开修复能力\_\_\_\_，说明接力资金\_\_\_\_。  
> 市场广度方面，上涨家数\_\_\_\_，涨跌幅中位数\_\_\_\_，赚钱效应呈现\_\_\_\_。  
> 主线方面，**方向获得\_\_\_\_成交支持，龙头**、中军\_\_\_\_、补涨\_\_\_\_，分歧承接\_\_\_\_。  
> 综合判断，当前可能处于 **冰点转强／修复失败／回调确认主升／高潮转弱／退潮加速** 节点，置信度为\_\_\_\_。下一交易日重点确认\_\_\_\_。

置信度可以这样划分：

- **高**：亏钱效应、涨停反馈、市场广度和主线资金四层证据一致，且已经得到次日确认；
- **中**：当天出现三层以上改善，但尚缺次日持续性；
- **低**：主要依据指数大涨、单只龙头反包或单个板块脉冲。

最重要的两句话是：

> **冰点转强的第一证据不是大涨，而是亏钱效应停止扩散；最终确认则是正反馈扩散并延续到次日。**

> **回调确认主升，不是看龙头有没有反弹，而是看龙头、中军、板块成交、中位股和市场广度能否共同修复。**
