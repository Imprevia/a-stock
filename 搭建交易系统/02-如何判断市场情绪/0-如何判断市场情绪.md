# 如何判断市场情绪

判断“情绪”，本质上是在判断三件事：

1. 资金是否愿意进场；
2. 追涨是否得到正反馈；
3. 分歧后是否有人承接。

不能由单个指标下结论，最好按“环境 → 赚钱效应 → 亏钱效应 → 主线结构 → 次日确认”逐层判断。



#### 一、先看五个维度

| 维度 | 偏强信号 | 偏弱信号 |
|-|-|-|
| 成交额与广度 | 放量上涨、上涨家数扩散、多数板块参与 | 缩量、上涨集中于少数权重、大多数个股下跌 |
| 涨停反馈 | 昨日涨停次日平均值和中位数为正，低开股能修复 | 高开低走、平均值被少数强股拉高、中位数为负 |
| 炸板修复 | 炸板股次日止跌、反包或明显减亏 | 炸板后继续低开低走，失败样本亏损扩大 |
| 梯队与亏钱效应 | 首板、二板、中高位层次完整，晋级率改善 | 中位股断层、跌停集中、高位核心补跌 |
| 主线结构 | 板块持续放量，龙头、中军、补涨共同活跃 | 只靠单一个股，轮动过快，次日没有资金承接 |

尤其要看“中位数”和失败样本。

平均溢价为正但中位数为负，通常说明赚钱效应只集中在极少数核心股，整体情绪并不健康。

#### 二、把市场划分为四种状态

##### 1. 冰点或退潮

特征包括：

- 成交低迷；
- 市场广度较差；
- 跌停数量增加；
- 炸板股继续亏损；
- 连板梯队断裂；
- 高位核心补跌。

此时即使指数上涨，也可能只是权重护盘，不能视为情绪回暖。

##### 2. 冰点修复

特征包括：

- 强势股率先止跌；
- 昨日涨停溢价改善；
- 炸板股不再持续杀跌；
- 上涨家数增加；
- 但成交额和主线结构尚未完全确认。

这个阶段只能称为“修复尝试”，不能直接认定新周期开始。

##### 3. 上升或主升

特征包括：

- 成交额连续活跃；
- 市场广度扩大；
- 涨停溢价持续为正；
- 连板梯队完整；
- 主线经历分歧后能够回流。

关键是这些信号至少持续两天，而不是单日高潮。

##### 4. 高潮分歧或退潮前兆

指数和涨停数量可能仍然很强，但同时出现：

- 炸板率上升；
- 中位股开始大亏；
- 高位核心放量滞涨；
- 板块扩散到低质量补涨。

此时市场“看起来最热”，风险往往也开始累积。

#### 三、识别情绪节点

##### 冰点转强

不能只看“今天大涨”，至少要看到：

- 亏钱效应停止扩散；
- 昨日涨停股次日反馈改善；
- 炸板股出现修复；
- 上涨广度扩大；
- 核心方向获得成交额支持；
- 次日没有迅速回到弱势状态。

##### 回调确认主升

需要观察分歧之后：

- 龙头没有结构性破位；
- 中军没有持续放量下跌；
- 板块成交额没有明显流失；
- 中位股没有集中跌停；
- 回流时涨停反馈和市场广度同步改善。

只有核心股反弹、其他个股继续走弱，通常只是局部抱团，不是主升确认。

#### 四、判断新旧热点切换

真正的热点切换需要同时满足：

- 新方向连续获得成交额；
- 强势从龙头扩散到中军、首板和补涨；
- 分歧后能够回流；
- 次日追涨资金获得正反馈；
- 旧方向成交额和赚钱效应同步下降。

如果新热点只有一日爆发，旧热点只是暂时休息，更可能是轮动而非切换。

新旧方向都没有持续反馈时，应定义为“混沌”，而不是强行选出主线。

#### 五、一个简单的每日评分方法

每项按 `-1、0、+1` 评分：

- 成交额与市场广度；
- 昨日涨停溢价；
- 炸板修复；
- 连板梯队；
- 跌停和高位亏钱效应；
- 主线持续性；
- 次日反馈。

总分可以辅助分类：

| 总分 | 情绪判断 |
|-|-|
| `+4` 以上 | 情绪偏强，但要检查是否处于高位高潮 |
| `+1` 到 `+3` | 修复或结构性活跃 |
| `-1` 到 `0` | 混沌、分歧 |
| `-2` 以下 | 退潮或冰点 |

分数不能替代结构判断。

最重要的是看变化方向。例如：

`-5 → -2 → +1`

这通常比一直维持在 `+2` 更能说明情绪正在转强。

#### 六、每日情绪结论模板

可以用下面的句式概括每日情绪：

> 当前处于“退潮/修复/上升/高潮分歧”阶段；主要依据是赚钱效应、亏钱效应和主线承接；下一交易日重点观察哪些信号来确认或证伪。

这样可以避免先给市场贴标签，再选择性寻找证据。
