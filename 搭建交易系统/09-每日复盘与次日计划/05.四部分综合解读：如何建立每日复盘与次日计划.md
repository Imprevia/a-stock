# 5.四部分综合解读：如何建立每日复盘与次日计划

每日复盘与次日计划的本质，是把盘后的事实整理为次日可验证的条件，并把每笔交易的经验沉淀为系统改进，而不是用一份复盘去预测明天必涨必跌。

## 一、四部分分别解决什么问题

| 模块 | 解决的问题 | 核心产出 |
|-|-|-|
| 1. 三个核心动作 | 如何把当天交易转化为可改进经验？ | 现场还原、错误链条、具体行动 |
| 2. 市场复盘五步骤 | 如何从市场到个股建立次日背景？ | 市场状态、主线/风险方向、候选情景 |
| 3. 情绪与资金四视角 | 如何识别资金关注、情绪高度与风险扩散？ | 大成交额、连板、涨跌停、炸板率时间序列 |
| 4. 动态优化频率 | 如何避免情绪化改系统？ | 日记录、周汇总、样本后评估、版本管理 |

## 二、固定判断顺序

> **先还原真实交易 → 再判断市场环境 → 再识别主线与情绪结构 → 再筛选候选并写条件 → 最后把偏差归入系统迭代。**

每天复盘可以按以下顺序完成：

```text
1. 今日交易：当时的入场、失效、加减仓和情绪是什么？计划内还是计划外？
2. 市场状态：指数、成交额、趋势位置和风格分化支持进攻、试错还是防守？
3. 板块与情绪：主线、轮动、退潮；大成交额、连板、涨跌停、炸板率怎样变化？
4. 消息核验：哪些是事实、哪些只是市场解读或传闻？
5. 候选剧本：每只标的的前提、触发、失效、风险/仓位与不交易情景是什么？
6. 系统记录：今天的偏差是否重复？是立刻修复执行，还是积累样本后再修改规则？
```

## 三、通过这些数据能得到什么

### 1. 得到“能否交易”的环境结论

指数位置、量能、市场广度、板块持续性和高位反馈共同决定环境属于进攻、试错、防守或空仓。个股机会必须服从这一背景，不能只看图形。

### 2. 得到“资金和情绪在哪”的结构结论

大成交额榜提供资金关注变化，连板与涨停潮衡量情绪高度和扩散，跌停与炸板揭示风险来源。四者必须结合时间序列和板块归属，而不是单看当天数量。

### 3. 得到“明天如何应对”的条件化剧本

次日计划不应写成预测，而应写成：若市场/板块满足前提且个股触发，则按预设风险参与；若跌破失效位、板块退潮或市场恶化，则减仓、观望或不交易。

### 4. 得到“系统该不该改”的证据

每日只记录事实和偏差；重复错误每周汇总；只有样本、期望、回撤、成本或市场机制证据足够时，才修改规则并标注新版本。

## 四、数据冲突时的优先级

- 个股强但市场环境明确防守时，市场与组合风险优先；
- 题材涨停多但高位断板、炸板与跌停扩散时，风险结构优先于表面热度；
- 盘后利好叙事与价格弱反馈冲突时，实际价格、成交和次日接受度优先；
- 单笔盈利与计划违规冲突时，合规性优先；
- 短期连亏与长期样本冲突时，先降风险、继续记录，不立即推翻系统。

## 五、盘后到次日的最小模板

```text
【今日事实】
- 市场状态：进攻 / 试错 / 防守 / 空仓
- 主线 / 轮动 / 风险方向：
- 情绪数据：涨停、跌停、炸板率、连板高度及变化：
- 今日交易：计划内 / 计划外；结果：___R；主要偏差：

【次日剧本】
- 进攻情景：触发条件 → 风险/仓位动作
- 中性情景：触发条件 → 观察或持有处理
- 防守情景：触发条件 → 减仓、退出或不交易
- 候选标的：市场前提 / 板块前提 / 入场触发 / 失效条件 / 不交易条件

【迭代记录】
- 重复错误或待验证假设：
- 本周统计项：
- 是否触发规则修改：否 / 是（版本号与证据）
```

## 六、结尾

完整的每日复盘与次日计划，不是每天寻找新的结论或快速更换系统，而是建立“事实—结构—剧本—反馈—迭代”的闭环：

> **用现场还原防止结果偏误，用市场与情绪数据确定可交易环境，用条件剧本替代盘中临时决策，用长期样本而非单日盈亏推动系统优化。**

当每一天都能留下可核验的事实、清晰的失效条件和具体的下一步行动，复盘才能逐渐转化为稳定的交易能力。

本文用于交易研究与复盘，不构成投资建议。
