# 1.复盘的三个核心动作

每日复盘的价值不在于事后解释涨跌，而在于把当天可见信息、真实决策和下一次具体改进连接起来。原文的三个核心动作是：还原现场、提取规律、迭代行动。

## 一、还原现场：只看当时能看到什么

| 记录项 | 要问的问题 | 能得到的信息 |
|-|-|-|
| 入场依据 | 是预设规则、盘中信号，还是主观感觉？ | 交易是否计划内 |
| 止损与止盈 | 到达条件时为何执行或未执行？ | 退出偏差来自规则还是情绪 |
| 加仓行为 | 是新证据增强，还是亏损摊低成本？ | 风险是否被错误扩大 |
| 当时市场/板块 | 当时指数、题材和情绪如何？ | 个股结果是否受环境影响 |

**关键原则：**不能把收盘后的新闻、后续走势或结果倒灌进当时决策。还原现场才能区分“合规但亏损”与“违规但赚钱”。

## 二、提取规律：从一次交易找到重复链条

不要只写“下次注意”。应把偏差写成因果链，例如：

```text
连续亏损 → 急于翻本 → 放大仓位 → 偏离模式 → 亏损扩大
```

当同一链条多次出现，才说明需要建立规则或调整流程；单笔结果本身不足以证明规律。

## 三、迭代行动：每个问题必须有动作

| 发现的问题 | 可执行动作 |
|-|-|
| 连亏后交易变形 | 连亏达到阈值，当天停止新开仓或降低风险 |
| 止损拖延 | 到失效位预设委托，盘中不临时修改 |
| 临时追逐标的 | 只加入观察池，次日满足条件才交易 |
| 同类错误反复 | 累计达到次数后暂停该模式并复查样本 |

## 四、最终能得到什么

- 判断亏损来自策略、市场环境还是执行偏差；
- 识别自己的高频错误和触发条件；
- 让复盘结论变成可验证的下一次行动；
- 防止“知道问题但重复犯”的空泛总结。

**结论：**每日复盘先还原、再归因、后行动。只有把错误转换成可执行约束，复盘才会真正改变下一笔交易。

本文用于交易研究与复盘，不构成投资建议。
