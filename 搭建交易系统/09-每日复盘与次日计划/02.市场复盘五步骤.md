# 2.市场复盘五步骤

市场复盘五步骤的作用是由外到内建立交易背景：先判断市场是否适合交易，再识别资金方向与情绪结构，最后为候选标的写出次日条件。

## 一、五步分别看什么

| 步骤 | 核心数据 | 能得到的信息 |
|-|-|-|
| 主要指数 | 涨跌、成交额、趋势位置、支撑压力、风格分化 | 市场属于进攻、试错、防守还是空仓环境 |
| 板块表现 | 涨幅、成交额增量、持续性、催化 | 主线、轮动与退潮方向 |
| 涨跌停结构 | 涨停/跌停数、连板梯队、一字板、炸板率、高位反馈 | 赚钱效应和亏钱效应扩散到哪里 |
| 新闻与公告 | 已核实事实、市场解读、传闻、影响层级 | 催化是短期情绪、行业供需还是长期价值变化 |
| 候选与情景 | 关注理由、市场/板块前提、触发、失效、仓位、不交易条件 | 次日不靠临场猜测的行动剧本 |

## 二、组合后怎么看

- 指数走强但成交不足、板块没有持续性，通常只能说明修复或试错，不能直接等同于全面进攻。
- 板块涨幅靠少数个股、炸板率高或高位反馈弱，应警惕表面热度下的分歧。
- 新闻先分事实与解读；没有可核实来源的传闻不能成为仓位依据。
- 候选股必须服从市场和板块前提。个股图形再好，若大环境或板块逻辑失效，也应保留不交易情景。

## 三、次日计划最小模板

```text
市场状态：进攻 / 试错 / 防守 / 空仓
主线与退潮方向：
候选标的：
必须满足的市场与板块条件：
入场触发：
失效条件：
计划风险/仓位：
不交易情景：
```

**结论：**五步骤不是预测次日涨跌，而是把市场背景、情绪、催化和个股计划统一成条件化决策。

本文用于交易研究与复盘，不构成投资建议。
