# 7.基本面筛选的补充说明

> 基本面筛选的作用，是把大量公司缩小为“值得继续研究”的候选集，而不是仅凭几个财务比率直接得出买卖结论。连续多年较高的 ROE、低于行业均值的估值和健康的现金流，可以作为初筛线索；但每一项指标都可能由不可持续因素造成，因此必须拆解来源、比较历史与同业、核对公告，并结合风险提示形成完整证据链。

## 一、先明确：筛选指标回答什么问题

基本面筛选通常围绕三个问题展开：

1. **公司是否持续创造了较高的股东回报？** 主要观察 ROE，并进一步判断回报来自盈利能力、经营效率还是财务杠杆。
2. **当前价格是否已经充分反映公司的质量与风险？** 主要使用 PE、PB 等估值指标，同时进行纵向历史比较和横向同业比较。
3. **账面利润是否真正转化为现金？** 主要分析经营、投资、融资三类现金流，并将经营现金流与净利润交叉验证。

这三类指标不能彼此替代：高 ROE 不代表估值便宜，低估值不代表公司优质，经营现金流为正也不一定意味着公司没有资本开支或偿债压力。更可靠的方法是寻找相互支持的组合证据。

## 二、ROE：看回报水平，更要看回报来源

### 1. ROE 的含义

净资产收益率（ROE）衡量公司使用股东权益创造净利润的效率：

[  
ROE=\frac{归属于普通股股东的净利润}{平均归属于普通股股东的净资产}  
]

其中，平均净资产通常取期初与期末净资产的平均值。分析时应尽量保持口径一致，并注意区分加权平均 ROE、摊薄 ROE，以及是否扣除非经常性损益。

ROE 较高通常意味着股东资本回报较好，但“高”本身并不说明回报可持续。至少应观察一个完整行业周期，或者连续 3—5 年的数据，而不能只看单一年度。

### 2. 连续多年高 ROE 应怎么看

重点观察以下四点：

- **水平**：ROE 是否长期高于行业中位数和公司的资本成本。
- **稳定性**：年度波动是否过大，是否只在某一景气高点突然上升。
- **口径**：扣非 ROE 是否同样较高，归母净利润是否被一次性收益抬升。
- **趋势**：ROE 是稳定、改善还是持续下降；下降源于利润率、周转率还是杠杆变化。

建议同时记录 ROE 均值、最低值和波动幅度。相比“某一年达到 25%”，连续多年维持在合理水平且波动较小，通常更能说明商业模式具有韧性。

### 3. 用杜邦分析拆解 ROE

经典三因素杜邦公式为：

[  
ROE=销售净利率\times总资产周转率\times权益乘数  
]

其中：

- **销售净利率 = 净利润 ÷ 营业收入**：反映每一元收入能够留下多少利润，主要受产品竞争力、成本控制、费用率和税率影响。
- **总资产周转率 = 营业收入 ÷ 平均总资产**：反映资产的运营效率。零售、制造等行业常需要重点观察存货和应收账款周转。
- **权益乘数 = 平均总资产 ÷ 平均净资产**：反映财务杠杆。权益乘数越高，负债对 ROE 的放大作用通常越强，风险也可能越高。

进一步拆解时，还可把净利率分为营业利润率、利息负担和税负因素，以识别盈利变化究竟来自主营经营、融资成本还是所得税波动。

| ROE 来源 | 可能的积极解释 | 需要核查的风险 |
|-|-|-|
| 高净利率 | 品牌、专利、成本优势、议价权强 | 一次性提价、原料价格低点、补贴或资产处置收益 |
| 高资产周转率 | 轻资产、高运营效率、供应链能力强 | 过度压库存、应付账款拉长、资本开支不足 |
| 高权益乘数 | 适度负债提高资本效率 | 偿债压力、利率敏感、表外负债、周期下行时亏损放大 |

### 4. 高 ROE 的常见“假象”

- **杠杆驱动**：利润率和周转率普通，但大量负债或回购导致净资产较小，从而抬高 ROE。
- **周期高点**：商品价格、运价或供需缺口暂时推高利润，不能线性外推。
- **一次性收益**：处置资产、政府补助、公允价值变动或债务重组收益推高净利润。
- **净资产基数异常**：历史亏损、巨额分红或大规模回购使净资产偏低。
- **会计确认差异**：收入提前确认、费用资本化、信用减值计提不足等，可能使当期利润偏高。

因此，高 ROE 公司至少还要核查资产负债率、有息负债、利息保障倍数、扣非净利润、应收与存货变化，以及现金流转化情况。

## 三、估值：低于行业均值只是起点

### 1. PE 与 PB 分别说明什么

市盈率（PE）衡量市值相对于盈利的倍数：

[  
PE=\frac{总市值}{归母净利润}=\frac{股价}{每股收益}  
]

常见口径包括静态 PE、滚动 PE（TTM）和预测 PE。比较时必须使用相同口径。PE 更适合盈利相对稳定、净利润为正的企业；亏损公司、利润剧烈波动的周期公司，PE 的解释力会显著下降。

市净率（PB）衡量市值相对于净资产的倍数：

[  
PB=\frac{总市值}{归属于母公司股东的净资产}=\frac{股价}{每股净资产}  
]

PB 常用于银行、保险、证券、地产及部分重资产行业，但前提是账面资产可核实、减值较充分。对品牌、软件、平台等无形资产占比较高的轻资产公司，账面净资产可能无法完整反映其经济价值。

### 2. 横向比较：与谁比

横向比较不能只看宽泛行业平均数，应尽量选择商业模式、收入结构、发展阶段和会计口径相近的公司。建议：

- 优先使用**行业中位数**，避免极端值扭曲平均数；
- 区分龙头、成长型公司、成熟公司和困境公司；
- 对比 ROE、增长率、毛利率、负债率等质量差异；
- 剔除亏损导致 PE 无意义的样本，并注明样本范围和估值日期；
- 对跨市场公司，考虑利率、流动性、治理和投资者结构差异。

估值低于同业，可能代表市场错估，也可能是市场正在为较低增长、较差治理、更高负债或更弱资产质量折价。

### 3. 纵向比较：与公司自己的历史比

观察当前 PE、PB 在过去 3—10 年或一个完整周期中的位置，例如历史分位数、中位数和极值。纵向比较时要同步判断公司的基本面是否发生变化：

- 盈利增速是否从高增长进入成熟期；
- 盈利能力和资本回报率是否永久下降；
- 商业模式、竞争格局或监管环境是否改变；
- 股本、会计准则和重大资产重组是否破坏历史可比性；
- 当前盈利是否处于周期顶部或底部。

“低于历史均值”只有在盈利质量、竞争优势和长期前景没有明显恶化时，才可能构成低估线索。

### 4. 低 PE、低 PB 的两种解释

| 现象 | 潜在低估解释 | 潜在价值陷阱解释 |
|-|-|-|
| 低 PE | 盈利稳定，市场情绪短期悲观 | 盈利位于周期顶部，未来利润将下降 |
| 低 PB | 资产被低估，ROE 有改善空间 | 资产减值不足、坏账或存货风险高 |
| 低估值且高股息 | 现金流充足、分红能力稳定 | 高分红不可持续，依赖举债或减少投资 |
| 估值低于同行 | 市场关注度低或短期事件错杀 | 治理、增长、负债或业务质量更差 |

判断时可结合预期盈利增长、自由现金流收益率、股息率、ROIC 等指标。不要把“价格便宜”和“价值被低估”视为同义词。

## 四、现金流：验证利润质量与资金安全

### 1. 三类现金流分别反映什么

现金流量表分为三部分：

- **经营活动现金流**：主营业务产生和消耗的现金，包括销售回款、采购付款、职工薪酬和税费等。它是验证利润含金量的核心。
- **投资活动现金流**：购建或处置长期资产、对外投资及其收回等。负值不必然是坏事，可能代表扩产或长期投入；关键是项目回报和资金来源。
- **融资活动现金流**：借款、还债、增发、回购、分红等。它揭示公司依赖外部融资的程度及资本分配方式。

三者必须联读。例如，经营现金流不足、投资现金流持续大额流出、融资现金流持续流入，可能意味着公司扩张依赖借款或增发；经营现金流稳定流入、投资支出可控、融资现金流因还债和分红流出，则通常更稳健。

### 2. 经营现金流与净利润交叉验证

常用指标包括：

[  
净现比=经营活动产生的现金流量净额\div净利润  
]

长期看，净现比接近或高于 1 通常表明利润现金含量较好，但单年数值受营运资金季节性影响，不能机械使用。应观察 3—5 年累计经营现金流与累计净利润的匹配程度。

若净利润持续增长而经营现金流明显落后，应检查：

- 应收账款、合同资产或票据是否快速增加；
- 存货是否积压、跌价准备是否充分；
- 应付账款是否被主动压降，或公司是否失去供应商信用；
- 预收款、合同负债是否变化；
- 收入确认政策是否激进；
- 税费、奖金、采购款等是否因结算时点造成暂时差异。

经营现金流好于净利润也不必然是永久优势，可能来自延长付款周期、一次性收回应收款或增加预收款，应判断其可持续性。

### 3. 自由现金流与资本开支

可用简化口径观察自由现金流：

[  
自由现金流\approx经营活动现金流净额-资本性支出  
]

自由现金流反映公司在维持和扩展经营后，可用于还债、分红、回购或再投资的现金。分析时应区分：

- **维持性资本开支**：保持现有产能和竞争力所必需；
- **扩张性资本开支**：用于新增产能或新业务，未来回报存在不确定性。

对于快速成长或重资产公司，自由现金流短期为负未必异常；但应确认新增投资能否带来合理回报、在建工程是否按期转固、产能利用率是否支持扩张，以及融资期限是否与项目回收期匹配。

## 五、行业适配：不同商业模式不能套用同一阈值

统一设置“ROE 必须高于 15%、PE 必须低于 20 倍、经营现金流必须每年为正”等条件，容易误删优质公司或留下高风险公司。行业差异主要来自资产结构、收入确认方式、杠杆惯例和周期特征。

| 行业类型 | 分析重点 | 需要谨慎使用的指标 |
|-|-|-|
| 银行 | 净息差、不良率、拨备覆盖率、核心一级资本充足率 | 普通企业口径经营现金流、资产负债率 |
| 保险 | 新业务价值、内含价值、偿付能力、投资收益质量 | 单年 PE、普通 PB 横比 |
| 地产 | 合同负债、销售回款、净负债率、存货减值、债务期限 | 单年经营现金流、未调整 PB |
| 制造业 | 毛利率、产能利用率、存货、应收、资本开支、ROIC | 忽略周期位置的 PE |
| 消费品 | 品牌与渠道、同店增长、预收款、库存周转、现金转化 | 只凭低 PB 判断便宜 |
| 软件与互联网 | 续费率、客户获取成本、研发投入、递延收入、股权激励 | 早期公司的 PE、PB |
| 公用事业 | 特许经营、监管定价、负债成本、资本开支、股息覆盖 | 只看高杠杆得出负面结论 |
| 资源与航运等周期行业 | 产品价格、成本曲线、产能周期、资产负债表韧性 | 周期顶部的低 PE |

实际筛选时，应先建立行业内可比口径，再确定阈值。阈值应来自同业分布、公司历史和周期位置，而非脱离场景的固定数字。

## 六、组合证据：把指标串成可验证的研究假设

单个数字只能提供线索，组合证据才能提高可信度。可将候选公司分为以下几类：

### 1. 较强的正向组合

- 连续多年 ROE 较高且波动可控；
- 杜邦拆解显示主要由净利率或周转效率驱动，而非杠杆持续上升；
- 扣非净利润与归母净利润差异较小；
- 多年累计经营现金流与累计净利润匹配；
- 估值低于自身合理历史区间或可比公司，但基本面未明显恶化；
- 资产负债表稳健，短期偿债和资本开支可覆盖。

这组证据可形成假设：“公司经营质量较好，当前估值可能未充分反映其可持续盈利能力。”随后仍需通过年报、公告、行业数据和管理层行为验证。

### 2. 需要警惕的冲突组合

- 高 ROE + 高杠杆 + 利息保障倍数下降；
- 低 PE + 盈利处于周期高位 + 产品价格开始回落；
- 低 PB + 应收、存货或商誉占比高 + 减值计提偏弱；
- 净利润增长 + 经营现金流持续下降；
- 高股息 + 自由现金流不足 + 有息负债增加；
- 收入高增长 + 应收或合同资产增长更快；
- 大额资本开支 + 产能利用率下降 + 在建工程长期不转固。

冲突不等于立即排除，但意味着应提高验证强度、降低初始置信度，并明确可能推翻假设的证据。

## 七、可执行的筛选流程

### 第一步：限定样本与统一口径

确定市场、行业、规模、上市年限、财务数据截止日和可比公司范围。统一使用同一财务期间和估值口径，避免把年报数据、单季数据和预测数据混在一起。

### 第二步：做基础财务初筛

可根据行业特点设置宽松条件，例如：

- 过去 3—5 年 ROE 多数年份高于行业中位数；
- 盈利不是主要依赖非经常性损益；
- 多年累计经营现金流与累计净利润大致匹配；
- 杠杆和偿债指标没有明显恶化；
- PE、PB 或自由现金流收益率处于自身历史及同业相对合理区间。

初筛宜“宽进”，避免使用精确但缺乏行业依据的硬阈值。

### 第三步：拆解驱动因素

对 ROE 做杜邦拆解，对利润增长拆分为销量、价格、成本、费用、税率和一次性项目；对现金流拆分营运资金、资本开支和融资来源；对估值差异拆分成长、质量、风险与流动性因素。

### 第四步：进行横向与纵向比较

同时比较：

- 公司当前与自身历史；
- 公司与直接可比企业；
- 公司与行业周期位置；
- 实际结果与管理层过去指引或市场预期。

如果公司估值明显低于同行，应写出至少两种竞争性解释：“市场错估”与“风险折价”，并分别寻找证据。

### 第五步：核对原始披露

至少阅读最近一期年报、审计报告、财务报表附注和重大公告，重点核对：

- 收入确认、关联交易和客户集中度；
- 应收账款、存货、商誉和长期资产减值；
- 有息负债、担保、抵押、诉讼和或有事项；
- 非经常性损益、政府补助和公允价值变动；
- 审计意见、关键审计事项和会计政策变更；
- 股东减持、股权质押、再融资、回购与分红。

### 第六步：形成结论与触发条件

结论不只写“通过”或“不通过”，而应记录：

- 当前研究假设；
- 支持与反对证据；
- 尚未解决的问题；
- 需要持续跟踪的指标；
- 哪些事件会增强或推翻假设。

| 融资与偿债 | 有息负债、利息保障倍数、到期结构 |  |  |  |  |
| 估值 | PE、PB、历史分位、同业中位数 |  |  |  |  |
| 治理与风险 | 关联交易、质押、减持、审计意见 |  |  |  |  |
| 研究结论 | 核心假设、反方证据、触发条件 |  |  |  |  |

建议保留每次更新的日期和原始数据来源，不覆盖旧判断。这样既能避免“事后解释”，也方便评估筛选规则是否真正有效。

## 九、需要优先排查的红旗

出现以下情况时，应暂停仅凭指标得出的乐观结论，并深入核查：

1. 净利润连续增长，但经营现金流长期显著低于净利润。
2. 应收账款、合同资产或存货增速持续高于收入增速。
3. ROE 上升主要由权益乘数提高或净资产下降造成。
4. 非经常性损益占净利润比例过高，扣非后盈利明显恶化。
5. 低 PE 恰逢行业景气和利润率的历史高位。
6. 低 PB 同时伴随商誉、存货、应收或长期股权投资占比过高。
7. 频繁变更审计机构、出现非标准审计意见或关键审计事项异常集中。
8. 大股东高比例质押、频繁减持，或关联交易规模异常。
9. 短债快速增长，而货币资金受限、经营现金流不足。
10. 分红或回购规模超过自由现金流，并依赖新增融资维持。
11. 大额并购后商誉高企，承诺业绩与现金回款不匹配。
12. 会计政策或估计频繁调整，并显著改善当期利润。

红旗是进一步调查的入口，并非自动定罪。关键是判断其原因、持续时间、金额重要性及管理层是否充分披露。

## 十、使用边界与风险提示

- 财务报表反映的是历史结果，无法完整预测技术变化、监管调整、竞争加剧和宏观冲击。
- 估值取决于未来现金流和风险，历史低位并不保证未来回归均值。
- 财务数据可能受会计政策、估计变更、季节性、并购重组和合并范围变化影响。
- 行业景气、利率、汇率和商品价格变化，可能同时改变利润、资产质量与估值中枢。
- 量化筛选容易产生幸存者偏差、数据滞后和口径不一致，应保留原始来源并复核异常值。
- 公司公告、审计报告、监管问询、风险因素和重大事项披露，优先级高于二手数据平台的汇总指标。

基本面指标应被视为形成研究假设的工具，而不是替代公告阅读、商业分析和风险判断的结论机器。一个合格的筛选结果，应明确说明“为什么值得研究”“可能错在哪里”以及“什么证据会推翻当前判断”。只有在指标、业务、行业、治理和现金流相互印证时，筛选结论才具有较高参考价值。
