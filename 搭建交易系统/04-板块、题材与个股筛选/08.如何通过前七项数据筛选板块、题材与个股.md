# 8.如何通过前七项数据筛选板块、题材与个股

> **核心结论：**前七节不是七套彼此独立的选股方法，而是一条从“大方向”逐层收缩到“具体标的”的证据链：**板块筛选负责找资金方向，大成交额榜负责验证真金白银和识别资金角色，龙头六特征负责确认核心，异动资金规则负责建立广义候选池，放量长上影与“一进二”负责把候选分成不同交易模式，基本面筛选负责排雷并判断逻辑能否延续。**
> 
> 最终目标不是选出“今天涨得最好的股票”，而是形成一份可验证的结果：**1—3个重点板块、每个板块1—2条核心题材、每条题材中的核心/中军/候选股，以及每个候选的确认条件和失效条件。**

## 一、先明确七类数据各自解决什么问题

| 环节 | 主要解决的问题 | 应得到的输出 |
|-|-|-|
| 1.板块筛选 | 资金主要去了哪里，方向是否具有持续性 | 主线候选、次主线、脉冲方向、退潮方向 |
| 2.大成交额榜 | 是否有真实资金参与，资金集中在哪些股票 | 新进榜标的、容量中军、活跃核心、兑现风险股 |
| 3.龙头六个观察特征 | 谁真正代表题材，谁只是跟随 | 趋势龙、连板龙、套利龙及龙头置信度 |
| 4.异动资金候选规则 | 哪些股票近期留下了可验证的资金痕迹 | A/B/C级广义观察池 |
| 5.放量长上影候选模式 | 压力位放量分歧后，是试盘换手还是派发 | 结构型候选、观察期限、突破确认与失效位 |
| 6.“一进二”候选模式 | 首板后下一交易日是否具备接力观察价值 | 严格一进二、五日强势候选、放弃名单 |
| 7.基本面筛选 | 公司质量、估值和现金流是否支持逻辑，是否存在硬伤 | 基本面通过、待核验、风险降级或排除 |

这七类数据的关系可以概括为：

```text
板块定方向
↓
题材找共同催化与内部梯队
↓
大成交额榜验证资金规模并识别核心角色
↓
龙头六特征确认谁最有代表性
↓
异动资金规则建立候选池
↓
按放量长上影 / 一进二 / 趋势延续等模式分组
↓
基本面排雷与逻辑验证
↓
写出确认条件、失效条件和观察优先级
```

## 二、第一层：先筛板块，不要从单只股票倒推主线

### 1.先建立板块初选池

每天先从行业板块和题材板块中，找出同时具备以下证据的方向：

- 涨幅或相对大盘超额收益靠前；
- 上涨家数占比较高，涨跌幅中位数为正；
- 成交额较昨日、近5日均额明显增加；
- 涨停数量、连板梯队或容量股表现较好；
- 近3—5日资金和成交额具有持续性；
- 存在可核验的政策、产业、业绩或事件催化。

不能只看板块涨幅。板块指数上涨但多数成分股下跌，可能只是权重拉升；涨停很多但成交额没有明显增量，可能只是小市值情绪脉冲；成交额暴增但板块冲高回落，则可能是高位兑现。

### 2.把板块分成四类

| 分类 | 典型数据 | 处理方式 |
|-|-|-|
| **主线候选** | 涨幅强、覆盖广、成交额增量大、梯队完整、连续活跃、有催化 | 进入重点研究，继续筛题材和核心股 |
| **次主线/轮动候选** | 有资金、有催化，但持续性或内部结构稍弱 | 保留观察，等待次日强化或回流 |
| **短线脉冲** | 首日异动明显，但覆盖窄、持续性未知或只有小票涨停 | 仅作为事件候选，不按主线处理 |
| **退潮/回避方向** | 放量下跌、核心补跌、成交额衰减、梯队负反馈扩大 | 降低优先级，不因个别反抽重新看强 |

### 3.板块筛选的最终要求

板块进入下一层前，至少要回答：

1. 为什么涨：政策、产业、业绩还是纯情绪；
2. 谁在涨：多数成分股、少数权重还是小市值票；
3. 钱是否进入：成交额和大单活跃度是否增加；
4. 能否持续：首日脉冲还是连续活跃、分歧后回流；
5. 当前阶段：启动、确认、强化、分歧、回流还是退潮。

如果这五个问题无法回答，就只能列为“待核验方向”，不能直接进入核心池。

## 三、第二层：从板块中提炼真正的题材

行业板块告诉我们资金的大方向，题材则解释资金正在交易哪一条具体逻辑。筛题材时，不能只依赖行情软件的概念标签，应建立三类共振：

### 1.共同催化

同一批股票是否受同一项政策、产品、涨价、订单、技术突破、业绩变化或突发事件影响。催化必须尽量来自正式公告、政策原文、行业数据等可核验来源。

### 2.共同资金行为

同题材是否出现：

- 多只股票共同进入成交额增量榜；
- 龙头、容量中军和低位补涨同步活跃；
- 涨停或连板形成梯队；
- 板块分歧时核心抗跌，回流时核心率先修复；
- 资金并非只集中在一只孤立个股。

### 3.共同价格反馈

题材内多数股票是否有正向反馈，昨日涨停股是否有溢价，跟风股是否仍有承接。如果只有一只股票走强、其余股票不跟，优先解释为个股公告、独立行情或抱团，而不是完整题材。

### 4.题材分级

- **核心题材**：催化清楚、资金聚集、内部梯队完整、连续活跃；
- **扩散题材**：由核心逻辑向上下游、补涨或同类公司扩散；
- **事件题材**：由单一消息驱动，持续性尚未确认；
- **伪题材**：只有标签重合，没有共同催化和资金联动。

每个重点板块只保留1—2条最能解释资金行为的题材，避免把一只股票的所有概念都当成上涨原因。

## 四、第三层：用大成交额榜验证资金，并识别个股角色

### 1.先看“集中出现”，再看单只股票

将成交额前20、前50或成交额增量榜按板块、题材归类：

- 同一方向多只股票集中进榜，说明资金可能在系统性选择该方向；
- 新方向集中进榜、原方向逐步退出，可能代表主线切换；
- 只有一只股票进榜，先按个股事件处理；
- 多只高位股巨额成交却冲高回落，可能意味着兑现从个股向板块扩散。

### 2.重点看“增量”，而不是只看绝对金额

常年位居成交额前列的股票，只能说明它流动性好、容量大。更有信息量的是：

- 首次进入大成交额榜；
- 排名较昨日快速上升；
- 成交额显著高于自身5日、20日均额；
- 连续多日保持较高成交；
- 放量后价格和板块得到正向确认。

### 3.结合涨跌幅和位置识别角色

| 数据组合 | 可能角色或含义 |
|-|-|
| 新进榜＋放量上涨＋板块联动 | 新方向启动候选或活跃核心 |
| 连续进榜＋趋势上涨＋回撤可控 | 容量中军或趋势龙候选 |
| 涨停＋带动同题材多股上涨 | 情绪龙或连板龙候选 |
| 巨额成交＋高位滞涨/冲高回落 | 高位分歧或兑现风险股 |
| 放量下跌＋核心补跌 | 板块退潮或资金撤离 |
| 个股巨额成交＋板块不跟 | 个股独立事件、抱团或资金博弈 |

大成交额榜的作用是**发现资金战场和关键角色**，不是按成交额从高到低买股票。

## 五、第四层：用龙头六特征确认谁是真正核心

对板块和题材中的领涨股，不按涨幅直接命名龙头，而是逐项验证：

1. **充分换手**：共识是否经过真实交易和分歧检验；
2. **辨识度高**：是否最早启动、反复被市场识别，并代表题材逻辑；
3. **带动性强**：走强后是否带动涨停、上涨家数、成交额和梯队扩散；
4. **抗跌性强**：指数或板块分歧时，是否相对抗跌且承接存在；
5. **走势独立**：是否持续跑赢板块和指数，而非被动跟涨；
6. **突破高度约束**：是否突破近期连板高度、趋势高点或市场空间限制，并得到后续反馈。

### 龙头判定的优先级

**带动性和分歧承接比单日涨幅更重要，持续性比一次封板更重要，板块回流时能否率先修复**比板块高潮时是否最强更重要。

可将候选核心分为：

- **趋势龙**：持续大成交额、趋势稳定、相对强度高、回撤可控；
- **连板龙**：高度领先、封板与换手质量较好、对情绪和梯队有明显带动；
- **套利龙/补涨核心**：围绕主龙逻辑出现，位置较低但依赖主线延续。

如果“辨识度高但不带板块”“高度高但跟风全部亏钱”“抗跌但板块持续退潮”，龙头假设都需要降级。

## 六、第五层：建立个股候选池，再按模式分组

### 1.先用异动资金规则建立广义候选池

候选至少应具备两类相互支持的证据，三类共振时优先级更高：

- **量价证据**：涨停、倍量、成交额排名跃升、平台突破；
- **结构证据**：异动后缩量回调、守住平台或异动K线关键位、底部反复承接；
- **相对强弱证据**：强于指数和同板块，分歧时抗跌、回流时领涨；
- **催化证据**：公告、政策、产业或业绩逻辑可以核验。

先排除位置无法判断、异动原因不明、流动性不足、重大风险难以评估的标的，再分级：

- **A级观察**：量价、结构、相对强弱、催化至少三项协调；
- **B级观察**：有一到两项积极证据，但还缺板块或后续结构确认；
- **C级备忘**：只有单次异动，位置偏高、原因不清或量价背离。

### 2.再把候选按交易逻辑分组

候选模式不能混在一起比较，因为持有周期、确认方法和失效条件不同。

#### A.放量长上影候选

更适合观察**关键压力位附近的筹码交换与后续结构**。先看位置，再看长上影和放量，最后看3—5日、最长10日的反馈。

升级条件包括：

- 长上影出现在平台上沿、前高或启动初期，而非连续加速高位；
- 回调缩量，未出现连续放量长阴；
- 守住候选K线低点、平台上沿等关键支撑；
- 后续重新放量并有效站上前高压力带；
- 板块和题材没有同步退潮。

若放量跌破支撑、连续重心下移、5—10日仍不能修复，则按失效处理。该模式要区分“试盘/换手”和“冲高派发”，不能看到长上影就假定为洗盘。

#### B.“一进二”候选

只适用于**首板后的下一交易日**，属于短周期接力观察。盘后先核验：

- 是否为本轮真正首板，而非高位反包或伪首板；
- 首板位置、封板时间、开板回封、成交和换手是否合理；
- 题材是否有梯队，个股处于核心、跟随还是补涨；
- 市值、流通盘和成交额是否匹配；
- 次日竞价、开盘承接、量价和板块反馈是否符合事前预期。

严格一进二的时间窗口只有下一交易日；未完成晋级后，不应继续用“一进二”名义解释。近五日有涨停但不属于严格首板次日的，应另列为“五日强势候选”“断板反包”或其他模式。

#### C.趋势/中军候选

大成交额榜中连续活跃、趋势上涨、回撤可控、板块地位稳定的股票，不必强行套用长上影或一进二。应按趋势龙或容量中军观察，重点看成交额持续性、均线和平台结构、板块强度、分歧承接与基本面逻辑。

## 七、第六层：用基本面做质量过滤，而不是代替择时

基本面筛选放在候选池形成之后，用于回答两个问题：

1. 这家公司是否真实受益于所选题材，逻辑能否由收入、利润和现金流验证；
2. 是否存在足以推翻技术和资金逻辑的财务、治理或估值风险。

### 1.优先验证的正向证据

- ROE连续多年较好，主要由净利率或周转效率驱动，而非杠杆上升；
- 扣非净利润与归母净利润差异不大；
- 多年累计经营现金流与累计净利润匹配；
- 应收、存货、合同资产没有持续异常增长；
- PE、PB或现金流估值处于自身历史和同业合理区间；
- 公司主营业务与题材逻辑真实相关，有订单、产品或业绩证据。

### 2.需要降级或排除的冲突证据

- 高ROE主要靠高杠杆或净资产异常偏低；
- 低PE出现在周期盈利顶部；
- 净利润增长但经营现金流长期落后；
- 应收、存货或合同资产增速显著高于收入；
- 大股东高比例质押、频繁减持、审计意见异常；
- 题材标签很热，但主营业务贡献很小或公司已明确澄清；
- 高位技术加速，同时估值、减持、解禁或业绩风险集中出现。

基本面良好不代表次日会涨，技术强势也不能消除财务风险。基本面主要决定**候选的质量、逻辑持久度和风险上限**，量价与市场反馈决定**当前是否仍值得跟踪**。

## 八、证据冲突时怎么处理

数据不可能永远同向。遇到冲突时，不要挑选对自己最有利的指标，应按以下优先级处理。

### 1.板块强、个股弱

板块可能仍是主线，但该股不是核心，或已经掉队。保留板块，降低个股等级，重新寻找龙头、中军或低位补涨。

### 2.个股强、板块弱

先按个股公告、独立行情或抱团处理。若没有明确独立催化，不把它上升为题材主线；板块持续退潮时，防止孤立强势股补跌。

### 3.成交额大、价格不强

低位可能是分歧吸筹，高位更可能是兑现。必须结合收盘位置、换手、次日反馈和板块联动，不能把“成交额大”解释成净流入。

### 4.龙头特征强、梯队变弱

说明资金可能只抱团核心。龙头仍可观察，但板块赚钱效应下降，不能按全面主升对待；若中位股批量负反馈，应提高退潮警惕。

### 5.技术和资金强、基本面有红旗

先核验公告和数据。硬性风险未消除前，降为事件型或短周期观察，必要时直接排除，不能用技术图形覆盖财务与治理风险。

### 6.基本面好、资金和价格不确认

说明公司可以进入中长期研究池，但尚未进入当前交易主线。不要因为“便宜、优质”就把它写成短线核心。

**冲突处理原则：宁可降级等待验证，也不要用主观叙事强行消除矛盾。**

## 九、最终怎样筛出板块、题材与个股

### 第一步：输出1—3个重点板块

每个板块必须写清：

- 当前分类：主线、次主线、脉冲或退潮；
- 核心证据：涨幅覆盖、成交额增量、涨停梯队、持续性、催化；
- 当前阶段：启动、确认、强化、分歧、回流或退潮；
- 次日确认和失效条件。

### 第二步：每个板块只保留1—2条核心题材

每条题材必须有：

- 共同催化；
- 至少两只以上股票的共同资金或价格反馈；
- 龙头、中军、补涨或跟随结构；
- 与其他相似概念的边界。

### 第三步：每条题材建立个股角色表

| 角色 | 筛选依据 | 观察重点 |
|-|-|-|
| 龙头 | 六特征中多数得到验证，带动和承接突出 | 分歧承接、回流修复、板块带动 |
| 容量中军 | 大成交额持续、流动性好、趋势稳定 | 成交额持续性、趋势和机构承接 |
| 补涨 | 逻辑同源、位置较低、资金开始扩散 | 是否由跟随升级为独立强势 |
| 异动候选 | 量价、结构、相对强弱或催化共振 | 3—10日结构验证 |
| 一进二候选 | 真首板、板块有梯队、首板质量较好 | 次日竞价、承接、晋级与失效 |
| 风险股 | 高位巨量滞涨、放量下跌、基本面红旗 | 是否出现兑现和风险扩散 |

### 第四步：给个股分级，而不是给出单一“买入名单”

- **核心观察**：板块、题材、资金、龙头地位和风险过滤大体同向；
- **条件观察**：方向成立，但个股仍缺量价、结构或次日确认；
- **模式候选**：只满足长上影、一进二或异动中的某一模式，等待专属条件；
- **备忘/排除**：逻辑冲突、流动性不足、位置过高、原因不明或风险红旗明显。

每只股票都必须同时写出“为什么入选”和“什么情况移除”。

## 十、建议使用的盘后综合筛选表

| 层级 | 字段 | 记录内容 |
|-|-|-|
| 市场环境 | 风险预算 | 进攻、防守或空仓环境；决定候选数量与优先级 |
| 板块 | 强度与阶段 | 涨幅覆盖、成交额增量、梯队、持续性、启动/分歧/退潮 |
| 题材 | 逻辑与共振 | 共同催化、共同资金行为、内部梯队、持续条件 |
| 个股角色 | 龙头/中军/补涨/跟随 | 六特征、大成交额、相对强弱、板块带动 |
| 资金异动 | 触发证据 | 涨停、倍量、进榜、突破、缩量回踩、底部承接 |
| 模式 | 候选类型 | 趋势龙、长上影、一进二、五日强势、其他 |
| 基本面 | 质量与风险 | ROE来源、现金流、估值、真实受益、治理红旗 |
| 结论 | 当前等级 | 核心观察、条件观察、模式候选、备忘/排除 |
| 次日剧本 | 确认条件 | 板块量能、核心反馈、关键价位、竞价与承接 |
| 风控 | 失效条件 | 破位、放量下跌、梯队瓦解、催化证伪、时间失效 |

## 十一、盘后固定执行顺序

```text
1.先看板块涨幅、覆盖率、成交额增量和涨停梯队
2.结合3—5日持续性与催化，选出1—3个方向
3.从大成交额榜找同方向的新进榜、增量榜和连续活跃股
4.识别题材中的龙头、容量中军、补涨和跟随
5.用龙头六特征验证核心地位
6.用异动资金规则建立A/B/C候选池
7.按趋势、放量长上影、一进二等模式分别归类
8.用基本面、公告、减持、解禁和流动性做风险过滤
9.处理互相冲突的证据，必要时降级而不是强行解释
10.为每个候选写清次日确认、失效和最长观察期限
```

## 十二、最后应该得到什么结果

完成整套筛选后，最终应得到五类信息：

1. **资金方向**：市场当前把主要成交和注意力放在哪些板块；
2. **核心题材**：板块上涨由哪条可核验逻辑驱动，是否形成多股共振；
3. **内部角色**：谁是趋势龙、连板龙、容量中军、补涨和跟随；
4. **候选模式**：每只股票属于趋势、异动、长上影、一进二还是仅作备忘；
5. **验证剧本**：次日什么条件出现才继续看强，什么条件出现必须降级或移除。

> **一句话总结：先用板块数据确定“去哪儿找”，再用大成交额和题材共振确定“钱是否真的来了”，用龙头六特征确定“谁是核心”，用异动与形态规则确定“怎么分类观察”，最后用基本面和失效条件确定“哪些值得留下、哪些必须排除”。**

以上流程只用于研究、筛选和盘后复盘，不构成任何买入、卖出或收益承诺。候选入池只是开始，后续仍须由市场、板块、量价和公司信息共同验证。
