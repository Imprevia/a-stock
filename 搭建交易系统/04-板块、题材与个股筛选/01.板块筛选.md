# 1.板块筛选



> **核心结论：**板块筛选不是简单寻找“今天涨幅第一的板块”，而是依次回答：**今天资金主要去了哪里？这是可持续的主线还是一天行情？板块内部哪些股票承担龙头、中军、补涨和跟随角色？**

复盘时应按 **涨幅、成交额增量、涨停数量、持续天数** 筛选板块，再检查上涨原因、内部结构和次日验证条件。

## 一、先区分行业板块和题材板块

### 1. 行业板块

行业板块按上市公司的主营业务归类，例如半导体、通信设备、电力、银行、汽车零部件和有色金属。其成分相对稳定，适合观察：

- 中期资金配置；
- 行业景气变化；
- 机构资金偏好；
- 产业趋势是否形成。

### 2. 题材或概念板块

题材板块按政策、事件、产品或市场叙事归类，例如算力、机器人、固态电池、低空经济、国企改革和并购重组。题材成分交叉较多、变化更快，适合观察：

- 短线资金聚集方向；
- 政策或事件催化；
- 市场情绪；
- 龙头与连板梯队。

一只股票可能同时属于多个题材。题材大涨时，要判断股票究竟由哪个逻辑驱动，不能只看概念标签。

## 二、板块筛选的四个核心数据怎么看

### 1. 板块涨幅：发现资金当天选择的方向

主要观察：

- 板块当日涨跌幅及全市场排名；
- 板块内上涨、下跌家数；
- 板块涨跌幅中位数；
- 板块相对大盘的超额收益；
- 是开盘即强还是盘中突然拉升；
- 收盘能否保持强势。

板块涨幅首先告诉我们：**当天哪些方向获得了市场的价格认可。**但涨幅不能单独使用。

| 表现 | 可能含义 |
|-|-|
| 板块涨幅高＋多数成分股上涨 | 上涨覆盖较广，板块强度相对真实 |
| 板块涨幅高＋只有少数权重股上涨 | 可能是权重拉升，板块赚钱效应一般 |
| 早盘强、尾盘仍强 | 资金承接较好，次日可继续观察 |
| 早盘冲高、尾盘明显回落 | 资金分歧加大，可能出现兑现 |
| 板块逆大盘上涨 | 相对强度高，可能存在独立催化 |
| 板块跟随大盘普涨 | 需要确认是否具备独立逻辑 |

因此，不能只看板块指数涨幅，还要同时看：**涨幅高不高、上涨覆盖广不广、相对大盘强不强、收盘能不能保住。**

### 2. 成交额增量：验证资金是否真正进入

主要观察：

- 板块当日成交额；
- 相对前一日增加多少；
- 相对近5日或近20日均额增加多少；
- 板块成交额占全市场成交额的比例；
- 成交额增量是否连续多日；
- 成交额集中在龙头，还是分布到多只股票。

成交额增量回答的是：**这个板块只是价格偶然上涨，还是确实吸引了更多资金参与？**

| 涨幅与成交额组合 | 可能含义 |
|-|-|
| 涨幅高＋成交额明显增加 | 资金关注度提升，值得进入候选方向 |
| 涨幅高＋成交额连续增加 | 有形成主线的可能 |
| 涨幅高＋成交额没有增加 | 可能抛压较轻，也可能缺乏增量资金 |
| 成交额增加＋涨幅不高 | 分歧较大，可能吸筹，也可能高位兑现 |
| 成交额暴增＋冲高回落 | 高位换手或兑现风险上升 |
| 下跌＋成交额明显增加 | 主动卖盘增强，资金可能撤离 |
| 回调＋成交额缩小 | 抛压可能减弱，等待后续重新放量转强 |

**成交额增加不等于净流入。**成交额只是买卖双方成交的总量；放量上涨说明当日买方相对占优，但高位放量也可能是筹码大规模交换甚至派发。

### 3. 涨停数量：观察资金聚集度和短线情绪

主要观察：

- 板块内涨停家数；
- 首板、二板、三板及以上分布；
- 涨停股占板块成分股的比例；
- 涨停是否集中于同一条细分逻辑；
- 是否有容量较大的股票同步走强；
- 炸板数量及炸板率；
- 昨日涨停股次日是否有溢价。

涨停数量回答的是：**短线资金是否在这个板块形成集中共识。**

| 涨停结构 | 可能含义 |
|-|-|
| 涨停多＋梯队完整＋容量股同步上涨 | 板块结构较强，可能成为主线 |
| 涨停多但全部为首板 | 可能处于启动期，也可能是一日事件脉冲 |
| 只有一只高位龙头涨停 | 可能是个股抱团，不代表整个板块强 |
| 龙头涨停但跟风股冲高回落 | 板块内部开始分化 |
| 涨停多但炸板率也高 | 情绪活跃但分歧较大 |
| 昨日涨停股次日普遍负反馈 | 板块追涨容错率下降 |
| 涨停向不同层次扩散 | 资金接力意愿较强 |
| 中位股批量掉队或跌停 | 板块可能由分歧进入退潮 |

不能只问“有几只涨停”，还要问：龙头是谁、有没有容量中军、有没有二板和三板梯队、跟风股有没有赚钱效应、炸板后能不能修复。

### 4. 持续天数：区分主线与一日游

主要观察：

- 板块进入涨幅前列多少天；
- 成交额持续增加多少天；
- 主力资金是连续流入还是只流入一天；
- 板块分歧后能否回流；
- 龙头和中军是否持续保持强势；
- 催化是否具有延续性；
- 板块是否反复出现新的补涨股。

持续天数回答的是：**资金是在形成稳定共识，还是借一个消息做短暂脉冲？**

| 阶段 | 数据特征 | 含义 |
|-|-|-|
| 初次异动 | 首日涨幅和成交额突然进入前列 | 发现新方向，但尚不能确认主线 |
| 次日确认 | 核心股有溢价、成交额维持、板块未全面回落 | 首日异动得到初步确认 |
| 持续强化 | 连续活跃、成交额持续、梯队扩散 | 主线概率提高 |
| 正常分歧 | 龙头分歧、跟风回落，但板块未全面破坏 | 观察能否出现资金回流 |
| 回流确认 | 分歧后重新放量，核心股率先走强 | 主线仍可能延续 |
| 退潮 | 成交额下降、核心补跌、跟风负反馈扩大 | 应降低关注等级和风险预算 |

“连续活跃三天以上”可作为主线参考，但不能把三天当成机械标准。关键是每天是否继续有资金参与、分歧后能否修复、内部梯队是否保持，以及催化逻辑是否仍然成立。

## 三、板块上涨的推动因素怎么看

### 1. 政策驱动

需要判断：

- 是正式落地还是市场预期；
- 政策覆盖整个行业还是只影响少数公司；
- 是否涉及真实订单、收入或利润；
- 政策是否具有连续落地空间；
- 当天上涨是否已经过度透支。

这些信息可以帮助区分长期政策方向、短期事件刺激、预期兑现，以及借政策名义炒作。

### 2. 产业驱动

例如产品涨价、技术突破、供需缺口、产能周期、新产品放量和海内外需求增长。需要判断：

- 产业变化是否有数据验证；
- 影响的是收入、成本还是利润率；
- 受益公司是否具有真实业务；
- 逻辑能否通过后续订单和业绩验证。

产业驱动更有机会形成中期主线，但要防止概念公司蹭热点、趋势真实而股价已过度反映，以及龙头真实受益但跟风公司没有业务贡献。

### 3. 业绩驱动

需要判断：

- 是单家公司超预期还是行业共性；
- 利润来自主营业务还是一次性收益；
- 同行业公司能否形成业绩扩散；
- 当前估值是否已反映增长预期。

这些信息可以区分个股独立行情、行业景气共振、一次性业绩刺激，以及具有延续性的基本面改善。

### 4. 纯情绪驱动

常见表现：

- 没有明确产业或业绩依据；
- 因一条模糊消息突然集体上涨；
- 小市值股票涨停较多；
- 容量股和机构股反应较弱；
- 成交额首日暴增、次日快速衰减；
- 题材名称频繁变化。

纯情绪行情不一定不能参与，但预期应更短：它更依赖龙头和情绪反馈，一旦龙头转弱，跟风股容易快速补跌，不能用产业主线的持有逻辑处理。

## 四、板块内部结构怎么看

### 1. 龙头或领涨股

主要特征包括最早启动、辨识度高、相对强度高、分歧时抗跌、修复时率先走强，并对板块其他股票具有带动性。它告诉我们：**市场把谁当作这个方向的核心代表。**但高辨识度只是观察证据，不等于自动买点。

### 2. 容量中军

容量中军通常成交额大、流动性好、能够容纳机构和大资金、趋势相对稳定，并对板块指数贡献较大。它告诉我们：**是否有较大规模资金真正认可这个方向。**

如果只有小市值股票涨停而中军不动，行情可能偏情绪脉冲；如果龙头活跃、中军放量走强，板块结构通常更扎实。

### 3. 补涨股

补涨股一般启动晚于龙头、位置较低，具有相似业务或题材映射，在龙头持续强势后获得资金扩散。它告诉我们：**板块行情是否从少数核心向更多股票扩散。**

补涨大量出现也可能意味着行情进入后半段，需要区分主线启动后的健康扩散、高位龙头乏力后的低位替代，以及题材尾声的全面补涨。

### 4. 跟风股

跟风股一般启动较晚、辨识度低，板块上涨时被动跟随，板块分歧时率先回落。它告诉我们：**板块的真实赚钱效应和风险扩散程度。**

如果龙头上涨但跟风股普遍亏钱，说明强度可能只存在于少数核心，不能理解为全面板块行情。

## 五、用四象限快速判断板块质量

|  | 上涨覆盖广 | 上涨覆盖窄 |
|-|-|-|
| **资金强度高** | **真实流入**：主线候选 | **短线脉冲**：少数个股驱动 |
| **资金强度低** | **权重拉升或普涨跟随**：强度有限 | **资金撤退或弱势板块** |

### 1. 真实流入

表现为板块成交额明显增加、多数成分股上涨、龙头中军补涨同步、资金连续多日关注，并具有相对大盘的超额收益。**最值得进入主线候选池。**

### 2. 短线脉冲

表现为少数股票大涨或涨停、上涨覆盖较窄、成交额集中在少数股票、次日持续性不确定。**存在情绪机会，但不能直接按主线处理。**

### 3. 权重拉升

表现为板块指数上涨，但少数大市值股票贡献主要涨幅，多数成分股表现普通，内部赚钱效应有限。**指数看起来强，但普通股票未必好做。**

### 4. 资金撤退

表现为成交额萎缩或资金流出、上涨覆盖窄、核心股转弱、跟风股亏钱效应扩散。**板块可能进入退潮，应降低关注等级。**

## 六、常见数据组合能告诉我们什么

### 组合一：涨幅高＋成交额增量大＋涨停多＋持续多日

可能说明资金形成较强共识，板块具备主线潜力，龙头、中军和补涨可能逐步形成。后续重点看分歧后的承接和回流；如果已经连续加速，也要防止高潮后的分化。

### 组合二：涨幅高＋成交额增量大＋只持续一天

可能是新方向刚启动、突发消息刺激、资金试探性进入，也可能是一日游。次日需要验证核心股是否有溢价、成交额能否维持、板块是否继续扩散，以及冲高后是否出现大面积回落。

### 组合三：涨停多＋成交额增量不明显

可能是小市值股票集中涨停，实际投入资金规模有限。情绪强，但机构和大资金参与不足，容量中军尚未获得认可。这种行情更依赖短线情绪，不宜用中期逻辑解释。

### 组合四：成交额增量大＋涨幅一般

可能是板块内部存在较大分歧，高位兑现与新资金承接同时发生，也可能处于启动前的吸筹阶段。单日不能确定，需要继续观察收盘位置、核心股表现、次日能否放量上涨，以及放量后是否跌破关键位置。

### 组合五：板块指数上涨＋多数成分股下跌

可能是权重股拉升、板块强度失真、普通股票赚钱效应较弱。不能因为板块排名靠前就追逐跟风股。

### 组合六：板块涨幅回落＋成交额缩小＋核心股抗跌

可能是主线正常分歧，抛压没有明显扩大，资金等待回流。次日若核心股率先转强，可重新确认；但如果跟风股已经批量跌停，就不能简单解释为健康洗盘。

### 组合七：板块下跌＋成交额放大＋核心股补跌

可能说明主动抛售增强、板块由分歧进入退潮、风险开始向核心扩散，需要降低板块评级。

## 七、最实用的板块筛选顺序

```text
第一步：找涨幅和成交额增量靠前的行业、题材
↓
第二步：看上涨覆盖率、涨跌幅中位数和相对大盘强度
↓
第三步：看涨停数量、炸板率及连板梯队
↓
第四步：看近3—5日成交额和资金持续性
↓
第五步：查政策、产业、业绩或事件催化
↓
第六步：识别龙头、容量中军、补涨和跟风
↓
第七步：判断真实流入、短线脉冲、权重拉升或资金撤退
↓
第八步：写出次日确认条件与失效条件
```

## 八、次日验证条件怎么写

复盘不是在盘后认定“它一定是主线”，而是为次日准备验证剧本。

### 看强的确认条件

- 板块成交额继续维持在近期较高水平；
- 核心股没有明显负反馈；
- 容量中军继续放量承接；
- 上涨覆盖率没有明显下降；
- 分歧后出现资金回流；
- 出现新的首板或补涨；
- 板块仍有相对大盘的超额收益。

### 看弱的失效条件

- 龙头低开低走且不能修复；
- 中军放量下跌；
- 板块成交额迅速衰减；
- 昨日涨停股普遍没有溢价；
- 炸板率明显提高；
- 跟风股批量回落；
- 政策、产业或业绩逻辑被证伪；
- 板块上涨仅剩一只高位股维持。

## 九、每日板块筛选表

| 维度 | 观察内容 | 要回答的问题 |
|-|-|-|
| 板块涨幅 | 当日涨幅、排名、相对大盘收益 | 今天资金选择了哪里 |
| 上涨覆盖 | 上涨占比、涨跌幅中位数 | 是全面上涨还是少数权重拉升 |
| 成交额增量 | 较昨日、近5日均额的变化 | 是否有增量资金参与 |
| 资金持续性 | 当日及近3—5日资金变化 | 是连续流入还是单日脉冲 |
| 涨停结构 | 涨停数、炸板率、连板梯队 | 短线共识是否形成 |
| 催化性质 | 政策、产业、业绩、纯情绪 | 行情可能持续多久 |
| 龙头 | 辨识度、带动性、抗跌性 | 谁是方向核心 |
| 容量中军 | 成交额、趋势、承接 | 大资金是否认可 |
| 补涨与跟风 | 扩散程度、失败反馈 | 板块赚钱效应是否扩散 |
| 板块阶段 | 启动、确认、强化、分歧、回流、退潮 | 当前处于什么位置 |
| 次日确认 | 量能、核心股、覆盖率、梯队 | 什么情况继续看强 |
| 失效条件 | 核心转弱、放量下跌、梯队瓦解 | 什么情况降低评级 |

## 十、最终结论

看板块筛选数据，最终要得到的不是“哪个板块今天涨得最好”，而是以下五条信息：

1. **资金方向**：当天资金主要进入了哪些行业和题材；
2. **强度真实性**：是多数股票共同上涨，还是权重或少数龙头制造的表面强势；
3. **持续性**：是主线启动、正常分歧和回流，还是一次性消息脉冲；
4. **内部结构**：谁是龙头、容量中军、补涨和跟风，板块是否形成健康梯队；
5. **次日剧本**：什么数据出现时确认，什么信号出现时失效。

> **一句话概括：涨幅用于发现方向，成交额用于验证资金，涨停与梯队用于观察情绪共识，持续天数用于区分主线和一日游，催化与内部结构用于判断行情能够走多远。**
