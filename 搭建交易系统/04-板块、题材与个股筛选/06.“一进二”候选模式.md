# 6.“一进二”候选模式

## 适用口径与边界

“一进二”通常指**首个涨停板后的下一交易日，尝试晋级为第二个涨停板**的观察场景。本节讨论的是候选模式与复盘框架，不构成任何直接买入信号、收益承诺或个股推荐。

原始资料中常见“**五个交易日内出现过涨停，且未跌破涨停日最低价**”的描述。它可能有两层含义，必须分开处理：

1. **严格的一进二口径**：只观察“首板日—次日”的晋级，首板必须是本轮行情中可识别的第一个涨停；
2. **五日涨停候选池口径**：在近五个交易日内任一涨停日形成过强势锚点，之后尚未跌破该涨停日最低价。这可以用于寻找仍在强势结构中的股票，但其中既可能包含一进二，也可能包含断板反包、趋势延续或高位接力，不能统称为一进二。

因此，记录时应明确标注“严格一进二”或“五日涨停强势候选”，不要用模糊名称混淆不同风险层级。若近五日有多个涨停日，应逐一记录日期、板型、最低价与是否有效，不能只选对自己有利的价格锚点。

## 先看什么：候选并非信号

候选的目的，是把注意力集中在结构较完整、信息可核验的样本上；它不是“满足几项条件就应参与”的机械规则。观察应从市场环境、题材、首板质量、次日竞价和盘中确认依次推进。任何一环明显转弱，都可能使候选降级或失效。

可先建立三个层次：

- **基础筛选**：近五日存在涨停锚点、价格未有效跌破锚点低点、流动性可交易；
- **质量筛选**：首板封板质量、题材催化、板块共振、相对地位和换手结构较好；
- **交易日确认**：次日集合竞价、开盘承接、量价配合及板块反馈没有显著走坏。

基础筛选只说明“值得继续看”，质量筛选才说明“有研究价值”，而交易日确认仍可能否定此前全部判断。

## 市值与流通规模：使用经验带，而非硬阈值

小流通盘或较小总市值往往更容易在短期资金推动下产生较大弹性，但也更容易出现流动性骤变、开板回落和情绪化波动。资料中“100亿元以内”应理解为历史环境下的**经验参考带**，不应固化为跨市场、跨周期的绝对门槛。

应同时看总市值、自由流通市值、实际成交额和股东结构：

- 总市值反映公司整体体量；自由流通市值更接近短线资金需要撬动的筹码规模；
- 在活跃行情中，市场可能容纳更大市值的核心标的；在缩量或退潮环境中，即使市值较小也未必有持续承接；
- 市值过小不必然更好。过度集中、长期低成交或盘中深度不足，可能放大滑点与无法退出的风险；
- 同一题材内，优先比较相对体量与相对成交，而不是孤立地用一个市值数字下结论。

记录中建议写“所处市值/流通盘分位、与板块核心的体量差、当日成交额是否匹配”，而不是写“低于某数值即可”。

## 首板定义与首板质量

首板是本轮可识别行情中首次封住涨停的交易日，不等于“历史上第一次涨停”。判断本轮时，要回看前期是否已有连续涨停、是否刚经历断板、是否属于反包或消息刺激后的脉冲。对连续高位后的再次涨停，应归入高位延续或反包研究，不宜伪装为低位一进二。

首板质量可从以下维度观察：

| 维度 | 观察重点 | 警惕情形 |
|-|-|-|
| 启动位置 | 是否处于整理后启动、是否脱离长期低迷区 | 已连续大涨、位置拥挤却称“首板” |
| 涨停时间 | 早盘快速封住通常更能显示主动性 | 尾盘突击、反复勉强回封 |
| 封单与开板 | 封板后稳定性、开板次数、回封速度 | 多次炸板且回封无力 |
| 成交结构 | 放量是否对应分歧换手，量能是否可被承接 | 无法解释的巨量、尾盘放量回落 |
| 触发因素 | 公告、政策、产业事件或板块催化是否可核验 | 传闻驱动、题材牵强附会 |
| 市场反馈 | 同题材是否有扩散与梯队 | 孤立涨停、板块整体走弱 |

“首板质量好”不是单看封单金额，也不能以封死涨停替代全部分析。封单可能随时撤除，盘口数字需结合成交、开板过程、板块和市场情绪解释。

## 板块地位：看梯队，不只看个股涨幅

一进二的持续性通常来自题材内的资金共识，而非单一个股的孤立强势。观察板块时，至少回答四个问题：

1. **是否有明确催化**：催化是否可验证、是否仍在发酵，而非已经被充分交易；
2. **是否形成梯队**：是否有同题材涨停、连板、趋势核心或容量中军相互印证；
3. **个股处于何种地位**：是领涨、跟随、补涨，还是仅因个别消息异动；
4. **板块资金是否持续**：上涨家数、涨停溢价、成交额和资金流向是否与个股表现一致。

所谓龙头不应只按涨幅命名。可把它拆成“最先启动、最强封板、最有辨识度、最能带动板块、最能承接分歧”几项验证。若只是跟风票，即便次日高开，也需将其与核心票区分，不能套用核心票的预期。

## 次日开盘预期与集合竞价

集合竞价提供的是隔夜预期和开盘前资金意愿的有限切片，不是最终结论。重点不在某一个绝对高开幅度，而在预期与质量是否匹配。

可按情景观察：

- **符合或略强于预期的高开**：需要继续看竞价成交是否自然、买卖盘是否稳定、板块是否同步；
- **过度高开或一字预期**：表面强，但可交易性下降，获利盘与开板后的承接风险更高；
- **平开或小幅低开**：不必自动判死刑，需看是否因板块分歧、指数扰动或个股预期不足，并观察开盘后的修复能力；
- **明显低于预期**：若同时伴随板块走弱、竞价量价恶化或前一日封板质量存疑，应优先按风险事件处理，而非寻找理由硬解释。

竞价记录建议包括：竞价涨跌幅、竞价成交额及其相对首板成交的比例、未匹配量变化、同题材核心股竞价表现，以及是否存在临近开盘的明显撤单。单独依赖虚拟挂单或单次盘口快照，容易误判。

## 量价与换手：适度分歧优于失控放量

首板到二板需要资金接力与筹码交换。完全无换手未必适合所有标的，巨量换手也不天然代表强承接；关键在于换手是否与价格强度、板块热度和流通盘结构相匹配。

可将换手理解为区间而非固定百分比：

- 流通盘较小、封板较早的标的，合理换手通常可能较低；
- 容量较大或经历盘中分歧的标的，适度换手有助于清洗浮筹；
- 若次日成交额、换手率远超首板且价格无法维持强势，可能表示分歧已从“交换筹码”转为“集中派发”；
- 量能萎缩也需区分：强封板下的自然缩量与买盘不足导致的缩量回落，含义不同。

不要预设一个适用于所有股票的“理想换手率”。应以首板换手、过去一段时间日均成交、自由流通盘和同题材可比标的为参照，记录“较自身基线放大/缩小多少、放量发生在哪个时段、价格是否得到确认”。

## 价格锚点、确认与失效

“未跌破涨停日最低价”是五日强势候选池的底线条件之一，但不是充分条件。它说明涨停日留下的价格支撑尚未完全失守，不代表次日必然晋级。

建议预先写明不同层级的失效条件：

- **结构失效**：收盘或盘中有效跌破所对应涨停日最低价；若多个涨停锚点并存，应说明使用哪一个锚点；
- **预期失效**：竞价或开盘显著低于事前预期，且板块没有提供合理解释或修复；
- **量价失效**：异常巨量但无法回到强势区间，或放量下跌、承接持续减弱；
- **板块失效**：催化被证伪、核心股转弱、梯队大面积掉队；
- **时间失效**：严格一进二观察窗口仅限首板后下一交易日。未在窗口内完成的，不应继续以“一进二”名义追踪。

“有效跌破”应在个人系统中统一定义，例如结合收盘、持续时间、成交放大和是否快速收回判断；不要在亏损时临时放宽、在盈利时临时收紧。确认也同样不是单点价格：更可靠的确认来自个股、板块、量价与市场环境的共同改善。

## 观察流程

1. **盘后建池**：标记近五日涨停股票，分为严格首板次日候选、断板/反包候选和其他强势候选；核对涨停日最低价。
2. **核验首板**：复盘涨停原因、首次封板时间、开板回封、成交额、换手和位置；排除伪首板与纯孤立异动。
3. **核验板块**：建立题材梯队，识别核心、跟随和补涨，记录催化与板块资金反馈。
4. **设定事前情景**：写下可接受、偏强、过热和低于预期的开盘情景，以及每种情景下仅“继续观察、降级或放弃”的处理原则。
5. **观察竞价与开盘**：比较实际表现与预期，重点看板块同步性、成交与盘口稳定性，不因单一数字冲动下结论。
6. **盘中复核**：观察关键价位附近承接、量价变化、封板/开板质量与板块联动。避免只盯个股分时图。
7. **收盘归档**：记录是否晋级、未晋级原因、是否触发失效条件，以及原判断中哪些假设被验证或否定。

流程的核心是先定义，再观察，再复盘；不是用盘中波动反向拼凑理由。

## 建议记录表

| 字段 | 记录内容 |
|-|-|
| 股票与日期 | 名称、代码、首板日、观察日 |
| 分类 | 严格一进二 / 五日涨停候选 / 断板反包等 |
| 题材与催化 | 可核验事件、题材持续性、消息来源 |
| 规模与流动性 | 总市值、自由流通盘、日均成交、相对板块体量 |
| 首板质量 | 启动位置、封板时间、开板次数、成交额、换手、回封情况 |
| 板块地位 | 核心/跟随/补涨、梯队成员、板块强弱 |
| 锚点价格 | 对应涨停日最高/最低/收盘，多个锚点时分别列明 |
| 竞价观察 | 涨跌幅、成交额、未匹配量变化、同题材表现 |
| 盘中量价 | 高低开后走势、关键位承接、成交相对基线、开板回封 |
| 预期与结果 | 事前情景、实际结果、确认/失效原因 |
| 风险备注 | 公告、监管、减持、解禁、停复牌、流动性及市场风险 |

长期积累后，可统计不同首板类型、板块地位、竞价情景和换手结构下的结果分布。统计时应包含所有入池样本与失效样本，避免只保留成功案例造成幸存者偏差。

## 风险提示

涨停、连板和题材热度具有高度不确定性。价格可能因公告、监管问询、减持、解禁、行业消息、指数波动、流动性变化或情绪退潮而快速反转；涨跌停限制还可能造成无法按预期成交或退出。小流通盘股票的波动、滑点和信息不对称风险尤其突出。

本模式仅用于教学、筛选和复盘。实际决策还应结合自身风险承受能力、持仓集中度、交易规则、费用与合规要求，并保留独立判断。对不符合预设条件的情况，最重要的处理往往是停止将其视为“一进二”候选，而不是提高容忍度去证明原判断正确。
