# 5.放量长上影候选模式

## 一、定位：这是“候选模式”，不是买入信号

“放量长上影”指价格在盘中向上突破或触及关键压力区、收盘却回落，并留下较长上影线，同时成交显著放大的K线。它反映的是关键价位附近多空资金的集中交换：可能是主力试探压力和承接，也可能是冲高派发。因此，这一形态只能把标的纳入后续观察池，**不能单独作为直接买入、追高或加仓依据**。

更有研究价值的场景通常是：

- 股价经历较长时间横盘整理，或刚从横盘区向上启动；
- 上影线盘中触及、略过或测试前高/平台上沿；
- 触及前高当天的成交量明显高于此前常态；
- 近期有涨停或强势放量启动，随后回调但低位承接仍在；
- 之后能缩量止跌、守住关键位，并重新放量收复压力位。

相反，如果股价已连续大幅拉升、远离底部成本区，或长上影伴随高位巨量、跌破关键支撑且无法收回，应优先按风险情形处理，而非把它解释为“洗盘”。

---

## 二、先统一口径：前高、长上影与放量如何定义

量化口径不是为了制造精确幻觉，而是为了让筛选、复盘和交易记录可重复。可按日线制定以下默认规则，再结合行业、流通盘和波动特征做调整。

### 1. 前高（压力位）

前高不是任意一根K线的最高价，而是市场曾经形成共识的阻力区。优先级如下：

1. **平台前高**：近20—60个交易日横盘区内，至少两次冲高未能有效站上的高点区域；
2. **波段前高**：近60—120个交易日内显著拐点的最高价；
3. **近期涨停后的高点**：强势启动后形成的阶段性压力；
4. **更大级别压力**：周线前高、密集成交区上沿等。

实务上应把前高看成区间而非一条细线。可将前高附近 **±1%**（高波动品种可放宽至±1.5%）定义为“压力带”。当日最高价进入该压力带，即视为“触及前高”；最高价超过前高1%但收盘仍回到压力带下方，属于“假突破/回落测试”，需要更严格的后续确认。

### 2. 长上影

设当日开盘价为 (O)、最高价为 (H)、最低价为 (L)、收盘价为 (C)。

- 上影长度：(H - \max(O,C))；
- 实体长度：(|C-O|)；
- 全日振幅：(H-L)。

建议满足以下至少两项：

- 上影长度占全日振幅 **≥40%**；
- 上影长度 **≥实体长度的1.5倍**；
- 当日振幅 **≥近20日平均振幅的1.2倍**，说明不是极小波动中的偶然影线。

同时应尽量避免明显下影。可把下影 (\min(O,C)-L) 占全日振幅 **>30%** 视为“下影明显”。上下影都很长时，多半表示剧烈分歧，单凭上影无法解读为对压力的有效测试，观察价值应降低、等待时间应延长。

### 3. 放量倍数

建议用成交量与前期均量比较，而非只看绝对成交额：

[  
放量倍数 = 当日成交量 ÷ 前20个交易日平均成交量  
]

其中前20日均量不包含当日。初筛可要求放量倍数 **≥1.5倍**；更强的关注信号通常为 **≥2.0倍**。但极端巨量也不是越大越好：若成交量达到20日均量的3—5倍以上、收盘明显走弱且次日承接不足，反而要警惕高位换手或派发。

对于近期刚出现涨停、成交量结构变化很大的标的，可同时参考5日均量和20日均量：相对5日均量仍放大，说明资金热度未快速消退；仅相对20日均量放大、但较近5日明显萎缩，则不应机械认定为强势。

## 三、K线背后的数据含义

一根放量长上影至少包含三段信息：

1. **价格曾上探**：盘中有资金愿意把价格推至前高附近或上方，说明该压力带被主动测试；
2. **成交显著增加**：在压力附近发生了大量交易，代表分歧和筹码交换扩大；
3. **收盘回落**：上方卖压、获利兑现或资金主动回撤占据了收盘前的优势。

因此，成交量本身不区分“吸筹”“试盘”或“出货”。同样的放量，可能是承接盘吸收抛压，也可能是卖方把筹码交给追涨资金。真正有区分度的是**量价的后续演化**：回落时是否缩量、支撑位是否守住、反弹时是否重新出现主动买盘，以及能否有效站回关键位。

可额外记录以下辅助数据，但不把任何单项当作结论：

- 当日收盘在全日振幅中的位置；收盘越靠近低位，偏弱含义越强；
- 换手率及其相对历史分位；低位适度换手未必坏，高位异常换手需警惕；
- 触及前高时的分时成交密度、封板/开板（如有）、大单方向；
- 板块强弱和市场风险偏好；个股独立上冲但板块退潮时，延续难度往往更高；
- 回调期间的量能递减情况及关键支撑附近的承接。

## 四、形态拆解：先看位置，再看当日，最后看后续

### 1. 位置优先于K线形状

同样是一根长上影，在不同位置含义不同：

- **长期横盘末端/突破初期**：若筹码尚未大幅获利，前高附近放量可能是突破前的压力测试，值得跟踪；
- **近期涨停后首次回调的支撑区**：若回调缩量、底部承接稳定，长上影可能是二次上攻前的换手；
- **连续上涨后的高位**：市场获利盘较多，放量长上影更容易对应抛压释放或派发风险；
- **下跌趋势中的反弹高点**：即使触及前高，也可能只是套牢盘卖出，优先等待趋势扭转证据。

筛选时可把“横盘或启动初期”作为前置条件。例如：候选K线前20—60日价格大部分在相对有限的区间内运行，或刚向上突破该区间；不宜把已经短期急涨、偏离20日均线过大的标的与其混为一谈。

### 2. 当日结构：回落幅度与收盘位置

重点观察：

- 最高价是否真正进入前高压力带，而不是远离压力位的普通冲高；
- 收盘是否仍守住平台上沿、突破位、5日/10日均线或近期涨停实体上方等关键位置；
- 收盘是否接近最低价；若接近最低且放出巨量，短线风险上升；
- 下影是否很长；长下影意味着盘中也出现较大抛压和反复，不宜简单归类；
- 次日是否低开、是否快速跌破候选K线实体低点或关键支撑。

### 3. 后续结构：观察期限必须预先写清

建议将候选K线出现后的 **3—5个交易日** 设为主要观察期，最多延长至 **10个交易日**。观察期内不急于给形态定性，而是记录下面两类路径。

**偏确认的路径**：

- 回调量能逐步缩小，未再出现放量长阴；
- 价格在平台上沿、候选K线实体中部/低点、10日均线或近期涨停关键位附近止跌；
- 3—5日内重新站回候选K线收盘价或前高压力带；
- 随后的上攻成交量合理放大，并以收盘价有效站上前高。

“有效站上”可定义为：收盘价高于前高压力带上沿至少 **1%**，且当天量能不低于20日均量的 **1.2倍**；或连续 **2个交易日** 收盘站在压力带上方。不同波动率品种可适度调整，但规则应在事前固定。

**偏失败的路径**：

- 反弹无量，数日都无法回到候选K线收盘价或压力带；
- 回调放量且连续收在候选K线实体低点下方；
- 突破后迅速跌回平台内部，并在3—5日内无法收复；
- 高位出现多根放量长上影、重心持续下移；
- 板块走弱、市场风险偏好下降时个股同步跌破支撑。

## 五、试盘与派发：只能比较概率，不能凭单日断言

### 更偏“试盘/换手”的特征

以下特征越多同时出现，越值得作为正向候选观察：

- 位置处在长期整理末端或启动初期，而不是连续大涨后；
- 前期有涨停或放量启动，之后回调的量能逐渐萎缩；
- 触及前高时虽有长上影，但收盘仍在重要支撑上方；
- 候选K线后1—3日下探未放量，低位买盘使价格企稳；
- 在观察期限内重新回到关键位上方，且再突破时有量价配合；
- 同板块仍有资金活跃、市场环境未明显转弱。

### 更偏“派发/失败突破”的特征

出现以下任意多项时，应明显降低优先级：

- 已经连续上涨、短期涨幅较大，远离整理平台和均线；
- 天量长上影，收盘接近日内低点，且换手显著高于历史常态；
- 接连多日冲高回落，前高始终无法有效突破；
- 后续下跌放量、反弹缩量，价格重心不断降低；
- 跌破候选K线低点、平台上沿或近期涨停关键位后不能迅速收回；
- 同期板块退潮、龙头走弱，个股缺乏独立基本面或事件驱动支撑。

不要把“有承接”“有大单”“主力未走”当作派发不存在的证据。盘口和资金流数据只能辅助观察，最终仍应以可验证的价格、成交量和时间条件为准。

## 六、确认、失效与风险控制规则

### 确认条件

候选模式至少满足“位置 + 放量长上影 + 后续企稳”三层，再考虑是否升级为重点跟踪：

1. 处在横盘末端、启动初期或涨停后缩量回调的相对有利位置；
2. 当日触及定义明确的前高，且上影和放量满足既定阈值；
3. 观察期内回调缩量、守住关键支撑，并重新有效站上前高或关键位。

请注意：确认条件是研究与观察条件，不等于建议建仓。任何执行决策还应独立考虑市场环境、流动性、仓位、风险承受能力和自身策略。

### 失效条件

应在记录中预先写明，避免事后不断修改解释。可采用以下任一条作为失效：

- **价格失效**：收盘跌破候选K线低点，或跌破横盘平台上沿/预设支撑 **1%—2%** 后，连续2日不能收回；
- **量价失效**：跌破支撑时成交量达到20日均量的 **1.5倍** 以上，显示抛压扩大；
- **时间失效**：候选K线后 **5个交易日** 仍不能回到候选K线收盘价或前高压力带附近；最长 **10个交易日** 仍未形成重新走强结构，则从观察池移除；
- **结构失效**：出现连续放量阴线、重心下移，或新的更低低点破坏原有横盘/上升结构。

阈值必须结合标的波动特征调整，但调整应在筛选前完成；不要因不愿接受失效而事后放宽条件。

## 七、可执行的筛选流程

### 第一步：建立基础池

1. 扫描近20—120日处于横盘整理、或刚突破横盘上沿的标的；
2. 标记近60—120日波段前高、平台前高与近期涨停后的关键价位；
3. 剔除流动性极差、价格异常波动、重大不确定事件或连续高位加速的标的；
4. 结合板块趋势，优先保留有相对强度和资金活跃度的方向。

### 第二步：识别候选K线

逐项核验：

- 最高价是否进入前高压力带；
- 上影是否满足“占振幅≥40%”或“至少为实体1.5倍”等规则；
- 下影是否不明显；
- 成交量是否达到前20日均量的1.5倍以上；
- 收盘是否尚在关键支撑之上；
- 该位置是否符合“横盘末端/上涨初期/涨停后缩量回调”的背景。

全部满足者列为A类候选；若下影明显、收盘偏弱或位置过高，可列为B类观察，不应与A类同等对待。

### 第三步：设定观察计划

对每个候选，事前写下：

- 前高压力带、平台上沿、候选K线高低点；
- 观察起止日期（第1日至第5日，必要时第10日复核）；
- 重新走强的确认标准；
- 明确的价格、量价、时间失效条件；
- 仅观察或纳入策略研究的状态。

### 第四步：每日复核而非盘中猜测

收盘后按同一口径更新：价格是否守住支撑、回调是否缩量、是否回到关键位、板块是否配合。盘中冲高回落容易制造情绪，日线收盘与后续两三日结构通常更可靠。

## 八、标准记录表（建议每个候选一行）

| 字段 | 记录内容 |
|-|-|
| 标的/日期 | 代码、名称、候选K线日期 |
| 背景位置 | 横盘天数、是否启动初期、距近期低点/前高的区间 |
| 前高定义 | 平台前高/波段前高/涨停后高点；压力带上下沿 |
| 候选K线 | 开高低收、实体、上下影占比、收盘所处位置 |
| 成交量 | 当日量、5日均量、20日均量、放量倍数、换手率 |
| 近期强势线索 | 是否有近期涨停、回调天数、回调量能是否缩减 |
| 关键支撑 | 平台上沿、候选K线低点、均线、涨停实体等 |
| 观察期限 | 第1—5日结论；是否需要延长至第10日 |
| 确认触发 | 有效站上哪个价位、需要何种量能 |
| 失效条件 | 价格、量价、时间、结构四类条件 |
| 后续结果 | 缩量企稳/有效突破/跌破失效/持续震荡 |
| 复盘备注 | 板块环境、消息扰动、规则是否需优化 |

建议定期统计A类与B类候选在不同市场环境、不同位置、不同放量倍数下的后续表现。只有经过足够样本复盘，规则才可能从“看起来合理”变成对自身有用的研究框架。

## 九、常见误区

1. **把长上影直接等同于洗盘。** 长上影只说明冲高后回落，不能证明资金意图。
2. **只看K线、不看位置。** 低位平台测试与高位冲顶回落的风险结构完全不同。
3. **把放量当作唯一利好。** 放量代表分歧扩大；必须结合收盘位置和后续承接判断。
4. **忽略前高的客观定义。** 不先画出压力带，事后很容易把任何冲高解释为“试盘”。
5. **忽略下影和振幅。** 上下影都长常意味着剧烈多空拉扯，信号纯度通常更低。
6. **只看当天，不给时间验证。** 关键在候选日后3—5日是否缩量企稳、能否重回关键位。
7. **失效后继续寻找理由。** 价格和时间条件触发后应按规则降级或移出观察池。
8. **忽视大盘与板块。** 个股形态无法完全脱离风险偏好、题材周期和行业资金流独立判断。

## 十、风险提示与使用边界

本模式是对公开价格和成交量行为的结构化观察，不包含对主体资金意图的确定性判断，也无法保证未来走势。涨跌停限制、隔夜消息、财报、监管、流动性变化及整体市场波动，都可能使形态快速失效。

使用时应坚持：先定义、再筛选、后观察；先写失效、再做结论；以收盘与后续结构验证，不以单日故事替代证据。该框架仅供学习、复盘和研究使用，**不构成任何证券买卖建议或收益承诺**。
