# 买入、持有与卖出规则

### 买入前的最低要求

每笔交易在下单前至少写清：

- 交易模式；
- 市场和板块前提；
- 入场触发条件；
- 计划入场价格或区间；
- 逻辑失效位置；
- 预计风险 R；
- 初始仓位和最大仓位；
- 符合、低于、超出预期的处理；
- 最晚退出时间或时间止损。

缺少任一关键项时，不应因为盘中波动而临时补规则。

### 原资料中的分时买点

原资料提供了四类短线买点：

1. 早盘冲高后回调至均价线附近，缩量并出现支撑。
2. 回调至开盘价附近，缩量并出现支撑。
3. 开盘放量下跌后转强，上穿均价线，再回踩均价线确认；资料强调缩量上穿不参与。
4. 临近涨停时按打板模式参与，错过则放弃，不在失去风险收益比后追高。

这些描述仍需量化：“缩量”“支撑”“放量上穿”“临近涨停”都应转换为可记录条件。打板还存在无法成交、次日低开、开板回落等额外风险。

### 买入时段规则的冲突

两份资料给出了互不兼容的时段建议：

- 资料一：只在上午 10:40 前或下午 14:40 后买入。
- 资料二：避开 9:30-10:00 和 14:50-15:00，优先 10:30-14:30。

这说明“最佳时段”不是通用规律，而是与策略、撮合特征、持仓周期和样本市场相关。正确做法是：

1. 先固定一种模式；
2. 记录每笔信号发生的时段；
3. 统计不同时间段的胜率、盈亏比、滑点和失败类型；
4. 只有样本显示稳定差异时，才把时段写入系统。

### 止损规则

止损应围绕“逻辑失效”，可分为四类：

| 类型 | 示例 |
|-|-|
| 价格止损 | 跌破突破位、关键低点或预设波动边界 |
| 事件止损 | 业绩、公告、政策或行业逻辑被证伪 |
| 时间止损 | 入场后规定时间内没有出现预期走势 |
| 组合止损 | 单日、连续亏损或账户回撤达到上限 |

原资料给出“单股止损 8%-10%”和“短线买入后 1-2 天没有溢价退出”等建议。百分比止损便于执行，但不一定适合所有波动水平。更合理的顺序是先确定逻辑失效位置，再据此计算仓位；如果止损距离过大导致仓位过小或风险收益比不足，就放弃交易。

### 止盈规则

止盈可以采用：

- 目标位分批退出；
- 跟踪止盈，让盈利随趋势运行；
- 预期兑现后退出；
- 时间窗口结束后退出；
- 出现放量滞涨、关键结构破坏或板块退潮后退出。

原资料包含“盈利 15%-20% 分批卖”“10:40 前设置条件单卖出”“次日无论走势如何卖出”等规则。它们分别对应不同模式，不能同时套用。卖出规则必须与入场逻辑一一对应。

### 原资料中的短线卖出信号

以下信号适合加入观察清单，但需要回测后才能成为规则：

- 开盘下跌后，两次反弹均未突破均价线；
- 开盘放量下跌，反弹未能收复开盘价；
- 开盘量比很高但涨幅有限，出现放量滞涨；原资料使用“量比大于 15、涨幅仅 1%-2%”作为例子；
- 结合前三日K线观察，高点不再持续抬高；
- 指数开盘快速下跌且短时间内无修复；
- 买入依据是突破前高，而价格重新跌破前高；
- 业绩或行业利好已经被股价提前充分反映，兑现时出现弱反馈。

原资料中“卖出只看个股、不看大盘”与“指数快速下杀时立即卖出”存在冲突。可统一为：个股失效条件是主要退出依据；当系统性风险触发组合级风控时，组合规则优先于单只个股规则。

### 中长线逻辑兑现

- 若买入基于业绩增长，应观察实际业绩、增长质量、未来指引和市场是否已提前定价。
- 若买入基于行业逻辑，应持续检查供需、价格、政策、竞争格局和公司兑现能力。
- “逻辑未证伪就一直持有”仍需配合估值、机会成本和组合风险，不能把信念替代证据。
- 利好兑现后股价不涨，可能说明预期已反映，也可能有其他风险，应重新评估而不是机械持有。
