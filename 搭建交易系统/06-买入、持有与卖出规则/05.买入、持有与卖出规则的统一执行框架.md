# 5.买入、持有与卖出规则的统一执行框架

本章前四节不是四套彼此独立的规则，而是一条完整的交易决策链：**先筛掉不该做的交易，再在合适时段等待确认；买入后用原始逻辑管理仓位；当利润与风险状态变化时，按模式兑现或退出。**

> 一笔合格交易的完整表达应是：**我做什么模式 → 为什么现在可以买 → 在什么条件下加/减/持有 → 什么现象说明判断错了 → 什么现象说明利润应兑现。**
> 
> 任何一个环节缺失，后面的“持有”都容易变成情绪化扛单，后面的“卖出”都容易变成临时猜顶猜底。

## 一、四节内容分别解决什么问题

| 章节 | 解决的核心问题 | 交易系统中的位置 | 最终要产出的内容 |
|-|-|-|-|
| 1. 买入前的最低要求 | 这笔交易是否值得做 | 交易筛选 | 模式、市场/板块前提、触发条件、失效位、风险与仓位 |
| 2. 买入时段规则的冲突 | 现在是否是该模式的有效执行窗口 | 入场执行 | 模式匹配的时段、分时确认、不可交易时段和等待条件 |
| 3. 止损规则 | 什么时候必须承认原判断失效 | 风险控制 | 结构、事件、时间、组合四类退出条件 |
| 4. 止盈规则 | 利润该锁定、让趋势运行还是全部兑现 | 利润管理 | 分批目标、趋势跟踪条件、板块/情绪兑现信号 |

四节合在一起，形成的不是“买卖口诀”，而是一个有前提、有证据、有退出边界的闭环。

## 二、先用交易模式统一所有规则

最常见的错误，是把打板、回踩低吸、平台突破、趋势波段和事件套利的买入、持有、卖出规则混用。

正确做法是：**下单前先给交易贴标签，之后只调用这类模式对应的时段、止损和止盈规则。**

| 交易模式 | 买入前提与触发 | 持有时重点观察 | 主要止损 | 主要止盈 |
|-|-|-|-|-|
| 打板/隔夜超短 | 主线核心、封板质量、板块梯队、次日溢价预期 | 次日高开、承接、开板回封、板块情绪 | 低开无法修复、炸板回封无力、板块退潮 | 次日冲高兑现、早盘条件单、强弱决定是否快速退出 |
| 平台突破 | 放量突破平台/前高，收盘站稳，板块配合 | 是否守住突破位、回踩是否缩量、能否再上攻 | 放量跌回平台、反抽不能收回突破位 | 目标位分批、平台/均线跟踪 |
| 回踩低吸 | 原趋势未坏，回踩缩量，关键位承接，再次转强 | 均线/前低/平台是否守住，量能是否收敛 | 放量跌破关键支撑、反弹无量、板块核心转弱 | 前高或压力位分批；趋势未坏则继续跟踪 |
| 强势股首阴/情绪修复 | 有辨识度的核心股，首阴结构未坏，板块高度仍在 | 次日修复速度、收复关键位置、同梯队反馈 | 放量破低、核心集体转弱、情绪退潮 | 修复冲高分批兑现，不拖成趋势持仓 |
| 趋势波段 | 行业/业绩逻辑、日周线趋势、合理位置和赔率 | 高低点是否抬高、均线方向、量价效率、逻辑兑现 | 周期结构破坏、基本面或行业逻辑证伪 | 目标位部分兑现，余仓按趋势结构跟踪 |
| 事件驱动 | 公告/政策/业绩带来新增预期差，市场反馈积极 | 预期是否继续强化、利好能否推动价格 | 事件证伪、利好落地不涨、市场反馈转弱 | 预期兑现或被充分定价时退出 |

**统一原则：买入模式决定持有周期；持有周期决定应看的数据；卖出方式必须回到最初买入模式。**

## 三、完整决策顺序：从“能不能买”到“该不该卖”

### 第一步：交易资格筛选——先决定“不做什么”

先检查以下五项：

1. **市场环境**：指数是否破位、情绪是否退潮、高位股是否批量补跌；
2. **板块环境**：是否有资金、是否属于主线、龙头和梯队是否稳定；
3. **个股位置**：在支撑/突破初期，还是连续急拉后的高位；
4. **趋势结构**：高低点、均线、平台和关键支撑是否完整；
5. **风险边界**：买入触发、逻辑失效位、时间止损、仓位上限是否已写清。

只要市场系统性风险明显、板块退潮、个股离失效位过远或无法定义风险，就不交易。**等待不是错过，而是在保留风险预算给更高质量的机会。**

### 第二步：选择执行窗口——时段服务于模式，不代替信号

- **确认型交易**（回踩、突破回踩、趋势低吸）：等待开盘噪声消化，观察回调是否缩量、关键位是否承接、再上攻是否有量，通常不应只因开盘急拉就追。
- **强势确认/打板型交易**：可在早盘或尾盘参与，但必须增加对板块地位、量价效率、封板/收盘质量和隔夜风险的检查。
- **无法归类或时段规则相互打架**：默认不交易。

时段只回答“现在的信息是否足够”；真正决定买入的，仍是**位置、量价、结构、板块和确认条件**。

### 第三步：触发买入——把模糊信号变成可验证条件

一个可执行的买入触发至少应同时说明：

| 维度 | 需要写清的问题 |
|-|-|
| 价格 | 突破哪个平台、回踩哪个支撑、站回哪条均线或前高 |
| 成交 | 突破是否放量、回调是否缩量、再上攻是否有新量 |
| 收盘/分时 | 是否站稳关键位、收盘是否靠近日内高位、是否守住均价线/开盘价 |
| 板块 | 龙头、同梯队和板块资金是否支持 |
| 风险 | 跌破哪里逻辑失效；从入场到止损的风险是多少 |
| 仓位 | 初始仓位、最大仓位和加仓条件是什么 |

没有触发条件的“看好”，不能转化为买入；没有失效条件的买入，也不应发生。

## 四、买入后如何持有：持有不是不动，而是持续验证

持有阶段的核心任务不是寻找更多支持自己观点的信息，而是持续比较：**实际走势是否符合买入前预期。**

### 1. 符合预期：让正确交易逐步扩大

偏强的共同特征包括：

- 突破后能站稳，回踩不破关键位；
- 回踩缩量、再上攻放量，量价效率正常；
- 收盘能保住大部分涨幅；
- 个股相对板块和市场仍强；
- 板块主线、核心股和情绪环境没有明显恶化。

满足这些条件时，持有的依据是结构，而不是因为“已经盈利”。若计划允许加仓，只有在原始逻辑进一步确认、风险仍可控时才考虑；不能因浮盈产生而盲目追高加仓。

### 2. 低于预期：先减速，而不是立刻自我说服

需要警惕的信号：

- 买入后没有预期的溢价或上攻；
- 板块走强而个股跟不上；
- 多次反弹无法站回均价线、开盘价、突破位或关键均线；
- 成交放大但涨幅有限，或冲高后收盘很弱；
- 题材核心开始掉队、资金扩散失败。

这时要先判断是**时间止损/减仓信号**，还是结构已直接失效。超短交易的时间容忍度应更低；趋势波段应更多看日线、周线和逻辑，而不能机械套用“1—2天不涨就卖”。

### 3. 超出预期：避免把浮盈当作永久利润

连续加速、乖离过大、巨量滞涨、长上影、高位股掉队和板块退潮，说明利润回吐风险上升。超预期上涨并不自动意味着应该全卖，但应将操作从“增加敞口”转向“锁定收益、管理余仓”。

## 五、退出规则的优先级：先防错，再管理利润

退出不是单一动作，应按以下优先级判断：

### 优先级一：逻辑与结构失效——必须处理

- 突破后放量跌回平台；
- 回踩交易放量跌破前低、均线或平台下沿；
- 反抽无量，关键位由支撑变成压力；
- 买入依据的业绩、公告、政策或行业逻辑被证伪；
- 主线退潮、核心股集体走弱，原来的情绪基础不再存在。

此时不需要等待固定亏损比例或时间条件。**结构失效优先于百分比止损。**

### 优先级二：时间与节奏失效——减少机会成本

若预期是隔夜溢价、强势修复或突破延续，但在预设时间内没有看到应有的正反馈，则应减仓或退出。

时间止损的目的不是惩罚不涨，而是确认：市场并未按预期接受你的价格和逻辑。时间窗口必须与模式匹配，不能一套标准管所有策略。

### 优先级三：组合级风险——账户优先于单股

指数快速下杀、情绪退潮、高位股批量补跌、多只持仓同步破位、单日或连续回撤触及上限时，组合风控优先。

即使个股没有完全触发自身止损，系统性风险也可能要求先降低总体仓位。单股逻辑不能凌驾于账户生存之上。

### 优先级四：利润兑现——按模式保护已有成果

| 情形 | 更合理的处理 |
|-|-|
| 超短/隔夜交易获得预期溢价 | 早盘观察强弱，冲高兑现或按条件单退出 |
| 突破、回踩修复到前高/目标位 | 分批锁定利润，余仓看是否仍守住结构 |
| 趋势持续、量价健康、板块仍强 | 用关键均线/前低/平台跟踪余仓，不因小波动全部卖出 |
| 高位巨量滞涨、长上影、板块退潮 | 提高兑现或减仓优先级；若结构同步破坏则退出 |
| 利好兑现但股价不涨 | 重新评估预期是否已被充分交易，不以“利好存在”作为继续持有理由 |

## 六、固定百分比、固定时段和固定天数应处于什么位置

“8%—10%止损”“15%—20%分批卖”“10:40前卖”“次日卖”等规则，都可以作为执行工具，但不能替代模式与证据。

它们更适合承担以下功能：

- **固定止损比例**：最后的风险底线，防止小错拖成大错；
- **固定盈利目标**：触发分批兑现检查，而非自动全卖；
- **固定卖出时段**：适用于明确的隔夜/超短策略，利用流动性和预期兑现窗口；
- **固定时间止损**：检验强势策略的节奏是否兑现。

若要把它们写成硬规则，必须通过自己的交易记录验证：在特定的**交易模式 × 市场环境 × 时段/退出方法**下，是否长期带来更高的期望值。

## 七、可直接执行的交易卡

每笔交易在下单前填写；盘中和盘后按同一张卡更新，避免临时改规则。

| 项目 | 交易前/持有中要填写的内容 |
|-|-|
| 交易模式 | 打板、突破、回踩、首阴、趋势或事件驱动 |
| 市场与板块前提 | 指数状态、情绪阶段、板块是否主线、龙头反馈 |
| 入场触发 | 价格关键位、量价条件、分时确认、计划入场区间 |
| 执行时段 | 为什么此时段适合该模式；哪些时段不交易 |
| 初始/最大仓位 | 初始仓位、加仓的确认条件、最大暴露 |
| 结构失效位 | 平台、前低、均线、突破位或事件证伪条件 |
| 时间止损 | 几个交易日内应出现什么反馈；不符合时如何处理 |
| 组合风控 | 指数、情绪、连续亏损、账户回撤触发后的动作 |
| 止盈计划 | 目标位、分批比例、余仓跟踪位、板块退潮处理 |
| 次日验证 | 需要观察的开盘、承接、量价、板块和收盘条件 |
| 最终复盘 | 是否按计划执行、触发何种退出、偏差原因和改进项 |

## 八、盘后统计：把规则从经验变成系统

记录的目的不是证明某次判断对错，而是识别哪类交易在什么条件下有稳定优势。

建议按以下维度统计：

- **交易模式 × 入场时段**：胜率、盈亏比、滑点、最大不利波动、失败类型；
- **交易模式 × 止损类型**：平均亏损、止损后修复比例、是否止损过慢或过紧；
- **交易模式 × 止盈方式 × 市场环境**：平均收益、最大浮盈、利润回吐、过早卖出比例和总体期望值；
- **板块与情绪阶段**：上升、分歧、退潮时，哪类模式仍有效、哪类应停止；
- **执行偏差**：未按交易卡执行的次数、原因和造成的额外损失。

只有样本中显示出稳定优势，固定时段、固定百分比或固定天数才可以升级为个人硬规则；否则，它们只是待验证的假设。

## 九、最终的统一规则

> **先选模式，再定前提；先定失效，再算仓位；先等确认，再执行买入；持有期间持续验证；逻辑失效先退出，利润兑现再管理；组合风险永远优先于单股执念。**

简化为实际执行的九步：

1. 判断市场、情绪和板块是否允许交易；
2. 明确交易模式，不混用不同模式的规则；
3. 定义位置、触发条件、失效位与时间预期；
4. 用风险距离决定仓位，风险收益比不足就放弃；
5. 在匹配该模式的时段等待量价和结构确认；
6. 买入后只按预先写好的持有验证项判断强弱；
7. 结构、事件或组合风险失效时优先退出；
8. 达到目标位或出现高位兑现信号时分批锁盈，余仓按趋势跟踪；
9. 盘后记录结果，并用统计修正规则，而不是用下一笔交易证明自己。

**本章结论：**真正的买入、持有与卖出规则，不是寻找一个永远正确的买点、止损点或止盈比例，而是把每笔交易变成可事前定义、可盘中验证、可事后统计的风险决策。规则的价值在于让你在不确定的市场中保持一致性：条件齐备才参与，条件变化就调整，证据被推翻就退出。
