# 如何判断市场环境

看市场环境，核心不是把每个指标单独打分，而是观察三条链是否一致：

1. **价格与量能**：指数是否有趋势，成交是否支持趋势。
2. **情绪与风险偏好**：市场宽度、涨跌停、连板和高低位反馈。
3. **资金选择**：板块持续性、成交额集中度和大成交额个股的主动性。

公告、政策和外围市场属于外部风险变量，用来修正判断，不能单独代替盘面证据。

## 先做再学：用一张卡完成 20 个交易日的市场环境练习

先打开本总览的练习卡，连续记录 20 个已收盘交易日，再按编号阅读 01 至 09 的详细解释。每天只做一次盘后记录，先写事实，再读理论；不要因为当天涨跌结果而临时修改记录口径。

一次练习的完成标准是：完成 8 组事实记录，写出 3 条证据链，选出 1 个环境标签，标注 1 个置信度，并预先写下 1 个次日验证项。练习输出的是环境观察结论，不是对明日涨跌的预测，也不直接生成买卖指令。

### 第 0 步：先检查数据能不能用

先核对所有数据是否属于同一个交易日，以及样本、涨跌停制度、停牌处理和板块分类口径是否与前一日一致。

- 价格、市场宽度或短线风险数据存在关键缺口：当天结论写“数据不足”，记录缺失字段和补齐方式。
- 事件只有截图、传闻或无法追溯的来源：保留为线索，不能当作事实证据。
- 单项数据来源降级但字段完整：记录来源和警告，降低置信度，继续使用可验证结果。
- 不把缺失值、无法计算的分母或未核实事件填成 0，也不使用其他日期的数据回填。

“数据不足”是有效结果，表示当天没有足够证据形成环境判断。

### 第 1 步：按顺序记录八组事实

每天只抄录下表内容，不急着写“强”“弱”或“好”“坏”。第一次练习可以使用看板已有结果；看板没有提供的字段，记录原始数据和缺口，不凭感觉补写。

| 序号 | 数据组 | 当日必须记录 |
|---:|---|---|
| 1 | 指数、趋势位置和成交额 | 五大指数方向、MA20 上下数量、成交额相对 5 日/20 日均值、放量后价格是否推进 |
| 2 | 上涨家数、下跌家数和涨跌幅中位数 | 上涨/下跌/平盘家数、上涨占比、涨跌家数差、全 A 涨跌幅中位数 |
| 3 | 涨停、跌停、炸板和连板晋级 | 涨停数、跌停数、炸板数和炸板率、晋级数和晋级率、最高板及梯队 |
| 4 | 高位、中位和低位股亏钱效应 | 各层样本数、涨跌和断板反馈、集中亏损、失败样本修复情况 |
| 5 | 主线持续性和成交额集中度 | 候选板块 3 日/5 日相对强度、板块宽度、成交集中度、核心和分歧承接 |
| 6 | 大成交额个股主动进攻 | 成交额前 30 的方向分组、同方向数量、成交放大、相对收益、收盘强度和板块跟随 |
| 7 | 公告、政策、外围和突发事件 | 来源、首次发布时间、影响路径、是否提前交易、价格成交和板块宽度是否确认 |
| 8 | 如何归类市场环境 | 三条证据链方向、系统性风险检查、趋势/轮动/退潮/混合候选 |

记录时保留数字、样本数和数据状态。例如写“上涨占比 62%、中位数 +0.48%、炸板率 18%、高位样本 12 只”，不要只写“市场情绪较好”。

### 第 2 步：把八组事实合成三条证据链

先把每条链标记为“改善、混合、恶化或数据不足”，并写出支持它的数字：

1. **价格与量能**：由指数方向、均线位置和成交后的价格推进组成，回答市场是否有趋势基础。
2. **情绪与风险偏好**：由市场宽度、涨跌停生态和高中低位亏钱效应组成，回答多数股票是否参与、接力是否健康、风险是否扩散。
3. **资金选择**：由主线持续性、成交额集中度和容量股表现组成，回答资金是否聚焦同一方向并能持续承载。

第 7 组外部事件只用于修正预期：先核实事实和影响路径，再检查盘面确认；没有成交、价格、宽度和核心股反馈时，不改变前三条证据链的结论。

### 第 3 步：按固定优先级选一个环境标签

归类顺序固定为“数据质量 → 系统性风险 → 证据共振 → 结构性轮动 → 证据冲突”：

1. **数据不足**：关键输入缺失、日期错位或样本口径无法确认。
2. **退潮**：放量破位、跌停扩散、炸板率上升、晋级率下降，以及高中低位风险共同恶化；风险否决优先于局部机会。
3. **趋势**：没有系统性风险，三条证据链大体同向，指数和宽度得到成交支持，主线与容量进攻具有持续性。
4. **轮动**：指数相对稳定，但热点快速切换，成交集中度和主线候选反复变化，缺少连续承接。
5. **混合**：权重与题材、指数与多数股票、核心与后排等方向明显冲突；必须写明谁强谁弱。

单日涨停增加、单只容量股上涨或一条利好消息都不足以单独改变环境标签。证据不一致时保留“混合”，不要强行用简单计票得出趋势或退潮。

### 第 4 步：填写综合判断卡

```text
日期：____；数据状态：完整／降级／数据不足。
价格与量能：____；情绪与风险偏好：____；资金选择：____。
主要证据 1：____；主要证据 2：____；反证或缺口：____。
内部结构：____强、____弱；外部事件修正：____。
今日环境：趋势／轮动／退潮／混合／数据不足。
置信度：高／中／低／不足；依据：____。
下一交易日只验证：____。
确认条件：____；失效条件：____；仍不明确：____。
```

置信度表示证据的完整度、一致性和持续性：三条证据链一致且有连续或分歧后承接为高；两条一致但缺少持续验证为中；主要依赖单日、单只股票或单条事件为低；关键数据缺失为不足。置信度不能理解为上涨概率。

### 第 5 步：次日只验证预先写下的一项

第二天先重新完成全部八组记录，再检查昨天的唯一验证项。选择验证项时按以下顺序：

1. 先验证昨天的数据缺口是否补齐；
2. 没有缺口时，验证最可能推翻结论的反证项；
3. 没有反证时，验证处于混合区的关键项；
4. 全部证据已确认时，验证市场宽度、主线承接或容量进攻能否持续。

结果只记为“确认、失效或仍不明确”。不要根据次日结果回头修改昨天的确认条件和失效条件。

### 第 6 步：在第 5、10、20 个交易日复盘练习质量

每次阶段复盘统计：

- 哪类环境标签最容易被次日推翻；
- 错误来自数据缺失、口径变化、忽略风险，还是把单日爆发当成持续趋势；
- 三条证据链中哪一条最常与其他证据冲突；
- 哪个验证项最能区分确认、失效和仍不明确；
- 自己是否把环境标签越过了独立的入场、止损和仓位规则。

完成 20 天后，再决定是否需要调整字段或补充指标。没有连续记录时，不根据印象修改阈值。



#### 1. 指数、趋势位置和成交额

同时看上证、深成指、创业板、沪深300、中证500等，避免只看一个指数。

建议记录：

- 当日涨跌幅；
- 收盘价相对5日、10日、20日、60日均线的位置；
- 20日、60日区间中的位置：

```Plain Text
N日位置 = (当前收盘价 - N日最低价) / (N日最高价 - N日最低价)
```

- 当日成交额与5日、20日均值的比值；
- 成交额增加后，价格是否真正推进。

常见解释：

- **上涨、放量、突破或沿均线运行**：趋势得到成交支持。
- **上涨、缩量、但只有少数权重股推动**：可能是指数虚强。
- **放量但指数滞涨**：成交被更高价格接受的程度下降，需警惕分歧或派发。
- **下跌缩量、市场宽度未恶化**：可能是正常回调。
- **下跌放量、跌破关键均线且广度恶化**：风险级别提高。

成交额本身不是利好或利空，关键看“成交之后价格有没有取得进展”。



#### 2. 上涨家数、下跌家数和涨跌幅中位数



至少记录：

- 上涨家数、下跌家数、平盘家数；
- 涨跌家数差；
- 全市场涨跌幅中位数；
- 上涨/下跌家数的5日变化趋势。

中位数很重要，因为指数可能被少数大市值股票影响。比如：

- 指数上涨，但上涨家数少、涨跌幅中位数为负：权重行情，个股环境偏弱。
- 指数下跌，但上涨家数多、中位数转正：可能是指数调整而个股修复。
- 上涨家数持续扩大、中位数连续为正：市场参与面改善。
- 下跌家数扩大、中位数持续为负：亏钱效应扩散。

必须保证股票样本、交易日期和停牌处理口径一致，不能把缺失数据当成下跌或上涨。



#### 3. 涨停、跌停、炸板和连板晋级

重点看结构，不只是数量：

- 涨停家数和跌停家数；
- 炸板数量及炸板率；
- 最高连板高度；
- 2板、3板、4板以上的分布；
- 昨日首板晋级率、昨日高位股次日反馈；
- 涨停是否集中在同一个板块。



可以使用：

```Plain Text
炸板率 = 炸板数 / (涨停数 + 炸板数)
晋级率 = 今日晋级数 / 昨日具备晋级资格的样本数
```



大致判断：

- **涨停增加、跌停减少、晋级率上升、最高板抬高**：情绪改善。
- **涨停不少但炸板增加、晋级率下降**：表面热闹，接力质量变差。
- **跌停扩散、最高板压缩、高位股断板增多**：退潮风险。
- **涨停集中于单一板块，其他方向无跟随**：可能是局部脉冲，不一定是全市场转强。

新股、ST股、不同涨跌幅制度的股票最好分开统计，否则梯队会被特殊样本扭曲。



#### 4. 高位股、中位股和低位股的亏钱效应

要先固定分组规则，不能根据当天结果临时划分。例如：

- 高位股：最高连板、近期市场核心、20日高位股；
- 中位股：2至3板、前期强势但尚未成为最高标的股票；
- 低位股：首板、低位启动或尚未形成高度的股票。

分别观察：

- 高开后能否继续走强；
- 盘中冲高回落幅度；
- 收盘价距离当日最高价的程度；
- 断板、跌停、连续下跌数量；
- 次日竞价和开盘承接；
- 所属板块是否同步转弱。

典型结构：

- **高位强、中位稳、低位扩散**：情绪健康，市场可能在扩散。
- **高位弱、中位弱、低位突然活跃**：旧周期退潮、新周期尚未确认。
- **高位弱、低位也弱**：整体风险偏好下降。
- **指数稳定，但高位股连续亏钱**：属于指数与题材分化，不能简单定义为强势市场。

“亏钱效应”不是看某一只股票跌了多少，而是看同类股票是否连续出现冲高回落、断板、低开和无法修复。



#### 5. 主线持续性和成交额集中度

一个板块成为主线候选，至少需要满足几项：

- 3日或5日相对强度持续；
- 不只有一只龙头，存在中军、补涨和一定宽度；
- 板块成交额能够持续承载资金；
- 核心股分歧后仍有承接；
- 市场转弱时仍保持相对强度；
- 有可验证的政策、产业或事件催化。

可以计算：

```Plain Text
前五板块成交额集中度
= 成交额最大的五个板块成交额 / 全市场成交额
```

也可以使用HHI等集中度指标，但必须固定板块分类口径。



解释时要区分：

- **集中度高、板块宽度扩大、核心股强、连续性好**：主线可能正在形成。
- **集中度高，但只有一两只股票上涨**：可能是抱团或单点脉冲。
- **集中度低、热点每天切换**：典型轮动环境。
- **板块涨幅高但成交额和持续性下降**：可能是情绪末端。

涨幅第一的板块不自动等于主线，持续性和承载成交的能力更重要。



#### 6. 大成交额个股中是否出现主动进攻方向

“大成交额”不等于“主动进攻”。应从成交额排名中筛选股票，再观察：

- 是否明显跑赢对应指数；
- 是否出现成交额放大；
- 收盘是否接近日内高位；
- 是否突破整理区间或关键高点；
- 同一板块是否有多只大成交额个股同步走强；
- 板块宽度和涨停梯队是否跟随；
- 是否连续两至三天保持相对强度。

主动进攻通常表现为：

```Plain Text
成交额增加 + 价格有效推进 + 收盘强 + 板块有跟随
```



以下情况不能轻易定义为主动进攻：

- 只有一只股票因公告大涨；
- 指数权重股被动拉升；
- ETF调仓、分红、回购等造成异常成交；
- 放量但收盘接近日内低位；
- 个股上涨，板块其他股票没有响应。

“新方向”至少要有两三只容量较大的股票共同表现，并在后续交易日得到持续性验证。



#### 7. 公告、政策、外围和突发事件



每个事件都按五个问题检查：

1. 来源是否可靠，发布时间是什么时候？
2. 影响的是指数、行业还是单只股票？
3. 影响路径是什么：盈利、供给、需求、监管还是风险偏好？
4. 市场是否已经提前交易？
5. 盘面是否出现与事件一致的成交和价格反馈？

可分为：

- **系统性风险**：利率、汇率、海外市场大跌、流动性冲击；
- **行业风险**：监管、价格、供需、政策变化；
- **个股风险**：业绩、问询、诉讼、减持、停牌等；
- **突发事件**：灾害、地缘冲突、重大事故等。

事件分析应写成：

```Plain Text
事件事实 -> 可能影响 -> 已反映程度 -> 盘面验证 -> 失效条件
```

不要因为一条新闻标题就认定主线切换。真正需要关注的是事件出现后，相关板块是否有成交、宽度和核心股反馈。

#### 8. 最后如何归类市场环境

可以把市场归为四类：

| 市场状态 | 典型特征 |
|-|-|
| 趋势 | 指数趋势清晰，成交维持，广度改善，主线持续，高位反馈稳定 |
| 轮动 | 指数尚可，但板块切换快，集中度不稳定，追涨反馈较差 |
| 退潮 | 跌停扩散，炸板率和断板增加，晋级率下降，高中位股亏钱 |
| 混合 | 权重与小票、指数与题材、主线与防御方向明显分化 |

盘后可以用下面这句话收束：

> 指数和量能显示\_\_\_\_；市场宽度显示\_\_\_\_；涨跌停和连板梯队显示\_\_\_\_；高中低位反馈显示\_\_\_\_；主线成交和持续性显示\_\_\_\_；外部事件风险为\_\_\_\_。因此当前更接近\_\_\_\_环境，置信度为\_\_\_\_，下一交易日重点确认\_\_\_\_。



置信度建议这样定：

- **高**：指数、市场情绪、板块资金三层证据一致；
- **中**：有两层证据一致，但缺少次日承接或分时数据；
- **低**：主要依赖单日涨跌、单只股票或单条新闻。
