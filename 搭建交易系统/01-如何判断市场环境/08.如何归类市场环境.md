# 8.如何归类市场环境



文档里“如何判断市场环境”的核心，不是把某一个指标判定为好或坏，而是看 **价格与量能、情绪与风险偏好、资金选择** 三条证据链是否相互印证，最后归类为 **趋势、轮动、退潮、混合** 四种环境。

---

## 一、先看三条证据链

### 1. 价格与量能：市场有没有趋势基础

主要看：

- 上证、深成指、创业板、沪深300、中证500是否同向；
- 指数处于5日、10日、20日、60日均线什么位置；
- 是否突破、回踩、震荡或跌破关键位置；
- 成交额相对5日、20日均值是放大还是缩小；
- 放量之后，价格有没有真正向上推进。

#### 能得到什么信息

| 盘面组合 | 说明 |
|-|-|
| 上涨＋放量＋突破关键位置 | 趋势得到资金确认 |
| 上涨＋缩量＋多数指数同步 | 可以继续上涨，但趋势强度一般 |
| 上涨＋缩量＋只有权重推动 | 指数可能虚强，个股体验未必好 |
| 放量但指数滞涨、冲高回落 | 分歧加大，可能存在兑现或派发 |
| 下跌＋缩量＋市场宽度稳定 | 更接近正常回调 |
| 下跌＋放量＋跌破均线＋广度恶化 | 风险升级，可能进入退潮 |
| 各指数明显分化 | 市场可能处于混合或结构性行情 |

**关键原则：成交额本身不是利好或利空，要看成交之后价格有没有取得进展。**

### 2. 情绪与风险偏好：多数股票是否好做

主要看：

- 上涨家数、下跌家数；
- 全市场涨跌幅中位数；
- 涨停、跌停数量；
- 炸板率、连板晋级率、最高连板高度；
- 高位股、中位股、低位股的次日反馈；
- 冲高回落、断板、低开、跌停是否成批出现。

#### 市场宽度能得到什么信息

| 数据表现 | 说明 |
|-|-|
| 指数上涨，但中位数为负、下跌家数更多 | 权重拉指数，个股环境偏弱 |
| 指数下跌，但上涨家数更多、中位数为正 | 指数调整，个股可能正在修复 |
| 上涨家数持续扩大、中位数连续为正 | 赚钱效应正在扩散 |
| 下跌家数持续扩大、中位数连续为负 | 亏钱效应正在扩散 |

#### 涨跌停和接力结构能得到什么信息

| 数据表现 | 说明 |
|-|-|
| 涨停增加、跌停减少、晋级率提升、最高板抬高 | 情绪改善 |
| 涨停不少，但炸板率上升、晋级率下降 | 表面热闹，实际接力质量下降 |
| 跌停扩散、高位断板、最高板压缩 | 退潮风险明显 |
| 涨停集中在一个板块，其他方向无响应 | 局部行情，不代表全市场转强 |

#### 高中低位反馈能得到什么信息

| 结构 | 说明 |
|-|-|
| 高位强、中位稳、低位扩散 | 情绪健康，主线可能向外扩散 |
| 高位弱、中位弱、低位活跃 | 旧周期退潮，新周期处于试错阶段 |
| 高位弱、低位也弱 | 整体风险偏好下降 |
| 指数稳定、高位股连续亏钱 | 指数与题材分化，属于混合环境 |

这里最重要的是：**不要根据一只股票判断亏钱效应，要看同类股票是否成批出现断板、低开、冲高回落和无法修复。**

### 3. 资金选择：市场有没有稳定主线

主要看：

- 板块3日、5日相对强度；
- 热点是否每天切换；
- 强势板块是否有龙头、中军、补涨和板块宽度；
- 核心股分歧后是否有承接；
- 板块成交额能否持续；
- 前五板块成交额集中度；
- 大成交额个股中是否出现共同进攻方向。

#### 能得到什么信息

| 资金结构 | 说明 |
|-|-|
| 集中度提升＋板块宽度扩大＋核心股强＋持续性好 | 主线正在形成或强化 |
| 集中度高，但只有一两只股票上涨 | 单点抱团，不是真正的板块主线 |
| 集中度低、热点每天切换 | 典型轮动环境 |
| 板块涨幅很高，但成交下降、宽度收窄 | 可能接近情绪末端 |
| 多只大成交额个股同板块放量上涨、收盘强 | 机构或容量资金主动进攻 |
| 大成交额个股放量但冲高回落、收盘弱 | 可能是分歧、兑现或派发 |
| 只有一只公告股大涨，板块没有响应 | 个股事件，不代表新方向 |

主动进攻需要满足：

> **成交额增加＋价格有效推进＋收盘位置强＋同板块有跟随＋后续能够持续**

不能因为“成交额很大”就认为资金进攻，也不能因为某板块一天涨幅第一，就认定它是主线。

## 二、如何归类为四种市场环境

### 1. 趋势环境

#### 典型特征

- 多个主要指数方向一致；
- 指数沿均线运行或突破关键位置；
- 成交额能够维持；
- 上涨家数扩大，中位数为正；
- 涨停结构健康，跌停较少；
- 高位核心稳定，中低位存在扩散；
- 主线持续，核心股分歧后有承接；
- 大成交额个股出现共同进攻方向。

#### 能得到的结论

市场存在较明确的方向，资金愿意持续持仓和接力，赚钱效应不局限于个别股票。

#### 操作含义

- 可以适当提高仓位；
- 优先围绕主线和核心股交易；
- 趋势回踩通常比追逐临时热点更有性价比；
- 但要防范放量滞涨、主线宽度收缩和高位股集体转弱。

### 2. 轮动环境

#### 典型特征

- 指数整体稳定，但缺乏持续突破；
- 成交额不足以支持多个方向同时上涨；
- 板块一天一换，持续性差；
- 成交额集中度不稳定；
- 昨日强势方向次日容易分化；
- 追涨反馈较差；
- 高位板块兑现后，资金迅速切换到低位方向。

#### 能得到的结论

市场不是完全没有机会，而是资金存量博弈明显。一个方向上涨，往往以另一个方向回落为代价。

#### 操作含义

- 不把单日最强板块自动当成主线；
- 少追一致高潮，重视分歧低吸和兑现；
- 缩短持股周期；
- 控制仓位，避免同时铺太多方向；
- 重点确认板块能否连续两三天保持强度。

### 3. 退潮环境

#### 典型特征

- 指数跌破关键位置或放量下跌；
- 下跌家数扩大，中位数持续为负；
- 跌停增加、炸板率上升；
- 连板晋级率下降，最高板高度压缩；
- 高位股、中位股成批断板和低开；
- 核心股分歧后缺乏承接；
- 主线成交和宽度同步下降；
- 大成交额个股普遍冲高回落或主动下跌。

#### 能得到的结论

资金风险偏好下降，亏钱效应正在从局部向更大范围扩散。此时“看起来便宜”并不等于风险已经释放完毕。

#### 操作含义

- 降低仓位和交易频率；
- 避免接力高位股；
- 不因单日反弹就判断退潮结束；
- 等待跌停收敛、高位止跌、中位修复、上涨家数回升等信号；
- 反弹是否有效，要看次日承接，而不是只看当天涨幅。

### 4. 混合环境

#### 典型特征

- 权重上涨，小票下跌；
- 指数稳定，但题材股亏钱；
- 创业板强，上证弱，或者相反；
- 主线仍强，但多数板块退潮；
- 防御板块与进攻板块同时活跃；
- 市场宽度一般，但少数容量方向非常强。

#### 能得到的结论

市场不能简单定义为“强”或“弱”，不同风格、不同位置、不同板块之间存在明显分化。

#### 操作含义

- 明确自己交易的是权重、题材、趋势还是短线接力；
- 不用上证指数的强弱替代个股环境；
- 只参与证据一致的局部方向；
- 降低对“全面牛市”或“全面退潮”的笼统判断；
- 仓位通常应低于明确趋势环境。

## 三、最实用的归类顺序

### 第一步：先判断有没有系统性风险

观察：

- 是否放量下跌；
- 是否跌破关键均线；
- 下跌家数和跌停是否扩散；
- 高位、中位、低位是否同时转弱。

如果四项大多成立，优先归入 **退潮环境**，不要急着寻找局部利好。

### 第二步：如果没有明显退潮，看有没有趋势共振

观察：

- 指数是否同向；
- 量价是否配合；
- 市场宽度是否改善；
- 主线是否持续；
- 高位核心是否稳定；
- 大成交额个股是否共同进攻。

大多数证据一致，归入 **趋势环境**。

### 第三步：指数稳定但主线不持续

如果：

- 指数没问题；
- 热点每天切换；
- 追涨反馈差；
- 成交额集中度不稳定；

归入 **轮动环境**。

### 第四步：不同层面结论冲突

例如：

- 指数强、个股弱；
- 权重强、题材弱；
- 主线强、市场宽度弱；
- 高位弱、低位活跃；

归入 **混合环境**，并明确写出“谁强、谁弱”，不能只写“震荡”。

## 四、外部事件怎么参与判断

公告、政策、外围和突发事件只负责 **修正判断**，不能单独决定市场环境。

建议按以下链条分析：

> **事件事实 → 影响路径 → 市场是否提前交易 → 盘面是否验证 → 失效条件**

例如出现行业利好后，需要继续检查：

- 相关板块成交额是否增加；
- 上涨是否具有板块宽度；
- 是否有多只核心股共同上涨；
- 大成交额股票是否主动进攻；
- 次日有没有承接；
- 市场整体风险偏好是否支持该方向。

如果只有新闻、没有成交、价格、宽度和核心股反馈，只能把它定义为 **观察线索**，不能认定主线启动。

## 五、盘后最终结论应该怎么写

可以直接使用下面的模板：

> 指数方面，主要指数呈现\_\_\_\_，价格处于\_\_\_\_位置，成交额较近期均值\_\_\_\_，量价关系说明\_\_\_\_。  
> 市场宽度方面，上涨家数\_\_\_\_，涨跌幅中位数\_\_\_\_，说明个股环境\_\_\_\_。  
> 情绪方面，涨停、跌停、炸板率和晋级率显示\_\_\_\_；高位、中位和低位反馈表现为\_\_\_\_。  
> 资金方面，板块成交集中度\_\_\_\_，主线持续性\_\_\_\_，大成交额个股显示\_\_\_\_。  
> 外部事件方面，**可能影响**，但盘面目前\_\_\_\_验证。  
> 综合来看，当前更接近 **趋势／轮动／退潮／混合** 环境，判断置信度为 **高／中／低**。下一交易日重点确认\_\_\_\_。

### 置信度标准

- **高置信度**：指数、情绪、资金三条证据链方向一致；
- **中置信度**：两条证据链一致，但缺少次日承接或持续性验证；
- **低置信度**：主要依赖单日涨跌、单只股票或单条新闻。

最重要的一句话是：

> **市场环境不是由“指数今天涨没涨”决定，而是由指数趋势、个股宽度、情绪反馈和资金持续性共同决定。**
