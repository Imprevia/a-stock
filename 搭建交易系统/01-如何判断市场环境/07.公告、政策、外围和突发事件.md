# 7.公告、政策、外围和突发事件

这一部分的核心原则是：

公告、政策、外围和突发事件是“外部变量”，用于修正市场判断；盘面的成交、价格、板块宽度和核心股反馈，才是最终证据。

不能因为看到一条利好或利空新闻，就直接判断主线切换、行情启动或风险落地。

---

## 先做再学：每遇到事件先填一张验证卡

选最近一条可能影响市场的公告、政策、外围变化或突发事件，先完成下面的卡片，再阅读观点和行情解读。练习至少积累 5 个事件样本。

### 第 1 步：只写可核实事实

| 问题 | 记录内容 |
|---|---|
| 来源可靠吗 | 原始发布机构、原文链接或公告编号 |
| 信息何时首次公开 | 精确到交易前、盘中或盘后，是否为旧闻重发 |
| 影响路径是什么 | 先影响哪个变量、行业、公司或风险偏好 |
| 市场是否提前交易 | 事件前价格、成交和预期是否已经明显变化 |
| 盘面是否确认 | 相关板块的相对收益、成交、宽度、容量核心和次日承接 |

来源无法追溯时写“未核实”；发布时间不清时写“时效不明”。两种情况都只保留为线索，不给事件方向加分。

### 第 2 步：给事件一个状态

- **事实已核实、影响未确认**：事件真实，但市场尚未出现共同定价。
- **盘面确认**：价格有效推进、成交增加、板块扩散和容量核心至少形成相互支持的证据。
- **预期已交易**：事件公布后没有进一步价格推进，或出现利好兑现、利空不跌。
- **证伪或失效**：原始信息被否认、影响路径未发生，或盘面走出相反结果。
- **信息不足**：来源、时间或相关行情缺失。

### 第 3 步：提前写出验证条件

```text
事件：____；来源与首次发布时间：____。
预期影响路径：____；当前事件状态：____。
下一交易日验证数据：相关板块的____、____和____。
确认条件：____；失效条件：____；仍不明确：____。
```

第二天先看盘面结果，再看新的解释文章。累计 5 个事件后，比较“消息方向”和“市场实际定价”是否一致。事件卡只能修正原有环境判断，不能替代价格、成交、宽度和承接证据。

## 一、所有事件都先过“五问”

不管是政策、公司公告、海外市场波动，还是突发事件，都按下面五个问题检查。

### 1. 来源可靠吗？发布时间是什么时候？

先分辨信息级别：

- 官方部门、交易所、上市公司正式公告；
- 公司官微、权威媒体报道；
- 行业传闻、社群截图、自媒体解读；
- 已经发布多日的旧消息被重新传播。

能得到的信息：

| 信息状态 | 应对 |
|-|-|
| 官方正式文件 / 公司公告 | 可作为事件事实 |
| 权威媒体转述，但原始文件未见 | 先核实，不急于交易 |
| 小作文、截图、传闻 | 只能作为观察线索 |
| 盘后消息、夜间海外消息 | 次日开盘前重点评估预期差 |
| 盘中突发且未核实 | 不宜追涨杀跌，先看市场如何定价 |

关键不是“消息听起来有多大”，而是它是否可靠。
