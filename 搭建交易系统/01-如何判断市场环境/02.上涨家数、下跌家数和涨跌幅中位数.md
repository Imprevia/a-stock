# 2.上涨家数、下跌家数和涨跌幅中位数

## 2. 上涨家数、下跌家数和涨跌幅中位数

这一组数据用来判断**市场宽度**：当天的涨跌，是少数权重股造成的指数表象，还是大多数股票共同参与的真实行情。

> **指数看表面方向；上涨/下跌家数看参与面；涨跌幅中位数看多数股票的真实体感。三者一致，市场结论才更可靠。**

### 一、三个指标分别看什么

| 指标 | 作用 | 核心含义 |
|-|-|-|
| 上涨家数 / 下跌家数 | 看涨跌覆盖面 | 多数股票是在赚钱还是亏钱 |
| 涨跌家数差 | 看多空力量 | 上涨家数减下跌家数；越大代表普涨越明显，越负代表杀跌越广 |
| 涨跌幅中位数 | 看典型股票的真实体感 | 将所有股票涨跌幅排序后取中间值，不容易被少数大盘权重扭曲 |

建议每日至少记录：

1. 上涨、下跌、平盘家数；
2. 涨跌家数差；
3. 全市场涨跌幅中位数；
4. 上涨/下跌家数与中位数的近5日变化趋势；
5. 与指数、成交额、涨停/跌停数量是否一致。

### 二、为什么涨跌幅中位数很重要

指数会受到少数大市值股票影响；但中位数反映的是“处于市场中间位置的那只股票”当天的涨跌，更接近多数持仓的实际体验。

- **中位数为正**：超过一半的有效样本倾向于上涨，个股赚钱效应相对较好。
- **中位数为负**：超过一半的有效样本倾向于下跌，多数股票体感偏弱。
- **中位数接近零**：多空相对均衡，常见于震荡或快速轮动。

因此，不能只问“指数涨没涨”，还要问：**多数股票今天有没有涨、涨得是否持续。**

### 三、常见组合如何解读

| 组合 | 可能含义 | 操作关注点 |
|-|-|-|
| 指数上涨 + 上涨家数少 + 中位数为负 | 权重拉指数、个股偏弱，可能是指数虚强 | 不因指数上涨就提高题材股仓位 |
| 指数下跌 + 上涨家数较多 + 中位数为正 | 权重调整、个股修复，未必是全面走弱 | 看中证500、创业板和主线板块是否承接 |
| 上涨家数持续扩大 + 中位数连续为正 | 市场参与面改善，普涨或趋势修复可信度提高 | 若指数、量能也配合，可提高进攻关注度 |
| 下跌家数扩大 + 中位数持续为负 | 亏钱效应扩散，风险偏好走弱 | 降低追涨，重点防范高位股补跌 |
| 指数震荡 + 涨跌家数反复切换 + 中位数接近零 | 轮动、震荡环境 | 控制持股周期，不把单日热点当主线 |

### 四、重点识别“指数虚强”与“个股修复”

#### 1. 指数虚强

若出现以下组合：

- 上证指数、沪深300上涨；
- 创业板或中证500走弱；
- 上涨家数偏少；
- 涨跌幅中位数为负；
- 成交额没有扩散到更多板块。

说明上涨可能主要由银行、保险、石油、白酒等权重股推动。指数看起来较强，但中小盘和题材股未必具备赚钱效应。

#### 2. 个股修复

若指数小跌或横盘，但同时：

- 上涨家数较多；
- 涨跌幅中位数为正；
- 创业板、中证500相对更强；
- 主线板块仍有承接。

则可能是少数权重调整拖累指数，而多数个股正在修复。此时应继续核对成交额和板块持续性，而不是直接按全面退潮处理。

### 五、不要只看单日，要看5日趋势

单日数据容易受突发消息、权重调仓或指数尾盘拉升影响。更有价值的是观察连续变化：

- **连续3天上涨家数增加，中位数由负转正并持续抬升**：市场可能从修复走向扩散。
- **指数横盘或小涨，但中位数连续走弱**：表面稳定、内部转弱，要警惕风险。
- **指数下跌，但中位数改善**：可能是权重调整，不必直接等同全面退潮。
- **指数、上涨家数、中位数、成交额同步改善**：强势判断的置信度最高。

### 六、与指数、趋势位置和成交额联合判断

| 组合 | 市场解读 |
|-|-|
| 指数上涨 + 成交放大 + 上涨家数扩大 + 中位数为正 | 较真实的普涨或趋势增强 |
| 指数上涨 + 成交额一般 + 上涨家数少 + 中位数为负 | 权重拉指数，个股环境偏弱 |
| 指数下跌 + 下跌家数扩大 + 中位数走弱 + 放量 | 风险扩散，偏防守 |
| 指数震荡 + 宽度指标来回切换 + 中位数接近零 | 轮动环境，不宜追高 |
| 指数下跌 + 多数股票上涨 + 中位数为正 | 权重调整与个股修复并存，需区分风格 |

### 七、每日盘后记录模板

1. **市场宽度**：上涨、下跌、平盘家数分别是多少？涨跌家数差是多少？
2. **真实体感**：全市场涨跌幅中位数为正、为负，还是接近零？
3. **连续性**：与前一日、近5日相比，宽度是在改善还是恶化？
4. **指数验证**：宽度是否与上证、沪深300、创业板、中证500的表现一致？
5. **量能验证**：成交额是否支持上涨家数扩散，还是只有权重股放量？
6. **情绪验证**：涨停、跌停、炸板、高位股反馈是否印证宽度变化？

可以用下面的句式收束：

> 今日上涨/下跌家数为\_\_\_\_/**，涨跌家数差为**，全市场涨跌幅中位数为\_\_\_\_；相较近5日，市场宽度在改善/恶化。结合指数表现与成交额，当前属于普涨、权重偏强、个股修复、轮动或风险扩散环境。

> **一句话总结：**指数告诉你市场表面怎么走，涨跌家数告诉你有多少股票参与，涨跌幅中位数告诉你多数股票到底赚没赚钱。
