# 5.主线持续性和成交额集中度



<callout emoji="💡">
**核心结论：**主线持续性回答“资金炒的方向能否从一天热点演变为可跟踪趋势”；成交额集中度回答“全市场资金是聚焦少数方向，还是四处扩散”。两者必须结合判断。
</callout>

## 一、如何判断市场环境的主线持续性

判断一个板块是不是主线，不能只看当天涨幅，而要看其是否具备**连续性、结构性、抗分歧能力和资金承载力**。

### 1. 看 3 日 / 5 日相对强度是否持续

把板块和大盘对比：大盘涨 1%、板块涨 3%属于强势；大盘跌 1%、板块仅跌 0.2%甚至翻红则更强。连续 3～5 天跑赢大盘，才开始具备主线候选资格。

| 现象 | 解读 |
|-|-|
| 连续跑赢大盘 | 有持续资金流入，方向可能在强化 |
| 仅单日大涨，随后明显掉队 | 更可能是消息刺激或轮动脉冲 |
| 大盘弱时仍抗跌 | 资金认可度高，主线质量较好 |
| 大盘涨它不涨、市场跌它大跌 | 主线地位正在削弱 |

真正强的主线不一定每天领涨，但通常在市场调整时更抗跌、在市场回暖时更容易先修复。

### 2. 看板块内部是否有“梯队”，而不只是单一龙头

一个健康主线通常有：**龙头**打开高度和吸引情绪，**中军**承接机构资金，**补涨股**扩散板块热度，以及一定数量的上涨个股形成板块宽度。

| 板块结构 | 含义 |
|-|-|
| 只有一只股涨，其余不跟 | 个股行情，不宜直接定义成主线 |
| 龙头 + 中军 + 补涨同时活跃 | 板块资金结构完整，主线可信度提高 |
| 涨停多但没有大成交中军 | 偏情绪投机，持续性要打折 |
| 中军放量、龙头稳定、补涨扩散 | 趋势性主线更健康 |
| 龙头滞涨、补涨冲高回落、后排掉队 | 主线可能进入退潮或高低切 |

**“龙头很强”不等于“板块很强”。**若资金无法扩散到中军、补涨和更多成分股，说明市场共识不足。

### 3. 看成交额能否连续承载资金

关注板块成交额是否连续数日处于市场前列、上涨时是否放量、回调时是否缩量，以及核心股是否有承接。

| 成交与价格组合 | 解读 |
|-|-|
| 连续放量上涨 | 资金持续进攻，主线强化 |
| 放量但不涨、冲高回落 | 高位分歧加大，可能是兑现而非增量进场 |
| 缩量回调、核心股抗跌 | 良性分歧，仍可观察 |
| 放量下跌、核心股破位 | 资金撤离，主线风险上升 |
| 板块成交额持续萎缩 | 资金关注度下降，容易失去主线地位 |

成交额大不必然代表看多。高位巨量而价格不涨，常意味着多空分歧，甚至资金派发；必须结合涨跌幅、收盘位置和核心股走势判断。

### 4. 看分歧后的承接，而非只看一致高潮

主线最有价值的验证，常出现在首次分歧时：龙头炸板后能否回封或稳住；中军回落后是否有承接；板块回调时是否仍有个股逆势走强；次日是否能够修复，而非集体闷杀。

- 分歧后能修复：资金仍愿意做，主线延续概率较高。
- 首次分歧就全面走弱：多数只是短线情绪脉冲。
- 龙头弱、中军稳：可能由纯情绪炒作切换成趋势行情。
- 龙头和中军一起破位：需防主线退潮。

### 5. 催化要能被验证

政策、产业事件、业绩变化、产品涨价或技术突破，能够解释资金为何持续聚集。但催化只是加分项，不能替代盘面验证。

- 有催化，且量价、宽度、核心股均验证：主线可信度高。
- 有催化但没有成交和个股跟随：仍只是叙事。
- 没有明确消息，但持续强度、资金和结构都存在：也可能形成交易主线。

## 二、成交额集中度怎么看

基础公式：

```text
前五板块成交额集中度 = 成交额最大的五个板块成交额 ÷ 全市场成交额
```

例如：全市场成交额 1 万亿元，成交额最高的五个板块合计 3,000 亿元，则集中度为 30%。它反映全市场成交资金有多大比例集中在少数方向。

| 成交额集中度表现 | 常见市场含义 | 操作侧重点 |
|-|-|-|
| 集中度低，且板块轮动快 | 资金分散、没有共识主线 | 降低追高，更多等待或做低吸 |
| 集中度上升，前列板块持续不变 | 资金开始聚焦，主线正在形成 | 跟踪核心股与板块分歧机会 |
| 集中度高，且主线内部有宽度 | 市场共识强，趋势或进攻环境较好 | 围绕主线做，避免偏离资金方向 |
| 集中度高，但只集中在一两个高位股 | 抱团、博弈或尾部风险增加 | 不宜盲目追高，重点防高位分歧 |
| 集中度下降，原主线成交额持续萎缩 | 资金从主线流出，轮动或退潮 | 收缩仓位，重新寻找新方向 |
| 集中度突然飙升但价格冲高回落 | 大量换手和兑现，未必是增量进攻 | 观察次日承接，避免把巨量误判为强势 |

## 三、主线持续性 × 成交额集中度：组合判断

| 组合 | 判断与应对 |
|-|-|
| 主线强 + 集中度上升 | 最健康。龙头、中军、补涨均有表现，板块连续跑赢大盘且成交额居前；市场共识明确，可聚焦核心方向。 |
| 主线强 + 集中度过高 | 区分健康聚焦与高位抱团。若有宽度、中军和低位补涨，偏健康；若成交几乎只压在少数高位股、后排走弱，则抱团风险上升。宜等分歧承接，避免一致高潮追高。 |
| 主线弱 + 集中度高 | 风险较大。若核心股放量滞涨、冲高回落或破位，板块涨少跌多，高成交额可能是兑现、换手甚至出货，不能只因“钱多”就判断看多。 |
| 主线弱 + 集中度低 | 典型轮动或弱市。每天换热点、板块无连续性、成交额分散，追涨容易次日吃亏；应降低交易频率和仓位，等待新主线验证。 |

## 四、每日复盘记录清单

1. 前 5 板块成交额及集中度。
2. 这些板块与昨日、3 日前相比的排名变化。
3. 板块内部的上涨家数、涨停数、核心股表现和中军表现。
4. 主线在大盘转弱时是否抗跌。
5. 核心股出现分歧后，次日有没有修复。
6. 资金是从旧主线撤出、在旧主线内部高低切，还是转向新方向。

<callout emoji="📌">
**复盘最终要回答：**市场有无主线；主线处于启动、强化、分歧、修复还是退潮；资金是聚焦进攻、抱团博弈还是无序轮动；当前应聚焦、低吸、等分歧，还是控制仓位并减少交易。
</callout>
