# 1.指数、趋势位置和成交额

## 1. 目的与输出

本节把“指数方向、趋势阶段、成交额认可度和市场广度”转换为可计算规则。输出不是主观描述，而是四个分项分数和一个市场状态：

```text
S_sync    指数同步分，取值 -2～+2
S_trend   趋势结构分，取值 -2～+2
S_volume  量价分，取值 -2～+2
S_breadth 市场广度分，取值 -2～+2
S_total   综合环境分，取值 -2～+2
```

> **指数看方向，均线和区间位置看阶段，成交额看价格推进是否获得资金配合，市场广度验证指数是否代表多数股票。所有结论必须能由本节公式复算。**

本节只判断市场环境，不预测指数点位，也不单独产生个股买卖信号。

## 2. 数据口径和有效性

### 2.1 固定观察对象

| 指数 | 代码 | 代表范围 |
|-|-|-|
| 上证指数 | SH000001 | 沪市大盘股、金融和周期权重 |
| 深证成指 | SZ399001 | 深市成长、制造和消费 |
| 创业板指 | SZ399006 | 高弹性成长股 |
| 沪深300 | SH000300 | 两市核心大盘蓝筹 |
| 中证500 | SH000905 | 中盘股 |

方向和趋势使用五个指数的同一交易日收盘数据。量能默认使用**沪深A股全市场成交额**；如果只能取得指数成交额代理，必须单独标记口径，不能与全市场成交额历史混算。

### 2.2 计算约束

1. 所有滚动指标只使用当日及以前的数据；平台上沿、平台下沿和成交额基准只使用当日前的数据，防止未来函数。
2. 停牌、无有效前收盘价、上市首日以及数据异常股票不进入市场广度分母。
3. 缺失值不能填成0，也不能无条件用前值代替。
4. 五个指数有效数量记为 `N`。`N=5` 时正常计算；`N=4` 时允许计算但标记“覆盖率80%”；`N<4` 时同步分记为 `NA`，最终状态只能是“数据不足”。
5. 成交额缺失时 `S_volume=NA`；市场广度缺失时 `S_breadth=NA`。综合分只按有效维度重新归一化，但只要任一维度缺失，结论必须附带“低置信度”。
6. 计算MA60至少需要60个有效交易日；历史不足时对应指标记为 `NA`。
7. 若当日最高价等于最低价，收盘位置 `CLV` 记为0.5。

### 2.3 波动率尺度

对每个指数计算20日真实波幅均值：

```text
TR_t = max(high_t-low_t, |high_t-close_t-1|, |low_t-close_t-1|)
ATR20_t = 最近20日TR的平均值
ATR率_t = ATR20_t / close_t
```

固定百分比阈值只作为下限，优先用ATR归一化，避免同一阈值在高波动和低波动时期含义不同。

## 3. 指数方向与同步性

### 3.1 单个指数方向

```text
日收益率 r_i,t = close_i,t / close_i,t-1 - 1
方向阈值 d_i,t = max(0.30%, 0.25 × ATR率_i,t)
```

- 上涨：`r_i,t > d_i,t`
- 下跌：`r_i,t < -d_i,t`
- 横盘：`|r_i,t| ≤ d_i,t`

设上涨、下跌、横盘指数数量分别为 `U、D、F`，且 `U+D+F=N`。

### 3.2 同步状态和 `S_sync`

| 可复算条件 | 状态 | `S_sync` |
|-|-|-:|
| `U/N ≥ 80%` | 同步上涨 | +2 |
| `60% ≤ U/N < 80%`，且`D/N ≤ 20%` | 偏一致上涨 | +1 |
| `D/N ≥ 80%` | 同步下跌 | -2 |
| `60% ≤ D/N < 80%`，且`U/N ≤ 20%` | 偏一致下跌 | -1 |
| 其他 | 分化或横盘 | 0 |

对五个有效指数，对应为：4～5个上涨是同步上涨，4～5个下跌是同步下跌；3个同向且至多1个反向是偏一致；其余是分化或横盘。

### 3.3 同方向不等于同幅度

计算：

```text
横截面离散度 XDisp_t = std(r_1,t … r_N,t)
收益极差 XRange_t = max(r_i,t) - min(r_i,t)
```

如果 `XDisp_t` 或 `XRange_t` 高于各自过去250日的80%分位数，即使方向比例达到80%，也标记为“方向同步但幅度分化”，并把 `S_sync` 向0调整1分。例如，原为+2则调整为+1。

### 3.4 权重与成长风格量化

```text
大盘组收益 R_large = mean(r_上证, r_沪深300)
成长组收益 R_growth = mean(r_创业板, r_中证500)
风格差 StyleGap = R_large - R_growth
风格阈值 StyleLimit = StyleGap过去250日绝对值的80%分位数
```

| 条件 | 定义 |
|-|-|
| `R_large>d`、`R_growth<-d`、`StyleGap≥StyleLimit` | 权重占优、成长走弱 |
| `R_growth>d`、`R_large<-d`、`StyleGap≤-StyleLimit` | 成长占优、权重走弱 |
| 两组均大于各自方向阈值，且`U/N≥80%` | 普遍上涨 |
| 两组均小于各自负方向阈值，且`D/N≥80%` | 普遍下跌 |
| 两组方向相反但未达到风格阈值 | 轻度风格分化 |

其中 `d` 取组内两个指数方向阈值的平均值。不能仅因上证上涨就判断市场全面偏强。

## 4. 趋势结构

### 4.1 均线位置和斜率

计算 `SMA5、SMA10、SMA20、SMA60`。

```text
均线有效距离 e_t = max(0.20%, 0.20 × ATR率_t)
MA斜率 slope_N,t = SMA_N,t / SMA_N,t-5 - 1
斜率阈值 q_N,t = max(0.50%, 0.50 × ATR率_t)
```

- 有效站上MA：`close/SMA_N-1 > e_t`
- 有效跌破MA：`close/SMA_N-1 < -e_t`
- MA附近：绝对距离不超过 `e_t`
- MA向上：`slope_N,t > q_N,t`
- MA向下：`slope_N,t < -q_N,t`
- MA走平：`|slope_N,t| ≤ q_N,t`

### 4.2 单指数趋势分

每个指数先计算多头条件数 `B_i`：

1. 收盘有效站上SMA20；
2. `SMA5>SMA10`；
3. `SMA10>SMA20`；
4. SMA20向上；
5. SMA60向上。

再计算对应空头条件数 `E_i`：

1. 收盘有效跌破SMA20；
2. `SMA5<SMA10`；
3. `SMA10<SMA20`；
4. SMA20向下；
5. SMA60向下。

```text
T_i = B_i - E_i，取值 -5～+5
```

| `T_i` | 单指数趋势 |
|-:|-|
| +4～+5 | 强上升趋势 |
| +2～+3 | 偏强趋势 |
| -1～+1 | 中性/震荡候选 |
| -3～-2 | 偏弱趋势 |
| -5～-4 | 强下降趋势 |

市场趋势原始值取五指数 `T_i` 的中位数 `T_med`：

| `T_med` | `S_trend` |
|-:|-:|
| `≥4` | +2 |
| `2～3` | +1 |
| `-1～1` | 0 |
| `-3～-2` | -1 |
| `≤-4` | -2 |

### 4.3 震荡和均线缠绕

```text
MA_spread = max(SMA5,SMA10,SMA20) / min(SMA5,SMA10,SMA20) - 1
```

“震荡结构”必须同时满足：

1. `MA_spread ≤ 2%`；
2. SMA20走平；
3. 过去20日收盘价对SMA20的有效穿越次数至少4次。一次有效穿越指收盘价从MA一侧超过有效距离，移动到另一侧也超过有效距离。

`MA_spread ≥ 4%` 记为均线明显发散。介于2%～4%不单独定性。

### 4.4 支撑承接

“在MA10或MA20附近获得承接”定义为：

1. 当日最低价进入目标MA的 `±0.5×ATR20` 区域；
2. 收盘价重新位于该MA之上；
3. `CLV=(close-low)/(high-low) ≥ 0.60`；
4. 次日收盘未有效跌破该MA。

缺少次日确认时只能写“承接候选”，不能写“获得承接”。

## 5. 区间位置、平台、突破与破位

### 5.1 20日和60日位置

使用当日前N个交易日的**收盘价**区间：

```text
High_N,t = max(close_t-N … close_t-1)
Low_N,t  = min(close_t-N … close_t-1)
P_N,t = (close_t-Low_N,t) / (High_N,t-Low_N,t)
```

若区间宽度为0，或 `High_N-Low_N < 0.5×ATR20`，则 `P_N=NA`。如果收盘创新高，`P_N` 可以大于1；创新低时可以小于0，不截断原值。

| `P_N` | 位置分类 |
|-:|-|
| `<0` | 跌破N日收盘区间 |
| `0～<0.20` | 区间低位 |
| `0.20～<0.40` | 低位区域 |
| `0.40～<0.60` | 区间中部 |
| `0.60～<0.80` | 偏高区域 |
| `0.80～≤1.00` | 区间高位 |
| `>1.00` | 突破N日收盘区间 |

位置变化：

```text
ΔP20_5 = P20_t-P20_t-5
ΔP60_5 = P60_t-P60_t-5
```

- 位置抬升：`ΔP>0.10`
- 基本不变：`|ΔP|≤0.10`
- 位置回落：`ΔP<-0.10`

### 5.2 有效突破和有效跌破

```text
20日平台上沿 = 当日前20日最高收盘价
20日平台下沿 = 当日前20日最低收盘价
Vratio20 = 当日全市场成交额 / 前20日全市场成交额中位数
```

有效突破候选：

```text
close_t > 平台上沿 + 0.5×ATR20
且 Vratio20 ≥ 1.20
且 CLV ≥ 0.60
```

有效跌破候选：

```text
close_t < 平台下沿 - 0.5×ATR20
且 Vratio20 ≥ 1.20
且 CLV ≤ 0.40
```

满足候选后，还须满足下列任一条件才叫“确认突破/破位”：

1. 后3个交易日中至少2日收盘仍位于平台外；或
2. 后5个交易日没有收盘回到平台内。

确认前只能写“突破候选”或“破位候选”。5日内重新收回平台内，记为“突破失败”或“破位修复”。

### 5.3 突破后是否推进

突破日之后5个交易日内：

- 持续推进：最高收盘价较突破日收盘至少上涨 `1×ATR20`，且未收盘回到平台内；
- 推进不足：最高收盘价涨幅小于 `0.5×ATR20`；
- 突破失败：任一日收盘回到平台内，且随后2日未重新突破。

## 6. 成交额与量价关系

### 6.1 成交额分档

成交额基准均不包含当日：

```text
Vratio5  = amount_t / median(amount_t-5 … amount_t-1)
Vratio20 = amount_t / median(amount_t-20 … amount_t-1)
```

| `Vratio20` | 量能状态 |
|-:|-|
| `<0.80` | 明显缩量 |
| `0.80～<1.20` | 正常量能 |
| `1.20～<1.50` | 放量 |
| `1.50～<2.00` | 显著放量 |
| `≥2.00` | 极端放量 |

“量能稳定”定义为：最近5日每一天的 `Vratio20` 均在0.80～1.20之间，且这5日成交额变异系数 `标准差/平均值 ≤ 15%`。

### 6.2 价格推进

对代表全市场方向的等权五指数收益中位数记为 `R_mkt`，其方向阈值记为五个阈值中位数 `d_mkt`。

- 上行推进：`R_mkt>d_mkt`，五指数中至少60%上涨，且代表指数CLV中位数≥0.60。
- 下行推进：`R_mkt<-d_mkt`，五指数中至少60%下跌，且代表指数CLV中位数≤0.40。
- 价格停滞：`|R_mkt|≤d_mkt`。
- 冲高回落：指数日内最高涨幅≥`max(1%,0.75×ATR率)`，但收盘收益不高于方向阈值，且CLV≤0.40。

### 6.3 量价组合与 `S_volume`

按下表从上到下匹配，先匹配到的规则生效：

| 可复算条件 | 量价状态 | `S_volume` |
|-|-|-:|
| 上行推进、`Vratio20≥1.20`、有效突破候选 | 放量突破推进 | +2 |
| 上行推进，且`0.80≤Vratio20<1.50` | 上行推进 | +1 |
| 上行推进、`Vratio20<0.80`，且趋势分不低于+1、并非突破首日 | 缩量趋势延续 | +1 |
| `Vratio20≥1.50`，且价格停滞或冲高回落 | 放量滞涨/高分歧 | -1 |
| 下行推进、`Vratio20≥1.20`、有效跌破候选 | 放量破位 | -2 |
| 下行推进、`Vratio20≥1.20` | 放量下跌 | -1 |
| 下行推进、`Vratio20<0.80`，但收盘仍在SMA20上方且未跌破平台 | 缩量正常回调候选 | 0 |
| 其他 | 量价中性 | 0 |

“派发”“吸筹”和“新增资金进场”无法仅凭指数成交额直接证明，因此统一使用“高分歧”“价格推进获得量能配合”等可观察表述。

## 7. 市场广度验证

### 7.1 基础指标

对全市场有效股票计算：

```text
个股上涨阈值 = +0.20%
个股下跌阈值 = -0.20%
上涨比例 Adv = 上涨股票数 / 有效股票数
下跌比例 Dec = 下跌股票数 / 有效股票数
涨跌幅中位数 MedRet = median(所有有效股票日收益率)
```

### 7.2 广度分类和 `S_breadth`

| 条件 | 广度状态 | `S_breadth` |
|-|-|-:|
| `Adv≥65%` 且 `MedRet>+0.20%` | 广度强 | +2 |
| `55%≤Adv<65%` 且 `MedRet>0` | 广度偏强 | +1 |
| `Dec≥65%` 且 `MedRet<-0.20%` | 广度弱 | -2 |
| `55%≤Dec<65%` 且 `MedRet<0` | 广度偏弱 | -1 |
| 其他 | 广度中性或分化 | 0 |

“广度较前一日恶化”定义为满足任一项：

1. `Adv` 单日下降至少15个百分点且 `MedRet<0`；
2. `Dec` 单日上升至少15个百分点且 `MedRet<0`；
3. `S_breadth` 较前一日下降至少2分。

“指数与广度背离”定义为：

- 指数上涨、个股偏弱：`S_sync≥+1` 且 `S_breadth≤-1`；
- 指数下跌、个股偏强：`S_sync≤-1` 且 `S_breadth≥+1`。

市场广度不可得时必须写“未验证”，不能写“广度正常”。

## 8. 综合评分和市场状态

### 8.1 综合分

四项数据完整时：

```text
S_total = 0.30×S_sync + 0.30×S_trend + 0.20×S_volume + 0.20×S_breadth
```

某项缺失时，用其余有效项按原权重重新归一化。例如广度缺失：

```text
S_total = (0.30×S_sync + 0.30×S_trend + 0.20×S_volume) / 0.80
```

但结论必须标注低置信度。若同步分或趋势分任一缺失，直接判为“数据不足”，不输出强弱结论。

### 8.2 状态判定

按下列顺序判断，先满足者生效：

| 状态 | 必须同时满足的量化条件 |
|-|-|
| 系统性风险 | `S_sync=-2`、`S_volume=-2`、`S_breadth=-2` |
| 趋势强势 | `S_total≥1.00`、`S_trend≥1`、`S_breadth≥0`，且过去5日至少3日`S_total>0` |
| 趋势弱势/退潮 | `S_total≤-1.00`、`S_trend≤-1`、`S_breadth≤0`；确认破位可直接触发 |
| 高位分歧 | 五指数`P60`中位数≥0.80、`S_volume≤-1`、`S_breadth≤0` |
| 低位修复候选 | 五指数`P60`中位数≤0.40、`S_trend≤1`、`S_volume≥0`，且`S_breadth`由负转为非负 |
| 震荡轮动 | `|S_total|<0.75`，至少3个指数满足震荡结构，且`|S_sync|≤1` |
| 风格分化/混合 | 大盘组与成长组方向相反、`|StyleGap|≥StyleLimit`、方向一致比例<80% |
| 中性 | 不满足以上任何状态 |
| 数据不足 | 有效指数少于4个，或同步分/趋势分缺失 |

除“系统性风险”和“确认破位”外，状态需连续2个交易日满足才正式切换；首日标记为“候选状态”。这样避免单日噪声造成频繁切换。

## 9. 状态对应的执行约束

市场状态不能直接替代个股信号，只用于限制风险：

| 市场状态 | 可量化约束基线 |
|-|-|
| 趋势强势 | 允许执行多头策略；新开仓标的必须在自身SMA20上方；总仓位上限使用策略回测设定值的100% |
| 震荡轮动 | 单笔风险和总仓位上限降至趋势强势状态的50%～70%；不追涨单日涨幅处于自身过去250日90%分位数以上的标的 |
| 风格分化/混合 | 大盘与成长策略分别计算，不用上证指数替代全市场；只交易与强势组方向一致的信号 |
| 高位分歧 | 不新增追涨仓；已有仓位按预设止损或有效跌破SMA20规则处理 |
| 低位修复候选 | 不按趋势反转处理；总仓位上限不超过趋势强势状态的50%，直到`S_trend≥1`且状态确认 |
| 趋势弱势/退潮 | 总仓位上限不超过趋势强势状态的30%；停止新增普通趋势多头 |
| 系统性风险或数据不足 | 不执行依赖本环境模型的新开仓信号 |

具体仓位百分比必须由对应交易策略的样本外回测确定；表中比例是风险约束初始值，不是收益承诺。

```text
S_total：
最终状态：候选 / 已确认
数据质量：完整 / 低置信度 / 数据不足
```

盘后结论统一使用下列句式，方括号必须填数值：

> 有效指数为[N]/5；上涨、下跌、横盘数量为[U/D/F]，同步分为[S_sync]。五指数趋势分中位数为[T_med]，20日/60日位置中位数为[P20/P60]。全市场成交额相对前20日中位数为[Vratio20]倍，量价分为[S_volume]。上涨比例为[Adv]，涨跌幅中位数为[MedRet]，广度分为[S_breadth]。综合分为[S_total]，按规则判定为[候选/已确认的市场状态]，数据质量为[等级]。

## 11. 阈值校准和风险边界

本文中的0.20%、0.30%、0.50×ATR、1.20倍、1.50倍、65%、80%等均为**初始参数**，作用是建立可执行基线，不代表永久有效规律。正式用于交易约束前必须：

1. 使用至少覆盖一个完整牛熊周期的数据，并优先覆盖2015年以来多个市场阶段；
2. 严格使用当时可获得的数据，避免未来函数和幸存者偏差；
3. 按年份或市场阶段做滚动训练、验证和样本外测试；
4. 对阈值上下浮动10%～20%做敏感性分析；若结论剧烈变化，说明规则不稳健；
5. 同时评估最大回撤、换手率、状态误判率、状态平均持续时间、切换频率和信号滞后，而不只看收益；
6. 记录交易成本、滑点、涨跌停不可成交和数据源时点差异；
7. 阈值优先采用滚动分位数，固定阈值只保留下限或兜底；
8. 每次修改阈值必须记录原值、新值、样本内结果、样本外结果和已知失效场景。

**一句话总结：** 不再用“感觉偏强、似乎放量、可能破位”形成结论；先计算同步、趋势、量价和广度四项分数，再按固定顺序输出候选状态、确认状态及数据置信度。
