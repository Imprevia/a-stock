# 1.指数、趋势位置和成交额



## 1. 指数、趋势位置和成交额

判断市场环境，不是分别看指数涨跌、价格位置和成交额大小，而是把三者结合起来观察：

> **指数看方向，趋势位置看阶段，成交额看资金是否认可；最后用市场广度验证指数是否真实。**

### 一、指数怎么看：不要只盯一个指数

建议同时观察上证指数、深证成指、创业板指、沪深300和中证500：

| 指数 | 主要代表 | 重点观察 |
|-|-|-|
| 上证指数 | 沪市大盘股、金融和周期权重 | 权重股及传统行业状态 |
| 深证成指 | 深市成长、制造、消费 | 市场整体成长活跃度 |
| 创业板指 | 高弹性成长股 | 成长方向的风险偏好 |
| 沪深300 | 两市核心大盘蓝筹 | 机构重仓股和大盘风格 |
| 中证500 | 中盘股 | 中盘股和题材扩散情况 |

重点不是哪个指数涨得最多，而是指数之间是否同步：

- **多数指数同步上涨**：上涨可能具有普遍性，市场风险偏好改善；如果上涨家数和涨跌幅中位数也改善，强势可信度更高。
- **上证、沪深300上涨，创业板、中证500走弱**：可能是银行、保险、石油等权重股护盘，属于指数偏强但个股偏弱，不能简单定义为全面强势。
- **上证偏弱，创业板、中证500较强**：资金可能从大盘权重转向成长和中小盘，题材机会可能强于指数表面，但仍需成交额和市场广度验证。
- **所有指数同步走弱**：如果同时放量、跌破关键均线、下跌家数扩大，通常意味着风险偏好正在系统性下降。

### 二、趋势位置怎么看：判断市场处于哪个阶段

#### 1. 看收盘价与均线的关系

建议记录收盘价相对5日、10日、20日和60日均线的位置：

| 均线 | 观察含义 |
|-|-|
| 5日线 | 超短期强弱和近期资金成本 |
| 10日线 | 短线趋势能否延续 |
| 20日线 | 一个月左右的波段趋势 |
| 60日线 | 中期趋势和主要成本区 |

**偏强结构：** 收盘价位于主要均线之上，5日线在10日线上方，10日线在20日线上方，20日线和60日线向上；回调时能在短期均线或20日线附近获得承接。说明市场处于上升趋势或偏强状态。

**震荡结构：** 价格反复穿越5日、10日和20日线，均线相互缠绕，20日线走平，突破后没有持续推进。说明市场方向不明确，应降低追涨预期。

**偏弱结构：** 收盘价位于5日、10日和20日线下方，短期均线向下，反弹到10日线或20日线附近受阻，20日线和60日线同时下行。说明市场偏弱，反弹应先按修复理解。

**破位结构：** 指数原本沿20日线运行，随后放量跌破20日线或重要平台，且次日不能收回，同时市场广度恶化，说明原有趋势可能发生变化。

#### 2. 看20日、60日区间位置

```text
N日位置 =（当前收盘价 - N日最低价）÷（N日最高价 - N日最低价）
```

结果可转换为百分比：0%表示接近区间低点，50%表示处于区间中部，100%表示接近区间高点。

| 区间位置 | 大致含义 | 重点观察 |
|-|-|-|
| 0%～20% | 接近阶段低位 | 是止跌筑底，还是继续创新低 |
| 20%～40% | 低位修复 | 能否站上20日线并形成更高低点 |
| 40%～60% | 区间中部 | 多空分歧，方向不明确 |
| 60%～80% | 偏强区域 | 是否沿均线上行、成交是否配合 |
| 80%～100% | 接近阶段高位 | 是有效突破，还是放量滞涨 |

区间位置不能单独决定强弱：

- **高位不一定危险**：如果均线向上、成交额稳定、市场广度改善、回调有承接，高位可能代表强趋势或即将突破。
- **低位不一定安全**：如果均线向下、下跌放量、持续创新低，低位可能只是下降趋势延续。

> **位置只告诉你价格在哪里，趋势和量能才告诉你价格为什么在那里、是否有能力离开那里。**

### 三、成交额怎么看：看成交后价格有没有推进

建议同时记录：

```text
当日成交额 ÷ 近5日平均成交额
当日成交额 ÷ 近20日平均成交额
```

可将成交额比值作为辅助参考：

| 成交额比值 | 大致含义 |
|-|-|
| 小于0.8 | 明显缩量 |
| 0.8～1.0 | 略低于近期平均 |
| 1.0～1.2 | 正常或温和放量 |
| 1.2～1.5 | 较明显放量 |
| 大于1.5 | 异常活跃，需要查找原因 |

成交额本身不是利好或利空，关键是成交之后价格有没有取得进展：

- **上涨＋放量＋有效突破**：新增资金进场，更高价格获得接受，突破有效性较高。
- **上涨＋缩量**：趋势中途、抛压较轻时可能是惜售；但低位刚突破时缩量，可能意味着跟进资金不足、突破容易失败。
- **放量但指数滞涨**：交易活跃但价格没有明显推进，可能存在上方抛压、资金分歧或高位兑现风险；需要观察后续能否重新突破。
- **下跌＋缩量**：若仍处于上升趋势、未跌破关键位置、市场广度未恶化，可能是正常回调。
- **下跌＋放量＋跌破关键位置**：说明主动卖出和风险扩散，原有趋势可能遭到破坏，应提高风险等级。

### 四、把指数、位置和成交额结合起来

| 典型组合 | 可能阶段或状态 |
|-|-|
| 低位、重新站回短期均线、温和放量 | 底部修复或启动尝试 |
| 均线多头、区间位置持续抬升、量能稳定 | 上升趋势或主升阶段 |
| 区间高位、放量突破、收盘较强 | 趋势加速或突破确认 |
| 区间高位、巨量滞涨、冲高回落 | 高位分歧或派发风险 |
| 均线缠绕、量能忽高忽低 | 震荡轮动 |
| 跌破关键均线、放量下跌 | 趋势破坏或退潮 |

由此可以得到四类重要信息：

1. **判断市场是不是真强**：多数指数同步走强、均线向上、位置偏强、成交额支持价格推进，并且上涨家数扩大，才更接近真实强势。
2. **判断市场所处阶段**：通过区间位置和均线结构，区分启动、主升、震荡、高位分歧或趋势破坏。
3. **判断资金是否认可当前价格**：放量上涨且价格推进，说明资金认可；放量滞涨，说明资金分歧加大；放量下跌，说明资金主动撤退。
4. **决定交易模式**：趋势环境顺势做，轮动环境降低追涨预期，退潮环境控制风险，混合环境要区分权重和题材的强弱，不能只看上证指数。

### 五、每日盘后记录模板

1. **指数同步性**：上证、深成指、创业板、沪深300、中证500分别涨跌多少，是否同步。
2. **均线结构**：主要指数位于5日、10日、20日、60日线之上还是之下，均线方向如何。
3. **趋势位置**：主要指数处于20日、60日区间的低位、中位还是高位，是否突破或跌破关键位置。
4. **成交额状态**：当日成交额较前一日、5日均值和20日均值是放大还是缩小。
5. **量价配合**：成交额增加后，价格是有效推进、滞涨，还是向下推进。
6. **广度验证**：上涨家数、下跌家数、涨跌幅中位数、涨跌停和高位股反馈是否与指数一致。

可以用下面的句式收束：

> 今天多数指数同步上涨/出现分化；指数位于20日线之上/之下，处于60日区间高位/中位/低位；全市场成交额较5日均值放大/缩小，但价格实现了有效突破/没有明显推进。结合市场广度，当前更接近趋势、轮动、退潮或混合环境。

**一句话总结：**指数看方向，位置看阶段，成交额看资金是否认可；最后用上涨家数和涨跌幅中位数验证指数有没有“骗人”。
