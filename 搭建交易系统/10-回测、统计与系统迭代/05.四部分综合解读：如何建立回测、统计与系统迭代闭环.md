# 5.四部分综合解读：如何建立回测、统计与系统迭代闭环

回测、统计与系统迭代的目标，不是找到一组历史上最赚钱的参数，而是建立一个可定义、可验证、可执行、可监控、可回滚的研究闭环。

## 一、四部分分别解决什么问题

| 模块 | 核心问题 | 主要产出 |
|-|-|-|
| 从想法到实盘的六阶段 | 一个想法何时有资格进入真实交易？ | 假设、反例、样本内外验证、模拟与小资金证据 |
| 必须统计的指标 | 系统是否有优势，代价多大？ | 收益、风险、成本、效率和执行质量指标 |
| 分组统计 | 优势到底来自哪里，边界在哪里？ | 适用环境、失效环境、容量和执行差异 |
| 修改系统的条件 | 什么时候该改，怎样防止过拟合？ | 变更证据、版本控制、验证与回滚规则 |

## 二、统一判断链

> **先定义可证伪假设 → 再做含现实约束的回测 → 再用样本外和实时流程验证 → 再看完整指标与分组结果 → 最后决定保持、降级、暂停或迭代。**

固定流程如下：

```text
1. 定义：规则、数据、入场、退出、仓位、失效条件是否客观？
2. 回测：是否避免未来函数、幸存者偏差，并计入成本和不可成交？
3. 验证：样本外、模拟和小资金结果是否支持同一假设？
4. 统计：期望、盈利因子、回撤、连亏、成本和执行率是否可接受？
5. 分组：优势在哪些环境存在，哪些组只是小样本或行情暴露？
6. 决策：维持 / 降仓 / 暂停 / 修改；若修改，建立新版本并重新验证。
```

## 三、通过这些数据能得到什么

### 1. 判断策略是否存在可重复优势

交易期望、盈利因子、样本外表现和不同时间段结果共同回答：收益是稳定统计优势，还是少数幸运交易、特定行情或过度调参造成的表象。

### 2. 判断优势的风险和现实代价

最大回撤、连续亏损、持仓时间、滑点、费用和无法成交情形共同回答：账户与心理能否承受，以及纸面收益是否能转化为实盘净收益。

### 3. 判断策略适用于什么环境

按市场、板块、市值、时段、情绪、信号强度和交易类型分组，可以形成“启用—降级—停用”边界，而不是让一套规则覆盖所有行情。

### 4. 判断问题来自系统还是执行

计划内交易与违规交易、应执行信号与实际执行、模拟与实盘差异，可以把规则缺陷、执行偏差、数据问题和容量问题分开处理。

### 5. 判断系统是否应该修改

只有足够样本、结构性恶化、机制变化、成本失真、规则歧义、容量变化或未覆盖风险，才构成修改证据；短期盈亏只触发风险管理和继续观察，不自动触发换系统。

## 四、数据冲突时的优先级

- 样本内很好、样本外明显恶化：以样本外和真实执行证据优先；
- 毛收益为正、扣除成本后为负：以净收益和可成交性优先；
- 总体盈利、关键分组亏损：按实际使用环境和分组样本重新判断，不用总体均值掩盖风险；
- 胜率很高、盈亏比和尾部风险很差：优先看期望、回撤与极端损失；
- 策略统计尚可、执行率很低：先修复流程并降低风险，不急于改核心规则；
- 最近表现差、但仍处历史正常回撤：先执行预设降档或暂停规则，等待更多证据；
- 单一指标与完整证据链冲突：完整收益—风险—成本—分组—执行链优先。

## 五、最终分类与行动含义

| 分类 | 证据特征 | 行动含义 |
|-|-|-|
| 可继续验证 | 样本内外方向一致，净期望为正，风险与成本可承受 | 维持规则，继续积累独立样本 |
| 条件性有效 | 总体有优势，但只在明确环境或容量内成立 | 只在适用组启用，其他环境降级或停用 |
| 待修复 | 优势可能存在，但规则歧义、执行率低或成本假设失真 | 暂不扩大风险，先修复单一问题再验证 |
| 证据不足 | 样本量小、分组过细或结果不稳定 | 保持观察，不下确定结论 |
| 应暂停/淘汰 | 样本外和实盘持续失效，净期望为负或风险不可承受 | 停止使用，保留记录，不靠继续调参挽救 |

## 六、置信度怎么写

- **高置信度**：规则明确，样本充分，样本外、模拟与实盘方向一致，分组和成本检验稳定。
- **中置信度**：总体证据支持，但样本、环境覆盖、成本或实时执行仍有一项待补。
- **低置信度**：样本小、参数多、分组后不稳定，或只有样本内漂亮结果。

置信度描述证据质量，不代表下一笔交易的胜率。

## 八、结尾

通过这四部分，最终得到的不是一条“永远有效”的策略，而是一套能够持续接受证据检验的系统：

> **用六阶段控制策略上线风险，用完整指标衡量收益与代价，用分组统计定义适用边界，用版本化迭代防止情绪调参和历史过拟合。**

完整闭环是：

> **假设 → 回测 → 样本外验证 → 模拟/小资金 → 完整统计 → 分组归因 → 保持、降级、暂停或最小修改 → 新版本重新验证。**

只要每次结论都保留数据口径、反例、置信度、失效条件与回滚路径，系统迭代就不再是“亏了就改、赚了就放大”，而会成为可审计、可复现的长期研究过程。

本文用于交易研究与复盘，不构成投资建议。
