# 2.必须统计的指标

统计指标不能各自孤立解读。胜率高不一定赚钱，收益高也可能来自不可承受的回撤。应同时观察收益能力、风险代价、样本可靠性、资金效率和执行质量。

## 一、必须统计的指标怎么看

| 指标 | 怎么看 | 能得到的信息 |
|-|-|-|
| 交易次数 | 看总样本及不同环境下的有效样本数 | 结论是否可能只是小样本偶然 |
| 胜率 | 盈利交易占全部交易的比例 | 系统命中的频率，但不能单独评价优劣 |
| 平均盈利/平均亏损 | 比较单次赚钱与亏钱的平均幅度 | 系统靠高胜率还是高盈亏比获利 |
| 交易期望 | 胜率与平均盈亏共同形成的单笔长期平均结果 | 策略是否具有长期统计优势 |
| 盈利因子 | 总盈利相对总亏损绝对值 | 总体盈利对亏损的覆盖能力 |
| 最大回撤 | 权益曲线从高点到低点的最大下降 | 历史最坏风险及仓位是否可承受 |
| 最大连续亏损 | 最长连亏次数及连亏期间损失 | 暂停、降仓和心理承受规则如何设计 |
| 持仓时间 | 盈亏交易各自持有多久、资金占用多久 | 资金效率与时间止损是否合理 |
| 滑点与费用 | 理论价格与实际成交的差额及全部成本 | 纸面收益能否落地 |
| 规则执行率 | 符合规则的交易数占应执行交易数或全部交易的比例 | 问题来自系统还是执行偏差 |

## 二、指标要怎样组合

- **胜率 + 平均盈亏 + 交易期望**：回答系统靠什么赚钱，以及长期平均是否有优势。
- **盈利因子 + 最大回撤 + 连续亏损**：回答赚取收益需要承受多大风险。
- **持仓时间 + 费用 + 滑点**：回答资金效率及理论优势是否被交易摩擦吞噬。
- **规则执行率 + 计划内/违规交易表现**：回答应该修改系统，还是先修正执行。

## 三、必须避免的误区

- 只展示累计收益，不展示回撤和资金曲线过程；
- 只看平均值，不看收益分布、极端亏损和少数大盈利的贡献；
- 样本很少却给出过度精确的胜率结论；
- 忽略费用、冲击成本、停牌和无法成交；
- 把违规盈利算成策略能力，把计划内亏损算成规则错误；
- 用单一阈值机械认定系统合格，不比较基准、环境和策略目标。

**结论：**指标的目标不是挑出最好看的数字，而是判断优势是否存在、风险是否可承受、结果是否可执行，以及统计结论是否可信。

本文用于交易研究与复盘，不构成投资建议。
