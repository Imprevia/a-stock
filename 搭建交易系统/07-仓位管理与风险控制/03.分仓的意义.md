# 3.分仓的意义

分仓的目的不是把股票数量做多，而是降低单一判断、单一事件或单一标的对账户的破坏力；但只有风险来源不同，分散才真正有效。

## 一、要看哪些数据

| 数据 | 要问的问题 | 能得到的信息 |
|-|-|-|
| 单票仓位与单票风险 | 任一股票失效会损失多少？ | 个股黑天鹅对账户的冲击 |
| 行业、题材与风格暴露 | 多只股票是否受同一催化或风险因子驱动？ | 表面分散是否实际集中 |
| 个股间走势相关性 | 下跌时是否经常同步？ | 组合是否会一起回撤 |
| 持仓数量与研究覆盖 | 是否还能跟踪每只的逻辑、公告与失效位？ | 分仓是否稀释决策质量 |
| 流动性与成交成本 | 退出时是否会互相挤压？ | 分散后的真实执行风险 |
| 组合最大回撤 | 分仓后权益波动有没有改善？ | 分散效果是否值得保留 |

## 二、数据能说明什么

- **单票风险下降，不等于组合风险下降。** 若持有多只同一题材、同一高波动风格股票，板块退潮时仍可能同步回撤。
- **分仓有助于降低特异性风险。** 一只股票停牌、业绩暴雷或跌停时，不会决定账户生存。
- **持仓越多，研究门槛越高。** 超出跟踪能力的分仓，可能把主动管理变成无意的指数化暴露，且增加交易成本。
- **分散是否有效需要复盘验证。** 比较组合回撤、单票贡献、相关性和持仓期，而不是根据持股数量判断。

## 三、实用判断顺序

> 先按风险因子归类持仓 → 计算各类风险暴露 → 限制单票与单主题风险 → 检查退出流动性 → 用历史组合回撤验证。

可把持仓标注为：市场风格、行业题材、核心逻辑、预设止损、单票风险、与其他持仓的关联。若三只股票的失败条件都来自同一板块退潮，应把它们视作一组风险，而非三次独立下注。

## 四、常见误区

- 把“买八只股票”当作天然低风险；
- 只限制单票金额，不限制同题材总暴露；
- 为分散而买研究不足、流动性较差的边缘标的；
- 忽略极端行情中相关性上升。

**结论：**有效分仓的核心是分散风险来源，而不是分散股票代码；最终应由组合回撤、集中度和执行能力验证效果。

本文用于交易研究与复盘，不构成投资建议。
