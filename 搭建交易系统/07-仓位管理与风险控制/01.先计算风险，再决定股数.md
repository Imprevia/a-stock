# 1.先计算风险，再决定股数

仓位不是先凭感觉决定“买多少”，而应从一笔交易最坏可能损失多少开始倒推。原资料的核心公式是：

```text
允许风险金额 = 账户权益 × 单笔风险比例
每股风险 = 计划入场价 - 逻辑失效价
理论股数 = 允许风险金额 ÷ 每股风险
```

## 一、先看什么

| 数据 | 要问的问题 | 能得到的信息 |
|-|-|-|
| 账户权益 | 当前可承受的总损失基数是多少？ | 风险预算的绝对金额 |
| 入场价与失效价 | 交易逻辑在哪里被推翻？ | 每股真实风险，而非主观止损比例 |
| 单笔风险比例 | 一次判断错误最多损失多少账户权益？ | 单笔交易对账户的冲击上限 |
| 计算出的股数 | 是否超过单票、流动性与组合限制？ | 可执行仓位上限 |
| 跳空、滑点、涨跌停 | 能否按预设止损成交？ | 账面风险与实际风险的差距 |

## 二、这些数据真正说明什么

1. **止损距离越远，允许股数应越少。** 同一只股票“看好程度”不变，若逻辑失效位更远，仓位也应自动缩小。
2. **仓位金额不是风险金额。** 买入金额相同的两笔交易，止损距离不同，对账户的风险完全不同。
3. **风险预算先于下单。** 若计算出的股数低于最小交易单位、预期盈亏比不足，或流动性承受不了，不是强行放大仓位，而是放弃该机会。
4. **公式给的是理论上限。** 隔夜跳空、跌停、停牌和滑点会令实际损失超过预设值，实盘需留缓冲。

## 三、正确使用顺序

> 先定义模式与失效条件 → 再确定入场区间 → 计算每股风险 → 设定单笔风险预算 → 得到理论股数 → 用单票/组合/流动性上限二次约束。

## 四、常见误区

- 先决定满仓或半仓，再倒找止损；
- 只用固定百分比止损，不管结构是否真的失效；
- 忽略跳空和无法成交，把理论最大亏损当作实际最大亏损；
- 因“很有把握”跳过风险计算。

**结论：**仓位大小应是风险预算和失效距离的结果。它不能预测交易是否盈利，但能把单次错误对账户的伤害控制在事先可接受的范围内。

本文用于交易研究与复盘，不构成投资建议。
