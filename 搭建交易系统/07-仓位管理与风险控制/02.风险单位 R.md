# 2.风险单位 R

`R` 是把每笔交易的计划风险标准化后的单位：若一笔交易按计划止损，记为 `-1R`；若盈利相当于初始风险的两倍，记为 `+2R`。它的作用是把不同股价、不同股数的交易放到同一把尺子上比较。

## 一、怎么看 R 数据

| 数据 | 要问的问题 | 能得到的信息 |
|-|-|-|
| 初始风险金额（1R） | 入场到失效价的计划损失是多少？ | 每笔交易可承受亏损的统一基准 |
| 单笔结果（R） | 最终盈利或亏损相当于几倍初始风险？ | 交易质量，不受金额大小干扰 |
| 平均盈利 R / 平均亏损 R | 赢时赚多少、错时亏多少？ | 盈亏结构是否健康 |
| 胜率 | 盈利交易占比多少？ | 命中率，但不能脱离盈亏比单独看 |
| 累计 R、最大连续亏损 R | 系统在一段时期的净结果和最坏连亏 | 风险预算、暂停线与心理承受要求 |
| 计划 R 与实际 R | 是否超止损、提前止盈或违规加仓？ | 执行偏差与系统问题的区分 |

## 二、能得到什么信息

- 同样赚 1,000 元，若一笔承担 500 元风险、另一笔承担 2,000 元风险，前者是 `+2R`，后者只是 `+0.5R`；R 更能反映风险调整后的结果。
- 胜率不高不必然差：若平均盈利明显大于平均亏损，系统仍可能有正期望；高胜率但偶尔一次大亏超过许多次盈利，则风险结构仍脆弱。
- 连续亏损 R 与权益回撤结合，可帮助设定降仓或暂停阈值，而不是只看“亏了几天”。
- 若多数亏损都超过 `-1R`，优先排查止损执行、流动性和跳空风险；若多数盈利过早止盈，则检查退出规则是否与模式匹配。

## 四、边界

R 不是收益保证，也不能掩盖仓位过大、相关性集中或流动性风险；初始止损若不合理，R 的比较也会失真。它应与账户回撤、组合暴露和执行成本一起使用。

**结论：**用 R 复盘，重点从“赚亏金额”转向“单位风险换回了什么结果”，从而判断问题来自策略、环境还是执行。

本文用于交易研究与复盘，不构成投资建议。
