# 6.连续亏损和账户回撤

连续亏损与账户回撤需要从“情绪问题”改造成预先写好的风险降档机制。目标不是预测何时转好，而是在系统可能失效、市场不适配或执行变形时，先限制损失扩散。

## 一、要记录哪些数据

| 数据 | 要问的问题 | 能得到的信息 |
|-|-|-|
| 连续亏损笔数 | 是否超出系统的正常连亏范围？ | 是否需要降低单笔风险 |
| 累计 R | 近期损失相当于多少次计划风险？ | 跨金额、跨仓位的统一损失口径 |
| 单日/单周亏损 | 是否触及当期风险预算？ | 是否应停止新开仓 |
| 从权益高点的回撤比例 | 账户实际退回了多少？ | 是否进入暂停或恢复模式 |
| 计划内与违规交易占比 | 亏损来自系统、市场，还是执行偏差？ | 后续应改规则还是改执行 |
| 市场环境与模式表现 | 当前环境是否不适合该策略？ | 是否需要暂停某类模式 |
| 恢复阶段表现 | 降仓后是否稳定？ | 是否具备逐步恢复资格 |

## 二、数据可以支持的判断

- 连亏本身不等于系统失效；但若累计 R、权益回撤和违规率同时恶化，应优先降风险而不是加仓翻本。
- 只按“连续亏损几天”触发容易受交易频率影响；结合连续亏损笔数、累计 R 和回撤比例更稳健。
- **亏损分类很关键：**计划内亏损需要检验环境适配和系统期望；违规亏损先修正执行，不应立刻修改策略参数。
- 恢复不是某天盈利就重回满仓。应先定义恢复条件，例如最小风险仓位下连续一段时间按计划执行、回撤停止扩大、特定模式重新出现符合统计的表现。

## 三、可建立的分级机制

| 状态 | 触发依据（需自行回测设定） | 行动 |
|-|-|-|
| 正常 | 未触及任一风险阈值 | 按常规风险预算执行 |
| 降档 | 连亏、累计 R 或日损失达到预警线 | 降低单笔风险，减少新开仓次数 |
| 暂停 | 周/月回撤或违规损失达到上限 | 停止实盘新开仓，复盘样本与执行 |
| 恢复 | 预设恢复条件已满足 | 从最小风险仓位逐步恢复 |

具体阈值必须根据策略历史样本、交易频率与承受能力设置，不能照搬他人的“两天/三天”规则。

## 四、常见误区

- 连亏后放大仓位试图回本；
- 因一两笔正常亏损频繁推翻系统；
- 把暂停理解为失败，而不做复盘；
- 没有恢复条件，盈利一天就恢复高仓位。

**结论：**回撤控制的价值在于让账户在不利阶段自动减速。先降低风险、区分原因、完成复盘，再考虑恢复，而不是用更大的仓位对抗亏损。

本文用于交易研究与复盘，不构成投资建议。
