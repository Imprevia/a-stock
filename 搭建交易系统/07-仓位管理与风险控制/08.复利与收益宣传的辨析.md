# 8.复利与收益宣传的辨析

复利是数学上的收益再投入过程，不是“高收益必然长期重复”的承诺。评估任何收益案例，必须把回报与回撤、波动、交易成本、样本量、容量和幸存者偏差放在一起看。

## 一、要看哪些数据

| 数据 | 要问的问题 | 能得到的信息 |
|-|-|-|
| 年化/阶段收益 | 赚了多少？收益来自哪些时期？ | 表面回报，但不足以判断质量 |
| 最大回撤 | 从历史高点到低点最大损失多少？ | 生存压力与真实风险 |
| 波动率、连续亏损 | 收益路径是否平稳，最差阶段如何？ | 能否承受并持续执行 |
| 交易次数与样本期限 | 结果是否覆盖足够多环境？ | 是否可能只是短期运气 |
| 平均盈利/亏损、胜率、期望 | 系统靠什么赚钱？ | 收益结构能否解释 |
| 费用、滑点、税费与冲击成本 | 理论收益能落地多少？ | 实盘可复制性 |
| 资金规模与成交容量 | 资金放大后能否以同样质量成交？ | 策略能否扩容 |
| 基准与幸存者偏差 | 是否只展示成功账户或峰值净值？ | 宣传叙事是否失真 |

## 二、这些数据可以告诉我们什么

- 高收益若伴随无法承受的回撤或波动，未必适合自己的资金和心理承受力。
- 短期翻倍、个别账户或单一行情阶段，不能推出长期稳定复利；必须检验样本是否覆盖震荡、下跌和极端行情。
- 未扣除成本、滑点与无法成交的回测或晒单，往往高估真实可得收益。
- “最高资产”不是已锁定收益；只有在风险控制、可复制执行和长期样本支持下，收益曲线才有参考意义。

## 三、正确的评价顺序

> 先看是否能生存 → 再看风险调整后的收益 → 再看样本与可复制性 → 最后才讨论复利与资金规模。

可用以下问题筛查任何高收益说法：

```text
1. 同期最大回撤、最大连续亏损和波动是多少？
2. 收益是否扣除了费用、滑点和无法成交？
3. 有多少笔交易、覆盖多长时间、经历过哪些市场环境？
4. 收益由少数极端盈利交易贡献，还是具有稳定结构？
5. 资金扩大后，流动性和冲击成本会不会改变结果？
6. 是否同时展示了失败样本，而非只展示幸存者？
```

## 四、常见误区

- 用“半年翻倍”倒推未来收益率；
- 只看胜率或收益，不看最大回撤；
- 忽略交易成本、容量和资金规模差异；
- 将历史峰值权益当作稳定、可复制的能力；
- 因短期盈利快速放大仓位。

**结论：**仓位管理的第一目标是避免不可逆损失。先建立可承受回撤和可持续执行的风险模型，复利才可能成为长期结果，而不是宣传口号。

本文用于交易研究与复盘，不构成投资建议。
