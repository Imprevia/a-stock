# 7.极端行情应对

极端行情的风险不在于判断错方向，而在于价格、流动性和执行条件可能同时失效：跌停、跳空、停牌、重大事件或系统故障，会使平时有效的止损与分散出现缺口。因此需要在平静时准备组合级预案。

## 一、重点监测的数据

| 数据/情景 | 要问的问题 | 能得到的信息 |
|-|-|-|
| 指数与市场广度 | 下跌是否从局部扩散为系统性风险？ | 是否需要启动组合减仓 |
| 涨跌停、炸板、连板反馈 | 流动性与情绪是否快速恶化？ | 高波动策略的可交易性变化 |
| 持仓相关性与主题暴露 | 多只股票会不会一起受冲击？ | 集中风险上限是否被突破 |
| 个股公告、停牌与重大利空 | 是否出现无法按常规止损处理的事件？ | 单票损失可能大于预设风险 |
| 买卖盘深度、成交额与滑点 | 是否还能按计划成交？ | 止损的可执行性 |
| 隔夜、节假日、重大事件日 | 是否存在无法盘中处理的风险窗口？ | 是否需要预先降低暴露 |
| 券商、网络、行情、条件单状态 | 下单与风控工具是否可用？ | 操作风险与备用方案需求 |

## 二、能得到什么信息

- 指数下跌本身不必然要求清仓；关键是看市场广度、流动性、持仓相关性和自己的系统是否同时恶化。
- 个股跌停、停牌或跳空时，价格止损可能无法按预设成交，因此单笔风险预算必须预留极端损失空间。
- 多只同题材持仓在极端时往往高度相关，表面分散会失效；应以主题/因子暴露而非股票只数衡量风险。
- 条件单、网络和券商故障属于真实风险源，预案要包括备用网络、备用设备、券商联系方式和人工下单流程。

## 三、预案应提前写清

```text
市场级：市场广度/指数/流动性恶化到何种程度，停止新开仓或降低总仓位？
组合级：同一主题、单票和总风险的上限分别是多少？
个股级：跌停、停牌、重大公告、无法成交时如何记录和处置？
执行级：条件单、网络或行情异常时，使用什么备用路径？
事件级：节假日、财报、政策、海外重大事件前，是否主动降低隔夜暴露？
恢复级：风险解除后，依据什么条件逐步恢复正常仓位？
```

原资料中以“开盘下跌家数”触发减仓或清仓的经验，可作为待验证假设；更稳健的做法是用动态市场广度、流动性和自身持仓表现共同确认，而不是使用固定数字机械执行。

## 四、常见误区

- 把极端情景当作小概率，因此不做预案；
- 认为分仓后不需要考虑系统性风险；
- 只设计卖出规则，不设计无法卖出的情形；
- 发生故障后临时凭情绪决策；
- 风险解除后立刻恢复满仓。

**结论：**极端风控不是预测黑天鹅，而是承认止损可能失效，并在风险发生前把仓位、流动性、技术故障和恢复流程都写成可执行方案。

本文用于交易研究与复盘，不构成投资建议。
