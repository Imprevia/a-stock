# 5.逆势加仓与“123仓位法”风险

原资料中的“首次 10%，下跌 10% 加 20%，再跌 10% 加 30%”属于在价格不利时扩大暴露的做法。它可能降低账面成本，但不能降低交易逻辑已被破坏的风险，具有逆势摊平和类马丁特征。

## 一、需要重点看什么

| 数据 | 要问的问题 | 能得到的信息 |
|-|-|-|
| 初始入场逻辑与失效位 | 下跌后原逻辑还成立吗？ | 加仓是否仍有前提 |
| 每次加仓后的总风险 | 新增股数后，若止损，账户会损失多少？ | 风险是否失控 |
| 价格结构与成交量 | 是缩量回踩守位，还是放量破位？ | 回调是健康整理还是趋势转弱 |
| 板块、基本面与事件变化 | 原催化是否仍在？ | 是否存在逻辑证伪 |
| 平均成本与市场价格 | 成本是否下降？ | 只能说明账面盈亏门槛变化，不能说明风险变小 |
| 流动性和极端损失 | 跌停、跳空时还能否退出？ | 摊平策略最脆弱的情景 |

## 二、这些数据能得到什么信息

- **成本降低不是风险降低。** 价格持续下跌且结构破坏时，加仓会令同一错误暴露更大。
- **正确加仓应发生在证据增强后。** 例如突破后站稳、回踩守住、量价重新转强、板块与逻辑得到确认；这属于顺势金字塔，而非逆势摊平。
- 若加仓后总风险超过单票或组合上限，哪怕图形短暂反弹，策略仍不符合风险控制。
- 均值回归策略并非一定不可用，但必须先有明确的可验证边界：适用市场、入场条件、最大层数、最终止损、最大风险和样本外表现。

## 三、加仓前的必答问题

```text
1. 原始交易逻辑是否仍成立？
2. 本次加仓是因为新证据出现，还是只因价格更低？
3. 加仓后到统一失效位的总风险是多少？
4. 单票、同主题、组合总风险是否仍在上限内？
5. 若明天跳空或跌停，账户还能承受吗？
```

只要其中任一项无法回答，就不应加仓。

## 四、主要误区

- 把“补仓后更容易回本”误当作胜率提升；
- 用更多资金解决原本的判断错误；
- 不设最大层数和最终退出条件；
- 在高波动、退潮或基本面恶化时继续摊平。

**结论：**加仓的合理依据应是“逻辑更强、风险仍受控”，不是“价格更低、成本更好看”。

本文用于交易研究与复盘，不构成投资建议。
