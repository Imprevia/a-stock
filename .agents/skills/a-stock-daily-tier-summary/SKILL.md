# A 股每日分层总结

用确定性脚本计算事实，再生成简短中文复盘。环境与分层必须绑定同一交易日；结论只描述市场结构，规则状态保持 `needs-backtest`。

## 工作流

1. 把“今天”或“昨天”按 `Asia/Shanghai` 解析为目标日，并确认该日已经收盘。休市时明确说明休市，并使用可信交易日历指出最近已完成交易日；不能证明时返回数据不足。
2. 从会话中分别提取最近一条可追溯的分层验证原文和环境验证原文。只接受原文可支持的结构化条件；不要根据今天结果补写或修改阈值。没有时分别记为 `unavailable`。
3. 优先读取仓库本地 v2 精确日期接口或调用者给定的 JSON fixture。目标交易日先读 `overview`，固定其 revision 后读取 `indices`、`breadth`、`limits` 及三个 pool 的全部 cursor 页；上一交易日 limits 使用自己的 revision。当前资源任一日期或 revision 不一致时停止组合判断。
4. 只有用户明确请求已完成交易日、本地证据不可用且当前环境允许外部只读请求时，才可使用脚本的东方财富降级模式。不得借此触发采集、回填、数据库写入或部署操作。
5. 运行 `scripts/analyze_tier_summary.py` 得到结构化 JSON；不要手算或直接按 provider 原始行计数。
6. 按下方固定顺序输出完整复盘卡。第一、二行必须列出具体指数名称；每个分层结论带冻结样本数和结果计数；分层与环境各保留一个下一交易日验证项。数据缺失只影响对应结论，不填 0。

需要接入数据、排查日期或质量问题时读取 [数据合同](references/data-contract.md)。需要选择结构标签、风险层或下一交易日唯一验证层时读取 [判断方法](references/methodology.md)。

## 脚本调用

离线 fixture：

```bash
python .agents/skills/a-stock-daily-tier-summary/scripts/analyze_tier_summary.py \
  --input path/to/input.json
```

本地 v2 精确日期读取：

```bash
python .agents/skills/a-stock-daily-tier-summary/scripts/analyze_tier_summary.py \
  --base-url http://127.0.0.1:8001 \
  --date YYYY-MM-DD \
  --previous-date YYYY-MM-DD
```

脚本默认输出 JSON。仅当用户明确允许外部只读降级时添加 `--allow-eastmoney`；该开关不是生产写授权。

## 固定输出

保持以下内容与顺序，所有字段都由结构化结果填充，不输出占位符：

```text
上证指数上涨；深证成指、创业板指、沪深300、中证500下跌
MA20下方：上证指数、深证成指、创业板指、沪深300、中证500
上涨占比40%
全A涨跌幅中位数-0.46%
五指数5日成交额比值中位数1.03
放量上涨/下跌为0/0
今日宽度标签：同向走弱。
核心证据：与指数一致。
昨日验证结果：高位层确认失败，并列出原阈值和观测计数。
今日分层结论：高位、中位、低位和失败样本修复均列出分子、分母或结果计数。
风险主要位于高位层，当前属于一个描述性结构标签，并列出支持它的 pool 变化。
下一交易日只验证低位层：确认条件为可观测计数，失效条件为可观测计数。
因此今天属于弱势分化、保持观察。
置信度低。
下一交易日只验证：一个环境概念及其数值阈值和期望方向。
```

示例中的数值和指数分组只是格式演示，实际输出必须来自目标交易日。方向分组同时存在时用分号分隔；MA20 上下方同时存在时在同一行分别具名。若休市或降级，在卡片前增加一句日期/质量说明。若无上一计划，验证行写“未找到可追溯的上一交易日验证条件”；若某个验证域没有充分证据，只将该验证行写为“待数据充分后确定”，不得编造条件。

## 不变量

- 高位为连续 4 板及以上，中位为 2 至 3 板，低位为首板；按上一交易日样本冻结后观察今日结果。
- 本地数据只用有效 `streak_days`；东方财富降级只用 `lbc`。`zttj.days`、`zttj.ct` 只能保留为模式元数据，绝不能用于分层。
- 按交易所加证券代码去重。相同重复行计一次并告警；同一身份的冲突行拒绝，不任选一条。
- 失败样本修复率是“昨日炸板且今日收盘涨停 / 昨日炸板样本”。分母为 0 时输出 `null/insufficient`，不是 `0%`。
- “脱离三池”仅表示未出现在今日涨停、炸板、跌停池，不能解释为普通上涨、停牌或特定亏损。
- 环境与分层证据必须使用同一当前交易日和 revision；禁止把其他日期的涨停、跌停、炸板或分层结果拼进当前指数结论。
- 环境判断优先复用 `synchronizationAssessment` 和 v2 原始指数、breadth 事实；不得因 `marketEvidence.directionPattern` 单字段缺失而覆盖有效的规范证据，也不得复制一套不同阈值。
- 分层验证与环境验证是两个独立假设。前者只选一个高/中/低位层，后者只选一个宽度、MA20 或成交概念；不能互相替代。
- 结构标签必须带事实依据并保持 `needs-backtest`；不输出 0–100 风险分数、仓位、买卖点或个股建议。
- 不保存会话计划或每日行情，不提交真实快照、原始 provider 响应、凭据或运行时产物。
