# STEP 2 评分规则

所有阈值冻结在 JSON `config`，并随 `reportId` 一起变化。规则族 `QTS-04-02`，校准状态 `needs-backtest`。

## 1. 题材单元

```
题材 = 概念当前成分股 ∩ 当日涨停池
```

- 概念目录来自 `index catalog --tag cn_concept`；成分股来自 `index constituents`。
- 只保留交集非空的概念；单只概念成员不构成题材。
- 共享 token 只在上述交集内部统计；同一 token 至少由 2 只交集成员持有才计入。

## 2. 原因词拆分

- 全角 `＋` 与半角 `+` 都视为分隔符；`/`、`、`、`，`、`;`、空白同样分隔。
- 去掉括号内内容（如“（试点）”）。
- 去掉通用后缀：`概念`、`板块`、`方向`、`题材`、`产业链`。
- 去重并保持出现顺序。

## 3. 停用词与属性词

- 内置停用表见 `theming.STOP_TOKENS`，覆盖回购/增减持/业绩/公告/政策/连板/ST/次新等事件或状态词。
- 跨概念检测：一个 token 同时出现在 ≥4 个概念的涨停成员原因里，判为属性词，不产生共享催化。
- 停用词与属性词仍保留在原始 `limitUp.reason`，只是不进入 `sharedTokens` 与催化来源。

## 4. lift

```
marketLimitUpRate = 当日涨停总数 / 市场股票数
expected           = 成员数 × marketLimitUpRate
lift               = 命中涨停成员数 / expected
```

- 市场股票数默认 5400，冻结进 `config.marketStockCount`。
- `expected` 为 0 或成员数为 0 时 `lift=null`，不得补 0。
- lift 是硬闸门：
  - 核心：`lift ≥ 3.0`
  - 扩散：`1.5 ≤ lift < 3.0`
  - 伪题材：`lift < 1.5`

2026-11-13 实测：短剧游戏 9.95（核心）、算力租赁 2.26（扩散）、新能源汽车 1.33（伪题材）。

## 5. 六项指标

| 指标 | 权重 | 五档切点 | 数据来源 |
|---|---:|---|---|
| `relative_strength_5` | 0.20 | 0 / 2% / 5% / 10% | 概念 5 日收益 − 基准 5 日收益 |
| `relative_strength_20` | 0.10 | 0 / 5% / 10% / 20% | 概念 20 日收益 − 基准 20 日收益 |
| `turnover_ratio` | 0.15 | 0.8 / 1.0 / 1.2 / 1.5 | 当日成交额 / 20 日均额 |
| `member_breadth` | 0.15 | 30% / 50% / 60% / 80% | 成员上涨家数 / 有行情成员数 |
| `limit_up_ladder` | 0.20 | 1 / 2 / 3 / 4 | 交集成员最高连板 |
| `shared_token_coverage` | 0.20 | 0 / 20% / 30% / 50% | 最大共享 token 持有数 / 涨停成员数 |

五档记分：低于第一切点 0 分，依次 25 / 50 / 75，达到最后切点 100。

总分 = 可用指标加权平均；可用权重覆盖率 <50% 时 `score=null`、`status=insufficient`，不补 0。

## 6. 分级闸门

| 分级 | 条件（全部满足） |
|---|---|
| 核心 `core` | `score ≥ 50`；`lift ≥ 3.0`；共享 token ≥2；最高连板 ≥2 或涨停成员 ≥4 |
| 扩散 `diffuse` | `score ≥ 35`；`lift ≥ 1.5`；涨停成员 ≥2；有共享 token |
| 事件 `event` | `lift ≥ 1.5`，但无共享 token / 分数不足 / 单只成员 |
| 伪题材 `pseudo` | `lift < 1.5` |

- 任一项不满足即降级，`tierReasons` 记录失败原因。
- 当日没有 `core` 时输出 `noCoreTheme=true`，原因枚举为 lift / 共享 token / 梯队 / 分数。
- 空结果是合法结论，不得为凑报告降级计入核心。

阈值校准说明：2026-11-13 短剧游戏成员宽度 31.7%、最高连板 1，若核心分数闸门取 70 会被判成无核心；因此 v1 把核心分数闸门校准到 50，同时把核心 lift 提到 3.0，避免把算力租赁（2.26）误判为核心。该阈值仍需 1 年回放验证。

## 7. 催化四档

| 标签 | 判据 | v1 可达 |
|---|---|---|
| `confirmed` | 交易所/公司公告/监管文件等主源可枚举且相互印证 | 否 |
| `partial` | 有共享 token，且至少 1 条异动解读命中该 token | 是 |
| `speculative` | 有共享 token，但没有独立异动解读 | 是 |
| `unknown` | 交集内没有共享 token | 是 |

- `confirmed` 不可达是硬约束：异动解读文本自带“AI 技术搜集公开信息总结生成”，不能当作主源。
- `catalyst.sources` 记录来源类型、provider、日期、引用与 token/股票代码；文章只能转述这些来源。
- 异动解读的股票代码是 6 位裸码，落库时按 `marketId=17/33` 补 `.SH`/`.SZ`。

## 8. 确认/失效谓词

复用 `qts04-core` 的扁平谓词结构：

- 确认：次日收盘 ≥ 当日收盘 × 1.005，且成交额 ≥ 20 日均额。
- 失效：次日收盘 < 当日收盘 × 0.97，或成交额 < 20 日均额 × 0.8。
- 缺次日行情时求值为 `unknown`；不得用当日或相邻日期代替。

## 9. 质量与回测边界

- `quality.pointInTime=false`：成分股只有当前快照。
- `quality.backtestGrade=D`：成员不可回溯、涨停池约 1 年、异动解读为 AI 文本。
- `quality.membershipGap`：成员数 vs 当日有行情成员数的缺口；大成员概念按样本估计，并标记 `estimated-from-sample`。
- 任何缺失数据输出 `degraded` / `insufficient`；不借相邻日期、不补 0、不伪造成功。
