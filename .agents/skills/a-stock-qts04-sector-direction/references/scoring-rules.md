# QTS-04-01 板块层打分规则

对应 `搭建交易系统-量化版/04-板块、题材与个股筛选/01.板块筛选.md`。规则 ID、权重与窗口是稳定接口，不得重排。

全部阈值状态为 `needs-backtest`：它们是排序工具，不是已验证信号。

## 权重骨架

| 规则 ID | 指标 | 权重 |
|---|---|---:|
| `QTS-04-01-01` | 5 日相对强度 | 25% |
| `QTS-04-01-02` | 20 日相对强度 | 15% |
| `QTS-04-01-03` | 成交额增量 | 20% |
| `QTS-04-01-04` | 板块宽度 | 20% |
| `QTS-04-01-05` | 持续与恢复 | 20% |

指标缺失时按剩余有效权重重新归一，缺失项记 `null`，不补 0。

上述权重、五档边界、最少观测、覆盖率门槛、四象限与池位/置信度阈值，以及确认/失效系数，全部冻结进 JSON 的 `config` 块；`config` 参与 `reportId` 计算，因此改阈值即换号。规则文件与 `config` 不一致时以代码常量为准，并视为文档缺陷。

## 五个指标

### QTS-04-01-01 5 日相对强度

- 公式：`sectorReturn5 - benchmarkReturn5`，逐日超额收益在最近 5 个共同交易日内累加。
- 基准：`000001.SH`。
- 窗口：5 日计算，250 日滚动分位。
- 打分：按 250 日分位五档。

### QTS-04-01-02 20 日相对强度

- 公式：`sectorReturn20 - benchmarkReturn20`，同上累加 20 日。
- 窗口：20 日计算，250 日滚动分位。
- 打分：按 250 日分位五档。

### QTS-04-01-03 成交额增量

- 公式：`turnover(today) / mean(turnover, 20)`，20 日均值**不含当日**。
- 窗口：20 日，250 日滚动分位。
- 分母为零或缺失 → `null`，状态 `insufficient`。

### QTS-04-01-04 板块宽度

- 公式：成分股中 `close > MA20` 的比例，MA20 为 20 日收盘均值（含当日）。
- 覆盖率：`有效成员数 / 成分股总数`。
- **否决**：覆盖率 <70% 时该行业不排名，状态 `insufficient`，`missingReason` 为 `constituent-coverage-below-70%`。
- 分位样本：用同一批成分股日线回溯计算最近 250 个交易日的宽度，不额外请求。
- 打分：按 250 日分位五档。

### QTS-04-01-05 持续与恢复

- 两个分量：
  - 近 5 日跑赢基准的天数（0—5）
  - 20 日区间最大回撤修复率 = `(当前收盘 - 区间低点) / (区间高点 - 区间低点)`
- 分量打分（上游为「预先列明的五档边界」，此处显式落地）：

| 跑赢天数 | 分 |
|---:|---:|
| 0 | 0 |
| 1 | 25 |
| 2 | 50 |
| 3 | 75 |
| ≥4 | 100 |

| 修复率 | 分 |
|---|---|
| ≤0.20 | 0 |
| 0.20—0.40 | 25 |
| 0.40—0.60 | 50 |
| 0.60—0.80 | 75 |
| >0.80 | 100 |

- 指标值 = 两个分量分的算术平均；`percentile` 记为 `null`，因为本规则使用固定档位而非滚动分位。

## 滚动分位与降级

- 窗口：250 个交易日。
- 最少观测：**严格 60**。
- 观测 <60 → `insufficient`，`score=null`。
- 60 ≤ 观测 <250 → `reduced-confidence`，按同一五档给分。
- 观测 ≥250 → `ok`。

五档边界：

| 分位 | 分 |
|---|---|
| ≤0.20 | 0 |
| 0.20—0.40 | 25 |
| 0.40—0.60 | 50 |
| 0.60—0.80 | 75 |
| >0.80 | 100 |

分位采用 midrank，包含当前观测，并列取值相同。

## 总分与池位

- 总分 = `Σ(指标分 × 归一权重)`，取值范围 0—100。
- 池位：
  - 总分 ≥70 且持续性分 ≥60 → 重点池（`focus`）
  - 总分 50—69 → 观察池（`watch`）
  - 总分 <50 → 不参与（`excluded`）

## 置信度

按有效指标覆盖率，并受观测窗口限制：

| 覆盖率 | 上限 |
|---|---|
| ≥90% | high |
| 70%—89% | medium |
| 50%—69% | low |
| <50% | insufficient |

任一指标为 `reduced-confidence` 时，最高只能给 `medium`，避免短历史声称高置信度。

## 四象限

只用原始值判定，不依赖分位：

- 资金强度高：`成交额增量 ≥ 1.20` 且 `5 日相对强度 > 0`
- 上涨覆盖广：`advance_ratio ≥ 0.50`（`advance_ratio` 为成分股当日上涨比例）

| 强度 | 覆盖 | 象限 |
|---|---|---|
| 高 | 广 | 真实流入 |
| 高 | 窄 | 短线脉冲 |
| 低 | 广 | 权重拉升 |
| 低 | 窄 | 资金撤退 |

任一分量为 `null` 时输出 `label=null` 并给 `reason`，不猜测象限。

## 确认与失效条件

每个方向输出两条**结构化谓词**，中文只是它的渲染结果：

- 确认：`close >= 当日收盘 × 1.005` 且 `turnover >= 20 日均额 × 1.0`
- 失效：`close < 当日收盘 × 0.97` 或 `turnover < 20 日均额 × 0.8`

字段形态为 `{text, horizonDays, all:[{field, op, value, basis}]}`，`horizonDays = 1` 表示报告日之后第一个交易日。

系数属于冻结配置的一部分，随 `config.confirmation` / `config.invalidation` 一起输出：

| 参数 | 值 | 含义 |
|---|---:|---|
| `confirmation.closeMultiplier` | 1.005 | 确认阈值 = 当日收盘 × 1.005（正文写作 +0.5%） |
| `confirmation.closeChange` | 0.005 | 同一系数的增量表达，供正文 `+0.5%` 溯源 |
| `confirmation.turnoverMultiplier` | 1.0 | 确认量能门槛 = 20 日均额 |
| `invalidation.closeMultiplier` | 0.97 | 失效阈值 = 当日收盘 × 0.97（正文写作 -3%） |
| `invalidation.closeChange` | -0.03 | 同一系数的增量表达 |
| `invalidation.turnoverMultiplier` | 0.8 | 失效量能门槛 = 20 日均额 × 0.8 |

`value` 与 `text` 使用同一舍入（收盘两位小数、成交额取整），阈值由当日收盘价与 20 日均额直接算出，不留给用户自行换算，也不允许手写散文。

系数为显式经验默认值，状态 `needs-backtest`；调参必须同步 `config`、本文与测试，并接受 `reportId` 变号。

## 边界

- 不输出 `validated`、买卖点、仓位、个股推荐或交易指令。
- 不从公开行情推断主体意图；无法可靠观察的证据不进入评分。
- 本文件与 `src/` 中的申万持续性实现（`QTS-01-05-*`）是不同规则族。二者共享分位与五档约定，但指标定义、权重和覆盖范围不同，不得互相替代或合并阈值。
- 上游文档中提到、但本阶段未落地的项：题材共同催化（STEP 2）、主力资金流口径、集合竞价数据、财务数据（STEP 8）。
