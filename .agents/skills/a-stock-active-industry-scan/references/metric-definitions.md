# 指标口径

## 1. 换手率

```
turnover_pct = volume(shares) / float_shares × 100
float_shares = 流通市值 / 价格
```

口径固定为 **`float-share`**（自由流通股本为分母）。

**为什么必须冻结口径**：总股本与流通股本算出的 Top50 只有 31/50 重合。两个口径都「正确」，但混用会让榜单不可比较，因此 `turnoverBasis` 固定输出 `float-share`。

2026-11-19 用该公式对 50 只股票与新浪官方 `turnoverratio` 比对：**最大相对误差 0.00%，中位 0.000%**。

## 2. 历史分位的等价性

分位数只用成交量计算，不用换手率：

```
turnover = volume / float_shares
```

在固定窗口内 `float_shares` 是常数，上式是 `volume` 的**单调线性变换**，因此

```
percentile(volume) ≡ percentile(turnover)
```

实测验证：50 只股票，换手率分位与成交量分位**不一致的数量为 0**。

这个等价性带来两个好处：

1. 不需要历史股本数据，只需历史成交量。
2. 避免使用「今天的股本」去折算「昨天的成交量」这种时点错配。

**不可检测的限制**：若窗口内发生解禁、增发或回购注销，真实换手率会跳变，而按固定股本折算的历史序列看不到这个跳变。此时窗口内较早的分位会失真。本口径在窗口内股本稳定时有效。

## 3. 盘中为什么不给分位

当日累计成交量与历史**全天**成交量不是同一口径。

实测个股在 10:30 的累计成交量占全天比例：

```
中位  48.1%
范围  37.9% – 63.7%     （相差 1.7 倍）
```

若按统一比例放大，误差极大。若用每只股票自身历史的 10:30 占比中位数外推全天量，实测：

```
预测误差：中位 30.0%，平均 31.9%，最大 82.5%
```

误差无法支撑「是否历史极值」的判断。因此：

- `sessionState ∈ {preopen, intraday, lunch, settling}` → 分位字段输出 `deferred`，附 `reason` 与 `availableAfter`。
- `sessionState = closed` → 才计算并输出 `ok` / `insufficient`。

**任何状态都不按固定比例缩放估算分位。**

## 4. 分位的 bar 数阈值

| bar 数 | 状态 |
|---|---|
| < 60 | `insufficient`，分位与放大倍数均为 `null` |
| ≥ 60 | `ok` |

不用短窗口凑一个数字：3 根 bar 的「历史」会让每只次新股都显示成历史极值。

与新股过滤联动：`--min-listing-days` 默认 250（约 250 个交易日），过滤后实测 bar 数最小 239，`bar < 60` 的股票从 9 只降为 0 只。两个阈值因此不再冲突。若把 `--min-listing-days` 调小，`bar < 60` 的兜底才会真正生效。

## 5. 放大倍数

```
amplification = 今日值 / 前 20 个交易日均值
```

均值**不含当日**，否则单日尖峰会抬高自己的基线。

这个字段的价值在于区分「绝对高」与「相对高」：

| 股票 | 今日换手 | 20 日均 | 放大倍数 | 解读 |
|---|---|---|---|---|
| 华东重机 | 51.33% | 3.35% | 15.31x | 相对自身也是极值 |
| 果麦文化 | 35.66% | 39.90% | 0.89x | 绝对值高，实际缩量 |
| 冰山冷热 | 30.06% | 37.39% | 0.80x | 同上 |

只看绝对值会把缩量股误判为放量股。

## 6. 四象限

判定只用两个榜的**绝对命中数**，阈值默认各 2 只。

| 成交额榜命中 | 换手榜命中 | 象限 | 含义 |
|---|---|---|---|
| ≥ 2 | ≥ 2 | 真实活跃 | 有资金规模，也有筹码交换 |
| ≥ 2 | < 2 | 权重拉升 | 大资金参与但换手温和 |
| < 2 | ≥ 2 | 小盘情绪 | 筹码剧烈交换但容量小 |
| < 2 | < 2 | 冷门 | 两个榜都不入 |

象限判定**完全不看涨跌**。高成交额或高换手本身不含方向：2026-11-20 收盘，成交额榜 Top50 有 34 只下跌、换手率榜 Top50 有 30 只下跌，它们照样落在「真实活跃」象限。方向由下一节单独给出，两者交叉而不是互相替代。

### 为什么不用 lift

`lift = 命中数 / (成员数 × 基准率)` 在小行业上系统性虚高。2026-11-19 实测：

```
环保设备  3/30  = 10.0%
通用设备  5/255 =  2.0%
全市场基准率      0.9%
```

环保设备仅 3 只上榜，lift 却是通用设备的 5.6 倍。按 lift 排序会把小行业稳定排在前面，而「小行业因分母小显得活跃」不是资金信号。

### 命中率的定位

`hitRate = 命中数 / 成分股总数` 照常输出，但：

- **不参与象限判定**
- **不作为唯一排序键**

排序用 `(是否双榜命中, 总命中数, 成交额命中数, 换手命中数)`，保证双榜都出现的行业优先，再按绝对数量排。

分母为 0（空行业）时命中率输出 `null`，不是 0。「不知道」与「没有」必须区分。

## 7. 方向与宽度

方向层回答「活跃的钱在买涨还是卖跌」。它与四象限**正交**：象限只看命中数，方向只看涨跌，两者交叉而不互相改写。

### 绝对方向

```
direction = up    if changePct >  FLAT_EPSILON
            down  if changePct < -FLAT_EPSILON
            flat  otherwise
            suspended  if changePct is null or volume <= 0
```

- `changePct` 基准是**前一收盘价**（`direction.basis = "changePct-vs-prev-close"`）。
- `FLAT_EPSILON = 0.005`（%）。等比变动在 ±0.005% 内视为平盘，避免把浮点噪声读成涨跌。
- **停牌不算平盘。** 当日无成交（`volume` 为 0 或无涨跌幅）记 `suspended`，剔出涨跌家数的分母。
- **无数据不算停牌。** 本次没取到该股行情记 `unknown`，同样不计入涨跌，但语义是「不知道」而非「没交易」。

### 相对方向

```
relativeToMarketPct = 等权成员中位涨跌幅 - 全市场中位涨跌幅
```

减数是 `direction.market.medianChangePct`，随报告一起输出，可直接复核。

**基准为什么用全市场等权中位，而不是上证指数。** 2026-11-20 收盘实测：全市场中位 -5.08%（313 涨 / 5236 跌），而上证 -1.23%。用指数作基准只有 4 个行业强于大盘、86 个弱于大盘；用等权中位是 53 强 / 37 弱。指数受权重股托举，会把「小盘普跌、指数抗跌」的日子读成全市场皆弱，方向层就失去分辨力。

### 行业方向的三类证据

行业方向不是单一公式，而是**按优先级取第一个可用证据**，并写明用了哪一个（`directionBasis`）：

| 优先级 | 证据 | `directionBasis` | 口径 |
|---|---|---|---|
| 1 | 成员等权中位涨跌幅 | `member-median` | 与相对基准同口径，最能代表「多数个股」 |
| 2 | 板块指数涨跌幅 | `board-index` | 市值加权，权重股独走时与宽度背离 |
| 3 | 上榜个股涨跌多数 | `hit-majority` | 只反映榜单内，样本小 |
| — | 都不可用 | `unavailable` | 方向为 `null`，不猜测 |

三类证据会给出不同答案，因此全部保留为独立字段而不是揉成一个数。2026-11-20 实测：

```
元件板块    指数 -0.82%，成员等权中位 -2.40%   → 指数被权重股托住，多数个股在跌
半导体板块  指数 -6.85%，成员 7 涨 / 182 跌    → 两种口径同向
银行板块    指数 +0.22%，成员 23 涨 / 19 跌    → 指数涨但内部并不一致
```

### 宽度覆盖率门槛

```
coverage = (涨 + 跌 + 平) / 成分股总数
coverage < 0.70  →  memberBreadthStatus = "insufficient"，中位与相对方向为 null
```

覆盖率不足时**不给中位数**：样本太少的「中位」在统计上没有意义，输出 `null` 比输出一个看似精确的数字更诚实。此时行业方向会退到板块指数或上榜多数，并如实写明来源。

2026-11-20 实测各层级覆盖率最低 95.8%，没有行业低于 70%，门槛在正常数据下不会触发。

### 上涨股成交额占比

```
upAmountShare = 上涨股成交额之和 / 全部上榜股成交额之和
```

它与涨跌家数是**两个独立维度**：可以「跌的家数多但上涨股占了大部分成交额」（少数权重股放量上涨），也可以相反。因此分开输出，不合成一个「多空比」。

### 方向不参与排序与筛选

- 行业列表顺序仍由 `(是否双榜命中, 总命中数, ...)` 决定，方向只加字段。
- `handoff.candidateThscodes` 仍只由命中数决定，下跌行业照样进候选清单。
- 方向不参与打分、不加权、不改变 `--top` / `--top-sectors` 的截断结果。

这条边界是刻意的：一旦方向参与排序，「活跃」就被悄悄替换成「活跃且上涨」，用户看到的活跃度榜单就变了含义。

## 8. 交集

```
交集 = 成交额榜 Top N ∩ 换手率榜 Top N
```

- 输出每只股票在各自榜的排名。
- 交集为空时输出空数组并说明，**不放宽阈值**、不改用「任一榜前若干名」。
- 交集为空不代表运行失败，`quality.status` 仍为 `ok`。
- 每只交集股票附 `changePct` / `direction` / `relativeToMarketPct`，并在报告里按涨跌分组呈现。

2026-11-19 实测交集 5 只；10:30 时点为 9 只，且收盘的 5 只全部包含在 10:30 的 9 只内。这是**单日样本**，不能推断早盘交集必然包含收盘交集。

2026-11-20 收盘实测交集 4 只，方向分化明显：华胜天成 +3.71%、冰山冷热 +10.03% 上涨，九阳股份 -7.21%、宏景科技 -5.32% 下跌。同为「既有规模又有交换」，方向可以完全相反——这正是需要方向层的原因。

## 9. 盘中排名的有效性

横截面排名在盘中是可用的，因为所有股票处于同一时间截面。实测 10:30 与收盘对比：

```
换手率榜 Spearman 0.982，Top50 重合 43/50
成交额榜               Top50 重合 36/50
```

这是「盘中能回答最活跃行业」的依据。它不依赖任何历史窗口，因此不受累计量影响。
