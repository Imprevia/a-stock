# 指数、趋势位置和成交额：补全缺口与第四部分呈现重做

## Why

第 01 节《指数、趋势位置和成交额》的原版方法论与看板实现之间存在五处缺口：指数同步性只输出"同步上涨 / 普遍走弱 / 指数分化"笼统三态，无法区分原版定义的"权重护盘"与"成长占优"两种分化模式；原版第五部分"每日盘后记录模板"（含收束句式）没有任何看板对应物；量化规则 `QTS-01-01-01/02/05` 对应的三个指标（五指数均线多头比例、MA20 斜率 250 日滚动分位、量价推进效率 250 日滚动分位）从未上屏——其中两条需要 250 日分位，而 provider 当前只拉取 160 根 K 线，数据层根本不支持；指数同步性、20 日区间位置、5 日成交额比值三个已在看板实现的口径没有登记规则条目（缺 `QTS-01-01-06/07/08`）；数据缺失时页面只显示"数据不足"，没有原因分层。

同时第四部分（把指数、位置和成交额结合起来）的呈现只能查看选中指数的单一组合结果，五个指数的组合全景不可见，"单指数判定 → 市场层结论"的推导链没有视觉表达。本次变更在补全五个缺口的同时重做第四部分呈现。

## What Changes

- **指数同步性五态细分**：从三态扩展为"同步上涨 / 权重护盘 / 成长占优 / 普遍走弱 / 分化未定型"，权重组（上证、沪深300）与成长组（创业板、中证500）的分化按原版口径识别；未命中任何明确模式时输出"分化未定型"，不猜测。
- **登记三条新规则（append-only）**：`QTS-01-01-06`（指数同步性五态）、`QTS-01-01-07`（20 日区间位置）、`QTS-01-01-08`（5 日成交额比值）。量化文档、`trading-rules` YAML、coverage 清单同步登记为 executable；已有规则 ID 不重排，`QTS-01-00-01` 价格量能组成员与权重不变（新规则不入评分组），可执行范围从 46 条扩至 49 条。
- **三个规则指标上屏**：市场层输出五指数均线多头比例；单指数层输出 MA20 斜率 250 日滚动分位与量价推进效率 250 日滚动分位。指数 K 线 provider 拉取深度从 160 根提升到 280 根以上，覆盖 250 日窗口加最少 60 有效观测的校准契约。
- **第四部分呈现重做**：以"五指数 × 六类组合"矩阵为骨架——每行一个指数、命中组合高亮并附关键数值、点击行展开命中证据；矩阵顶部保留"四问"结论条（市场是否真强 / 所处阶段 / 资金是否认可 / 交易模式），结论由矩阵列汇总推导且证据可回溯；保持"未命中不兜底分类"原则。
- **盘后收束句自动生成**：按原版第五部分句式自动生成今日结论句（同步性、20 日线位置、60 日区间位置、成交额相对 5 日均值、价格推进、环境倾向），任一成分缺失时分段标注"数据不足"，不编造。
- **数据缺失原因分层**：指标为 null 时输出原因枚举（历史窗口不足 / 当日数据缺失 / 供应商失败 / 数学上不可计算），前端按原因显示区分化缺失文案。

不改变：六类组合的判定阈值与匹配优先级、`QTS-01-00-01` 评分组结构、现有 API 字段语义（只新增字段）。

## Capabilities

### New Capabilities

- `index-combination-analysis`: 第 01 节指数组合分析的完整看板能力——五态同步性判定、规则指标计算与上屏（含 250 日分位与 provider 深度要求）、五指数组合矩阵与四问结论条呈现、盘后收束句生成、数据缺失原因分层。

### Modified Capabilities

- `trading-rule-registry`: coverage 清单覆盖数量随三条新规则登记从 327 扩展到 330；新增"append-only 规则登记不得变更既有评分组成员与权重"的约束，保证 golden trace 与既有证据不受影响。
