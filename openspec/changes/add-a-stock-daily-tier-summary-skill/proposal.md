## Why

当前高位、中位、低位亏钱效应复盘依赖对话中临时拼装脚本，日期选择、证券去重、连板字段和上一交易日验证条件缺少稳定约束，已经出现把东方财富 `zttj.days` 误作连续板数而形成假高度的风险。需要将这套重复工作固化为仓库级 Skill，让 Agent 能以精确交易日和可追溯样本生成一致的盘后结论，并在证据不足时明确停止判断。

## What Changes

- 新增仓库级 `a-stock-daily-tier-summary` Skill，响应“今天/昨天的分层总结”等请求，并固定输出上一验证结果、三层结论、市场结构和下一交易日验证条件。
- 新增确定性分析脚本，按规范证券身份去重，使用本地事实 `streak_days` 或东方财富 `lbc` 将涨停样本划分为高位（四板以上）、中位（二至三板）和低位（首板），并交叉相邻交易日三类池。
- 优先读取本地精确日期、只读市场数据 API/快照；仅在用户明确请求盘后真实数据且本地证据不可用时允许外部只读降级，保留来源、实际日期和质量状态。
- 计算各层续板、炸板、跌停和脱离样本，以及昨日炸板样本的当日收盘涨停修复率；分母为零或样本不完整时返回 `insufficient`，不填充零值。
- 支持周末、节假日和“今天/昨天”语义，始终映射到最近已完成且可证明的交易日，不用其他日期数据冒充目标日期。
- 若会话中存在上一交易日预设的确认/失效条件，则先给出验证结果；没有可追溯条件时明确说明无法验真，不反推条件。
- 将“扩散、抱团、低位试错、修复、混合”限制为描述性结构标签，不生成未经回测的风险分数或交易建议。
- 增加字段误用、重复证券、日期不一致、零分母、休市日和验证条件边界的离线测试与 Skill 校验。

## Capabilities

### New Capabilities

- `daily-tier-summary-skill`: 为 Agent 提供精确日期、质量受控、可重复的高/中/低位亏钱效应日更总结和上一交易日条件验证能力。

### Modified Capabilities

- 无。现有 `limit-ecosystem-dashboard-parity`、`ai-market-data-api` 和市场数据采集行为保持不变；新 Skill 作为只读消费者复用已有合同。

## Impact

- 新增 `.agents/skills/a-stock-daily-tier-summary/` 下的 Skill 指令、分析脚本和按需读取的参考文档。
- 新增针对分析脚本的离线测试和固定小型样本，不提交真实市场快照或运行时产物。
- 实现阶段需要同步 active exec plan、仓库指南或适用的 Skill 文档映射，并通过 Skill 快速校验、聚焦 pytest 和 docs-contract gate。
- 不修改 FastAPI 路由、数据库 schema、交易规则 YAML、生产配置、调度、凭据或远端市场数据。
