# 搭建交易系统量化版

## 目标

本目录把原知识库中的描述性判断重写为可记录、可复算、可回测的规则草案。所有 `needs-backtest` 阈值均为经验初值，不代表已经取得统计优势，也不构成投资建议。

## 输入与数据口径

- 全市场默认采用全A可交易样本，排除停牌和无有效行情标的。
- 主板、创业板、科创板、ST及上市不足对应窗口的股票分层统计，不混用涨跌幅制度。
- 日频收盘数据负责环境和候选分类；分钟数据只用于竞价、买卖时点、承接、成交质量和异常确认。
- 默认窗口：5日短期、20日结构、60日环境、250日阈值校准；不足60个交易日不得输出高置信度。

## 量化规则

| 规则ID | 规则 | 固定定义 |
|---|---|---|
| `QTS-00-00-01` | 五档评分 | 指标统一映射为0、25、50、75、100分；方向相反的风险指标反向计分。 |
| `QTS-00-00-02` | 滚动分位 | 无可靠绝对阈值的市场变量按250日P20、P40、P60、P80分档；均标记为经验初值、待回测。 |
| `QTS-00-00-03` | 置信度 | 有效覆盖率≥90%、证据一致且完成确认才为高；70%–89%或一组冲突为中；低于70%、关键缺失或多组冲突为低。 |
| `QTS-00-00-04` | 否决优先 | 数据错误、不可交易、系统性风险、账户硬风险或逻辑失效不能被其他高分抵消。 |
| `QTS-00-00-05` | 状态晋级 | `defined`表示公式确定；`needs-backtest`表示经验规则；只有满足第10章证据要求才能标记`validated`。 |

组合分只对有效指标按权重重新归一。若某组覆盖率为50%–69%，最高置信度为低；低于50%则输出“数据不足”。风险否决相关数据缺失时按未知风险处理，不得假设安全。

## 数据缺失与异常处理

- 分母为0、行情无效或样本归属不明时记为`null`，不得用0伪装有效输入。
- 对剩余有效指标重新归一权重；否决项输入缺失时保留风险提示。
- 极端值用于风险识别时保留原值，用于均值与分位时同时输出稳健统计。

## 校准与验证

- 固定定义可标记为`defined`，经验阈值统一标记为`needs-backtest`。
- 升级为`validated`前必须满足第10章的样本外、成本、版本和回滚证据。
- 每次阈值修改必须保留旧版本、训练区间、验证区间和变更原因。

## 输出接口

每条规则必须提供：`ruleId`、适用范围、数据口径、公式、窗口、阈值与得分、权重、否决条件、缺失处理和状态。每篇文档输出以下稳定字段：

```yaml
asOf: YYYY-MM-DD
score: 0-100
state: string
confidence: high | medium | low | insufficient
coverage: 0-1
triggeredRules: []
vetoes: []
missingInputs: []
confirmation: string
invalidation: string
ruleVersion: "0.1"
```

## 风险姿态

- 进攻：综合分70–100且无否决，风险预算倍率为用户基准的1.0倍。
- 防守：综合分40–69，风险预算倍率为用户基准的0至0.5倍。
- 空仓：综合分0–39，或触发系统性、账户级、流动性或数据质量否决，风险预算倍率为0。

这些边界是经验初值，必须按第10章完成样本外验证后才能升级状态。

## 使用边界

- 形态、评分和候选排名只能形成研究对象，不能单独替代交易计划。
- 公开行情不能可靠证明具体机构、游资或量化主体的身份和主观意图；此类判断排除出评分。
- 阈值校准必须保留旧版本、训练与样本外区间、成本假设、暂停条件和回滚条件。
