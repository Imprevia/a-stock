# 1.指数、趋势位置和成交额

## 目标与输出

量化指数方向、均线结构、区间位置以及成交是否转化为价格推进。

**组合判定：**指数趋势分为各指数得分的等权均值；至少3个主要指数同向且总分≥70才定义为趋势候选。单一指数强而广度背离时只输出混合候选。

## 输入与数据口径

- 市场类指标使用全A可交易样本，并按主板、创业板、科创板、ST和上市不足窗口样本分层。
- 价格使用前复权序列计算收益、均线和区间位置；成交额、换手率和涨跌停统计使用当日原始交易口径。
- 日频结论以收盘后数据为准；分钟级数据只在规则窗口明确要求时使用。
- 默认分位校准窗口为250个交易日，最少60个有效观测；不足时降低置信度或输出数据不足。

## 置信度计算方法

置信度表示当前证据的完整性和一致性，不表示次日上涨概率、收益概率或策略胜率。第 01 页存在三个相关但不同的置信度位置，使用时必须区分：

| 位置 | 计算对象 | 输出含义 |
|---|---|---|
| 跨指数关系·联合确认 | 指数同步性、市场宽度、MA20 位置和成交确认 | 当前同步上涨、权重护盘、成长占优或普遍走弱判断是否被证据确认或反驳 |
| 四问结论与五指数矩阵 | 联合确认结果及相同明确组合的指数数量 | 多数指数是否落入同一个已定义组合；少数指数命中时只给低置信度 |
| 第 01 章证据总览 | 广度、涨跌停、行业、容量和事件数据质量 | 章节证据覆盖程度；不是方向预测置信度 |

### 联合确认的分支

先生成四类维度：

1. **指数同步性**：至少 4 个有效指数涨幅达到 `0.5%`为同步上涨；至少 4 个跌幅达到 `-0.5%`为普遍走弱；上证/沪深300与创业板/中证500反向时识别权重护盘或成长占优；其他情况为分化未定型。
2. **市场宽度**：上涨占比 `>=55%` 且涨跌幅中位数 `>0`为正；上涨占比 `<=45%` 且中位数 `<0`为负；其余为混合。
3. **趋势位置**：五大指数中至少 3 个收盘高于 MA20 为正，至少 3 个低于 MA20 为负；有效观测少于 3 个为数据不足。
4. **成交确认**：日涨跌幅达到正负 `0.5%`且 5 日成交额比值 `>=1.2`的指数分别计为放量上涨或放量下跌；至少 3 个同向才形成量能确认。成长占优额外检查创业板指和中证500成交额比值中位数，`>=1.0`为确认，`<0.8`为反向证据。

置信度按假设分支给出：

| 情况 | 置信度 | 解释 |
|---|---|---|
| 同步上涨 + 正向市场宽度 + 上一交易日上涨占比和中位数均改善 | `high` | 普遍强势有当日和改善方向的双重确认 |
| 同步上涨 + 正向市场宽度，但没有可用的上一交易日比较 | `medium` | 当前强势成立，持续性尚未确认 |
| 同步上涨 + 负向市场宽度 | `high` | “指数强但个股弱”的背离判断很确定；不是看多置信度 |
| 权重护盘 + 负向宽度，或成长占优 + 正向宽度 + 成长成交确认 | `high` | 风格结论得到参与面和成交的共同确认 |
| 普遍走弱 + 负向宽度 + 至少 3 个指数低于 MA20 + 至少 3 个放量下跌 | `high` | 系统性走弱的三类证据同时成立 |
| 上述分支的关键数据缺失 | `insufficient` | 不形成确定性结论 |
| 没有明确确认或反证，维度处于混合区 | `low` | 只保留观察标签 |

因此，`high` 也可能出现在 `contradicted` 状态：它表示对“原来的强势/弱势假设被反驳”这件事有充分证据，不表示未来方向确定。

### 覆盖率与章节总览

规则级有效覆盖率按“有效指标数 / 需要指标数”计算：

- `>=90%`：最高允许 `high`；
- `70%` 至 `<90%`：最高为 `medium`；
- `50%` 至 `<70%`：最高为 `low`；
- `<50%`：输出 `insufficient`。

第 01 章证据总览另按数据集质量计算：

```text
coverage = (1 + breadthWeight + limitsWeight + sectorWeight + activeDirectionWeight + eventWeight) / 6
```

质量权重为 `ok=1.0`、`fallback=0.75`、`partial=0.5`、`missing/failed=0`。章节总览当前只有覆盖率达到至少 `0.5` 才能显示低置信度，否则显示 `insufficient`；这和联合确认条的方向置信度不是同一个字段。

以上阈值用于数据质量和证据一致性控制。所有经验阈值仍为 `needs-backtest`，不能解释成已验证的收益优势。

## 看板组合映射

下表是原文第四部分在市场环境看板中的可解释展示映射，复用 `QTS-01-01-01` 至 `QTS-01-01-05` 的输入，不新增评分规则或规则 ID。所有阈值都是经验初值，状态仍为 `needs-backtest`。匹配按风险优先顺序执行；未命中任何明确组合时输出 `null`，不得兜底分类。

| 优先级 | 组合键 | 页面状态 | 明确条件 |
|---:|---|---|---|
| 1 | `trend_damage` | 趋势破坏或退潮 | 收盘低于 MA20、日涨跌幅≤-0.5%、5 日成交额比值≥1.2 |
| 2 | `high_divergence` | 高位分歧或派发风险 | 60 日位置≥80%、日涨跌幅绝对值<0.5%、5 日成交额比值≥1.2、日内收盘位置<50% |
| 3 | `breakout` | 趋势加速或突破确认 | 60 日位置≥80%、日涨跌幅≥0.5%、5 日成交额比值≥1.2、日内收盘位置≥70%、收盘不低于此前 20 日最高价 |
| 4 | `bottom_repair` | 底部修复或启动尝试 | 60 日位置<40%、前一日收盘不高于当时 MA5、当日收盘重新站上 MA5、5 日成交额比值位于 `[1.0,1.2)` |
| 5 | `uptrend` | 上升趋势或主升阶段 | close≥MA5≥MA10≥MA20≥MA60、5 日价格上涨、60 日位置≥60%、5 日成交额比值位于 `[0.8,1.2)` |
| 6 | `rotation` | 震荡轮动 | MA5/MA10/MA20 最大值与最小值之差不超过最小值的 1%，且最近 5 日成交额最大值/最小值≥1.25 |

组合证据必须返回实际数值或触发关系。交易模式仅作为盘后研究提示：底部修复对应“观察修复确认”，上升趋势对应“顺势跟踪”，突破确认对应“趋势跟随，防止追高”，高位分歧对应“降低追高，等待承接”，震荡轮动对应“轮动应对”，趋势破坏对应“风险控制”。

## 下一交易日只验证

### 目标与输出

把今日证据压缩为唯一一项"下一交易日只验证"字段，用于盘后研究和复盘对错，不预测次日涨跌或点位。该字段由观察项、触发阈值与期望方向三段组成，按固定优先级取自本篇已定义的置信度分支，不新增评分规则，不复用"强弱形容词"。

### 选层逻辑

选层必须按以下固定顺序执行；命中第一层即停止，不再向后评估。

1. **A1 数据缺失优先**：联合确认所需字段（交易日期、上一交易日快照、五大指数涨跌、MA20 位置、市场宽度、5 日成交额比值）任一为 `missing` / `failed` 时，本节不输出方向验证项，只输出"`<缺失字段名>` 是否已恢复为 `ok` / `fallback`"。当日所有方向结论同步降级为 `insufficient`。
2. **A2 反证项**：今日指数方向与市场宽度、MA20 位置或成交确认任一维度反向时，按"市场宽度 → 趋势位置 → 成交确认"顺序取首个反证项作为验证字段。优先级来源是信号衰减速度：宽度为当日横截面，最快也最容易失真；MA20 为收盘对中期均线，居中；5 日成交额比值最滞后但反转常代表趋势级问题。
3. **A3 中性项**：今日证据未形成反证，但某个维度处于混合区（宽度处于 `45%`–`55%` 或两个指标不同向、MA20 上下指数打平、放量计数不足 3 个同向），按同样顺序"宽度 → 趋势位置 → 成交确认"取最易翻脸的中性项作为验证字段。
4. **A4 全部确认**：四类维度全部与今日结论同向时，默认验证市场宽度能否保持同向；宽度通常比 MA20 更早暴露参与面收缩，比 5 日成交额比值更敏感。
5. **A5 风格例外**：当今日结论为"成长占优"且市场宽度已确认，唯一未确认的是成长组成交额（创业板指与中证500 的 5 日成交额比值中位数）时，跳过宽度，直接验证成长组成交额是否回升至 `≥1.0`，避免重复已经通过的检查。

### 场景标准句

下表把选层逻辑落到一句话。每一行只能命中一种状态，命中即停止；同一行不命中时按下一行匹配。A1 永远优先于 A2–A5；A2–A4 之间按上述优先级取首个；A5 只在成长占优且宽度已确认时生效。

| 命中层 | 当前状态 | 验证字段 | 触发阈值 | 期望方向 |
|---|---|---|---|---|
| A1 | 任一必要输入 `missing` / `failed` | 缺失字段名 | 字段质量恢复为 `ok` / `fallback` | 恢复有效输入 |
| A2 | 同步上涨 + 负向宽度 | 上涨占比 + 全 A 涨跌幅中位数 | 占比 `≥55%` 且中位数 `>0`（修复）或占比 `≤45%` 且中位数 `<0`（分化未定型） | 修复侧与今日结论同向；分化未定型侧今日结论被推翻 |
| A2 | 同步上涨 + 混合宽度 | 上涨占比 + 全 A 涨跌幅中位数 | 至少一方由混合转为正向（占比 `≥55%` 或中位数 `>0`） | 持续性确认 |
| A2 | 权重护盘 + 负向宽度 | 上涨占比 + 全 A 涨跌幅中位数 | 占比 `≤45%` 且中位数 `<0`（背离延续）或占比 `≥55%` 且中位数 `>0`（个股跟随） | 与今日结论同向的延续 / 推翻 |
| A3 | 同步上涨 + MA20 下方指数 ≥ 3 个 | MA20 上方指数计数 | MA20 上方指数重新回到 `≥3` 个 | 趋势位置由中性转正 |
| A3 | 同步上涨 + 放量计数同向不足 3 个 | 放量上涨指数计数 | 放量上涨指数数 `≥3` | 量能由中性转正 |
| A4 | 同步上涨 + 普遍走弱（宽度负向已被同时挡住） | 上涨占比 + 全 A 涨跌幅中位数 | 占比仍 `≥55%` 且中位数仍 `>0` | 持续性确认 |
| A4 | 同步上涨 + 全部确认（默认场景） | 上涨占比 + 全 A 涨跌幅中位数 | 占比仍 `≥55%` 且中位数仍 `>0` | 与今日结论同向 |
| A4 | 普遍走弱 + 全部确认 | 上涨占比 + 全 A 涨跌幅中位数 | 占比仍 `≤45%` 且中位数仍 `<0` | 与今日结论同向 |
| A4 | 分化未定型 + 全部确认 | 上涨占比 + 全 A 涨跌幅中位数 | 至少一方突破混合区（占比 `≥55%` 或 `≤45%`，或中位数跨过 `0`） | 方向由未定型转为确认 |
| A5 | 成长占优 + 宽度已确认 + 成长组成交额未确认 | 创业板指与中证500 的 5 日成交额比值中位数 | 中位数 `≥1.0` | 成长占优的成交确认 |

选层对应的规则依据见本篇置信度计算与 `QTS-01-01-06` 的五态编码；本节不新增 `QTS-01-01-*` 规则，只复用现有指标和阈值状态。

### 填句硬约束

`下一交易日只验证` 字段输出必须同时满足下列约束：

1. **只写一项**。写入两项以上等于没写，复盘时仍会按偏好挑一项解释。
2. **字段、阈值、方向三段齐全**。观察项必须来自本节场景表的字段列；触发阈值必须是数值（百分比或比值），不接受"继续强势""维持现状"等定性词；期望方向必须与今日结论同向，不是次日涨跌预测。
3. **A1 永远优先**。必要输入缺失时不写方向验证项，写缺失字段恢复项。
4. **多个反证或中性项并列**时按 A2 → A3 → A4 取首个；成长占优符合 A5 条件时直接走 A5，不再回退到 A4。
5. **不写技术分析视角**。压力位、缺口、前高、形态等不属于环境验证字段，遇到时回退到宽度 / MA20 / 成交确认三选一。

### 明日回测逻辑

下一交易日仍要重新读取全部数据并重新计算本篇置信度；同时按昨日写入的验证字段做单向回测，结果只用于更新置信度，不直接生成新结论。回测口径如下：

- **通过 — 加强**：昨日验证字段与今日同向且幅度更优（占比远离阈值、中位数同号增大），置信度允许升级一档；同步上涨 + 正向宽度 + 改善 → `high`。
- **通过 — 维持**：昨日验证字段与今日同向但幅度未放大，置信度沿用昨日档位。
- **失败**：昨日验证字段反向，回到原始证据重新分类。同步上涨 → 权重护盘或分化未定型；普遍走弱 → 分化未定型；成长占优 → 同步上涨或分化未定型。
- **中性**：昨日验证字段仍处于混合区或当日缺失，今日结论暂时保留，把这条字段升级为"再下一交易日的验证项"，并写入 `nextVerification`。

回测结果必须记录在输出接口的 `confirmation` 或 `invalidation` 字段，不进入评分；连续两次中性时回退到 A4 默认验证项。

### 验证字段的缺失与异常处理

- 联合确认所需字段缺失或上一交易日快照不存在时，本节只输出字段恢复项，方向验证项留空。
- 验证字段所需的指标本身进入 `null` 时，按"反向证据足以推翻今日结论"处理，置信度最高保留 `medium`，并在 `invalidation` 字段写明"验证字段缺失，按反证对待"。
- 同一字段连续两个交易日不可计算时，回退到 A4 默认验证项，并在输出接口 `missingInputs` 中登记。


## 数据缺失与异常处理

- 分母为0、行情无效或样本归属不明时，该指标记为`null`，不得填0代替。
- 有效指标覆盖率≥90%才允许高置信度；70%–89%最高为中；50%–69%最高为低；低于50%输出`insufficient`。
- 对剩余有效指标重新归一权重；涉及风险否决的输入缺失时保留风险提示，不按安全处理。
- 极端值保留原值用于风险识别；用于分位和均值时同时输出稳健统计，避免单点污染。

## 校准与验证

- 本篇所有`needs-backtest`阈值均为经验初值，必须记录训练区间、样本外区间、交易成本和规则版本。
- 至少比较固定阈值与滚动分位阈值，并按市场环境、板块、流动性或交易模式分组检查稳定性。
